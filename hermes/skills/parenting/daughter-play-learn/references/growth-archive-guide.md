## 一、档案结构

### 📓 成长记录（按时间线）
每次对话追加一个条目，格式：
```
### [YYYY-MM-DD] | 标题

**来源**：会话渠道 + 简要背景

#### 核心内容
用表格/列表清晰呈现，保留关键细节。

**军师评语**：（如果有）
```

### 💡 学习策略库
按策略类型归类，标注：策略名、说明、当前效果（待试/进行中/有效/停用）

### 🏷️ 标签索引
标准标签：`#对话记录` `#策略迭代` `#情绪观察` `#里程碑` `#反思` `#战情`

## 三、每日自动入库

已设置 cron 任务，每天 22:00 执行：
- 扫描当日所有会话中与端木/大女儿相关的内容
- 按格式追加到成长记录
- 更新 index.md 和 log.md
- 无新内容则静默

cron 设置参考：
```
name: 我爱端木 · 每日扫描入库
schedule: "0 22 * * *"
enabled_toolsets: ["search", "file"]
deliver: origin
```

在 skill 中触发自动存档的方式：生成每日文心/惊喜/任何端木相关内容后，如果内容涉及端木的新观察或策略调整，应提醒用户是否要「存进端木档案」。
