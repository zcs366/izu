# 古典故事童话版改编 v3.0

> **设计哲学**（受 Google NotebookLM 启发）：
> 1. **源头锚定**（Source-Grounded）——每一篇改编都忠于原文核心，不虚构关键事实
> 2. **一次摄入，反复使用**（BYOS + Cache）——原文首次读后入 wiki，永不重读
> 3. **引用可查**（Citation）——每篇末尾标注出处
> 4. **多形态输出**（Multi-Format）——童话 + 讨论指南 + 角色卡
> 5. **认知谦逊**（Epistemic Humility）——合理想象与原文事实分界清晰

---

### 📂 输入目录
用户将原始文档放入：**`I:\hermes\input\pdf\`**

```
I:\hermes\input\pdf\ → 提取原文 → 清洗排版 → 存入 wiki/raw/
```

## 二、适用范围（三大类）

### 第一类：小说类（虚构叙事）
聊斋志异、四大名著、唐宋传奇、太平广记、三言二拍、阅微草堂笔记、子不语等

### 第二类：历史类（纪传/编年）
二十四史、左传、国语、战国策、吴越春秋、越绝书等

**历史类改编要点**：
- 保留"真人真事"的庄重感——告诉孩子"这是曾经真实发生过的事"
- 历史背景不可虚构，但细节（对话、心理）可合理想象
- 复杂政治→简化"好人vs坏人、智慧vs愚蠢"
- 战争：写勇气和智慧，不写血腥
- 长事件拆成"英雄三部曲"

### 第三类：典故类（寓言/格言/轶事）
论语、孟子、韩非子、庄子、列子、世说新语、说苑、新序等

**典故类改编要点**：
- 每个典故自成一个完整小故事（800-1000字）
- 保留原文金句→告诉孩子"这句话后来变成了一句成语"
- 寓言类：不直接说教，让故事自己说话
- 末尾加："XXX这个成语/典故就是这么来的"

## 三、核心模板（四段式）

### 1.【开场钩子】
用每个孩子都有的普遍生活体验切入。第一段就要抓住孩子。

✅ 正确："宝贝，你有没有过这样的念头：要是……"
❌ 错误："宝贝，你还记得昨天我们拼乐高的时候……"

| 类别 | 开场角度 | 示例 |
|------|---------|------|
| 小说类 | 情感共鸣 | "宝贝，如果你有一个特别要好的朋友，有一天他突然要搬家了……" |
| 历史类 | 崇敬感 | "宝贝，你知道吗？在很久很久以前，有一个真正的小英雄……" |
| 典故类 | 生活连接 | "宝贝，你有没有在路上看到一块大石头，觉得它像一只蹲着的小猫？……" |

### 2.【古风俗小课堂】
每篇必须有一个有趣的古代文化/历史知识点。用孩子能理解的类比解释。

| 类别 | 讲什么 | 示例 |
|------|--------|------|
| 小说类 | 古代风俗习惯 | "在古代，集市是乡下最热闹的地方……" |
| 历史类 | 古代制度/器物 | "那时候打仗用的'战车'就像一台移动的小房子……" |
| 典故类 | 古代思想/礼仪 | "'仁义'这个词，在古人心里就像我们心里'做好事'的指南针……" |

### 3.【故事正文】
#### 通用叙事要求

| 要素 | 要求 |
|------|------|
| 开头第一段 | 有强吸引力，让孩子"抢着要听" |
| 人物动机 | 一开始说明白主角为什么这么做 |
| 对话 | 生动、有童趣、有记忆力 |
| 心理活动 | 不露痕迹融入叙事，不加提示词 |
| 悬念反转 | 有紧张时刻、出人意料转折 |
| 恐惧控制 | 去掉血腥暴力，保留紧张刺激 |
| 逻辑闭环 | 结局有必然感，不强行团圆 |
| 字数 | **800-1200汉字**（精简有力；情节复杂者可达1500，但勿超） |

关于"睡着的秘密"：涉及离别/死亡时，用具象化比喻——"换装游戏""能量置换""交卷仪式"。

#### 分类叙事策略
- **小说类**：直接讲故事，保留人物鲜活度。对话为主，心理为辅。保留"异"味和传奇性。
- **历史类**：先定调"这是真的！不是编的！" 场景真实，复杂政治用"藏猫猫"式比喻。
- **典故类**：还原场景，"我就在现场看着"。写清起因经过结果。对话还原原意，文言→孩子能懂。

### 4.【爸爸想对你说】
从故事自然引出道理，语气亲切，不做道德说教。

## 四、改编禁忌

1. ❌ 不要用"任务卡片""任务目标"的游戏化框架
2. ❌ 不要为"温和"而磨平传奇性（孩子需要适度的紧张英雄感）
3. ❌ 不要用特定生活物件做类比（乐高/某个品牌）
4. ❌ 心理活动前加"（心想）""（自我对话）"等提示词
5. ❌ 忘记古风俗小课堂
6. ❌ 历史类改编虚构核心史实（人物、地点、结果不可改）
7. ❌ 典故类改编丢失原文金句
8. ❌ **新增**：不要擅自添加原文没有的主要情节或人物

## 五、长篇故事拆分规则

| 规则 | 说明 |
|------|------|
| 每篇自洽 | 单篇有起承转合，孩子独立听完也有获得感 |
| 悬念连接 | 末尾留钩子，期待下一篇 |
| 三部曲节奏 | 第一篇重「勇」、第二篇重「智」、第三篇重「爱」 |

## 六、多形态输出（NotebookLM 风格）

每篇改编可选附带以下内容（用户说"加指南"时触发）：

### 📖 讨论指南（Parent's Discussion Guide）
- 3个亲子讨论问题
- 1个"可以和孩子一起做的事"

### 🎭 角色卡片（Character Card）
- 主角名 + 一句话简介
- 孩子能记住的角色特征（≤3条）

---

## 七、输出规范

### 主输出（必选）
- 直接输出改编后的故事全文（四段式完整）
- 每篇600-900字
- 文末标注：`📜 改编自：《[作品名]·[篇名]》`
- 保存到 `I:\hermes\output\doc\`

### 副输出（可选）
- 讨论指南 + 角色卡片
- 保存到 `I:\hermes\output\doc\`（同目录，文件名加后缀）
