# Chinese Social Media Platform Formats

## 公众号 (WeChat Official Account)

| Property | Value |
|----------|-------|
| Article length | 1500-3000 characters (sweet spot: 2000) |
| Title length | 15-25 characters |
| Image count | 3-8 images |
| Image max size | 10MB per image |
| Supported formats | Rich HTML (via editor), simplified markdown |
| Best posting time | 8:00-9:00, 12:00-13:00, 20:00-22:00 |
| Key feature | Subscriber push notification |
| Monetization | 流量主 (ads), 赞赏 (tips), 带货 (sales) |

## 抖音 (Douyin)

| Property | Value |
|----------|-------|
| Video length | 15-60 seconds (sweet spot: 30-45s) |
| Aspect ratio | 9:16 (vertical) |
| Resolution | 1080×1920 recommended |
| Cover image | 9:16 vertical, text-free preferred |
| Caption length | Up to 500 characters |
| Hashtags | 2-5 relevant tags |
| Best posting time | 7:00-9:00, 12:00-14:00, 17:00-19:00, 21:00-23:00 |
| Key feature | Algorithm-driven discovery |

## 小红书 (Xiaohongshu / RED)

| Property | Value |
|----------|-------|
| Note length | 300-800 characters (sweet spot: 500) |
| Image count | 3-9 images (sweet spot: 6) |
| Image aspect | 1:1 (square) or 3:4 (portrait) |
| Cover image | First image is cover, make it eye-catching |
| Video length | 15-60 seconds |
| Hashtags | 0-5 tags |
| Best posting time | 7:00-9:00, 12:00-14:00, 18:00-22:00 |
| Key feature | Search-driven discovery (like visual Google) |
| Content tone | Personal, authentic, detailed, visual |

## 微博 (Weibo)

| Property | Value |
|----------|-------|
| Post length | Up to 500 characters (long text via 头条文章) |
| Image count | 1-9 images (sweet spot: 4-6) |
| Image aspect | Any, but 1:1 or 16:9 preferred |
| Video length | Up to 15 minutes |
| Hashtags | 1-2 key tags (#topic# format) |
| Key feature | Real-time trending, viral potential |
| Content tone | Newsy, opinionated, short, punchy |

## Common Content Adaptation Matrix

When given source materials, adapt per platform as follows:

| Source Material | 公众号 | 抖音 | 小红书 | 微博 |
|----------------|--------|------|--------|------|
| Facility photos (3-5张) | 配图+解说 | 快速切换幻灯视频 | 精选6张+图文笔记 | 九宫格+短文案 |
| Event video clips | 嵌入视频+分析文 | 精剪30秒高潮 | 15秒亮点+截图笔记 | 链接短视频 |
| Written introduction | 深度改写扩展 | 提取金句做口播 | 提炼干货清单 | 提炼3句话 |
| Pricing/packages | 详细方案文 | 价格展示卡视频 | 价格+价值对比图 | 优惠活动短帖 |
| User testimonials | 故事化扩写 | 感动瞬间混剪 | 真实体验图文 | 转发+短评 |
