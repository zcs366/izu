# 抖音短视频脚本模板

## 格式规范

脚本包含三部分：**画面分镜** + **旁白文案** + **制作备注**

## 模板

```
标题：【吸睛标题】15字以内

总时长：XX秒

─── 分镜 1 ───
时长: 00:00-00:05
画面: [画面描述]
旁白: "[旁白文案]"
字幕: [字幕文字]
特效: [转场/特效建议]

─── 分镜 2 ───
时长: 00:05-00:12
画面: [画面描述]
旁白: "[旁白文案]"
字幕: [字幕文字]
特效: [转场/特效建议]

...（按需增加分镜）

─── 结尾 ───
时长: 最后5秒
画面: [联系信息/二维码/引导关注]
旁白: "[行动号召]"
字幕: "[关注引导文字]"

─── 制作备注 ───
BGM风格: [激昂/温馨/紧张/轻快]
配音: [男声/女声/语速]
字体: [字幕字体]
封面建议: [封面图文字]
Hashtags: #标签1 #标签2 #标签3
```

## 国防教育基地类脚本范例

```
标题：走进真实的军事基地

总时长：45秒

─── 分镜 1 (钩子) ───
时长: 00:00-00:05
画面: 无人机俯拍山林全景，缓慢推进
旁白: "在你不知道的山里，藏着一个让孩子尖叫的地方。"
字幕: 你的孩子来过这里吗？

─── 分镜 2 (展示) ───
时长: 00:05-00:20
画面: 学生队列训练 → 射击体验 → 障碍跨越（快速切换）
旁白: "真人CS、射击训练、野外生存——这不是军营，是XX国防教育基地。"
字幕: 体验式国防教育

─── 分镜 3 (价值) ───
时长: 00:20-00:35
画面: 学生快乐笑脸特写 → 教官指导 → 团队合作场景
旁白: "一天研学，让孩子学会纪律、勇气和团队精神。"
字幕: 培养少年强国梦

─── 分镜 4 (规划) ───
时长: 00:35-00:42
画面: 紧张建设中的CS场地 → 规划效果图快速叠化
旁白: "全新的真人CS战场正在建设中，完成后更刺激！"
字幕: 全新CS战场即将开放

─── 结尾 ───
时长: 00:42-00:45
画面: 基地Logo + 联系方式
旁白: "私信预约，给孩子一个不一样的周末。"
字幕: 私信预约研学/团建

─── 制作备注 ───
BGM风格: 激昂管弦乐/军旅配乐
配音: 男声（云希），语速中等偏快
字幕: 文泉驿正黑，白字黑底半透明
Hashtags: #国防教育 #研学旅行 #周末去哪玩 #军事体验
```

## 托管班/书法班脚本范例

```
标题：孩子写作业磨蹭怎么办？

总时长：30秒

─── 分镜 1 (痛点) ───
时长: 00:00-00:05
画面: 孩子在书桌前东张西望，家长叹气
旁白: "孩子写作业磨蹭到半夜，你也不想天天吼？"
字幕: 你家也这样吗？😫

─── 分镜 2 (方案) ───
时长: 00:05-00:20
画面: 托管班教室实拍 → 老师辅导 → 孩子专心写作业
旁白: "XX托管班，专业老师辅导作业，孩子高效完成，家长省心。"
字幕: 专业辅导+良好习惯

─── 分镜 3 (特色) ───
时长: 00:20-00:27
画面: 周末书法班 → 学生展示书法作品
旁白: "周末还能学书法，孩子静下来了，字也漂亮了。"
字幕: 周末书法班同步招生

─── 结尾 ───
时长: 00:27-00:30
画面: 联系方式 + 地址
旁白: "私信咨询，免费试听一周！"
字幕: 私信免费试听

─── 制作备注 ───
BGM风格: 温馨轻快
配音: 女声（晓晓）或温厚男声
Hashtags: #托管班 #书法 #小学教育 #家长必看
```
