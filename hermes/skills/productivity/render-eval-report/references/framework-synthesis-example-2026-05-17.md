## 合成触发条件

当批量处理的一批文章满足以下条件时，必须做框架合成：
1. **有理论框架文章**（如周昌Evolver工程）— 定义方向和分类
2. **有架构模型文章**（如Agent=Model+Harness）— 给出组件结构
3. **有子系统文章**（如记忆综述、Ground Truth）— 深入具体层面
4. **有约束条件文章**（如Prompt Caching）— 给出边界
5. **有全景综述文章作为句号**（如年度综述）— 验证方向

## 合成方法

1. **找到最高抽象层级**：哪篇文章提供了最上层的分类框架？（通常是第一篇理论性文章）
2. **建立层级关系**：其他文章是它的子层、互补面、还是实例化？
3. **验证一致性**：所有文章是否指向同一个方向？有没有矛盾？
4. **输出一句总结**：用一句话把整个体系说清楚
