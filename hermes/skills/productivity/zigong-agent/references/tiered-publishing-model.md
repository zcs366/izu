# 三级包装发布模型（2026-05-15实战验证）

> 子贡的核心理念：一个好东西生产出来了，怎么让它到达该到的人手里，以他们能接住的形态？

## 三级结构

| 级别 | 受众 | 阅读时间 | 形态 | 弃了什么 |
|------|------|---------|------|---------|
| **一级** | 家庭群/元宝派（妻子/亲友） | 1分钟 | 四段式短推送，0术语，有温度 | 弃了所有学术引用 |
| **二级** | 公众号/朋友圈 | 5分钟 | 故事开头+四阶段展开+结尾追问 | 弃了理论溯源全文 |
| **三级** | 知乎/专业读者 | 25分钟 | 白皮书全文（学术严谨+引用完整） | 什么都没弃 |

## 关键设计原则

1. **每一级都是完整的独立叙事**。一级不是二级的摘要，二级不是三级的摘要。每篇都让目标读者觉得"你在说我"。

2. **弃什么是精心选择的**。一级弃学术但不弃温度——"她爬出去三步回头看你在"包含了安全基地理论的全部内核，只是去掉了术语。二级弃深度但不弃结构——四阶段叙事完整，维果茨基被一句话带到但留下入口。

3. **最深的不是"降低深度"，是"改变承载密度"**。白皮书1500字说"养正者"五个阶段，二级用300字，一级用四句话——但"安全基地→游戏伙伴→对话延伸者→沉默脚手架→见证者"的直觉曲线完整传递。

4. **最快的先发**。Hermes原则：先到位再调整。一级直推元宝派群聊，不需要排版、不需要审批。

## 切线与不可逆

三级包装+子贡=产品经理+信使的联合体。但发布有一票否决：Apollo+Venus双神把关，二级/三级发布前需军师终裁签核。一级（家庭群）因私域范围自动批准。

## 实战验证

2026-05-15白皮书《从游戏中长出的学习》：
- 一级 → 元宝派妻子事业群 ✅ 已发
- 二级 → 公众号/朋友圈 📋 就绪待发
- 三级 → 知乎 📋 就绪待发
