# PRD / Non-Goal 快速模板

在用户说"开干"之前，军师自动输出此模板。用户过目核准后执行。

## Goal

[一句话：我们要做什么]

## Non-Goal（最重要部分）

本次明确**不做**的三件事：

| # | 不做什么 | 为什么 |
|---|---------|--------|
| 1 | ... | 不涉及当前范围 / 需等前置条件 / 优先级不够 |
| 2 | ... | ... |
| 3 | ... | ... |

> Non-Goal 可以是外延控制（"不涉及X模块"）也可以是深度控制（"不做Y方向的优化"）。
