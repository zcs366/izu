# ITA项目启动 · 全团合议参考案例

> 2026-05-16 首次全团合议模式实战验证。

## 背景

用户完成《代码即编码：三语交互的压缩之路》白皮书后，提出ITA项目（Intelligence-Transformation-Architecture），与izu同级。核心理念：代码可压缩为LLM可读的compact encoding，三语交互（自然语言↔代码↔AI内部编码）。

已有学术支撑：Latent Programmer(ICML2021)、CoDist(EMNLP2023)、Activation Steering(2025-2026)、RoundTripCodeEval(2026)。

## 流程速览

| Phase | 过程 | 产出 |
|-------|------|------|
| P1 五人合议 | 子产→韩信→鲁班→萧何→子贡→军师 | 10个研究方向，核心三角 |
| P2 核战队选3 | 全员讨论，不同视角发言 | 方向1/2/3锁定 |
| P3 izu研究 | 三个方向并行研究 | 研究报告（由后续izu流水线完成） |
| P4 核战队汇总 | 阅读研究结果后各自意见 | 分歧意见汇总 |
| P5 五人合议定案 | 二次子产→韩信→鲁班→萧何→子贡→军师 | 项目命名+9个月路线图+成本$925 |

## 关键冲突与裁决

| 冲突 | 分歧 | 裁决 |
|------|------|------|
| 时间线 | 韩信6个月 vs 萧何9个月(日均1h) | 接受9个月，保留鲁班砍后3里程碑 |
| 编码器架构 | VQ-VAE vs FSQ vs 纯连续 | FSQ为主，连续→FSQ→双模式三步走 |
| 范围 | 子产10个 vs 鲁班3个 | 第一期3个，其余写设计文档不投入工程 |
