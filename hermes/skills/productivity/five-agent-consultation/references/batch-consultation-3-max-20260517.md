# 批量化合议实战：三极大模式（2026-05-17）

## 触发
用户说「启动三极大」——批量合议三条极大线：
1. Evolver工程（周昌）
2. Agent记忆全景综述（20+机构）
3. Skills取代Agent框架（Johnson7788）

## 流程
1. 评估先行：三条极大线各自先完成独立评估和入库
2. 子产：P0=记忆系统(窄做三样)、P1=Evolver工程(窄做三样)、P2=Skills趋势(只跟踪)
3. 韩信：3个月终局画像——记忆有结构、技能有评估、遗忘有算法
4. 鲁班：两次interrupted（上下文膨胀）→ 未完成
5. 军师直断：基于子产+韩信输出完成终裁

## 军师终裁

| 项目 | 决策 | 时间 |
|---|---|---|
| P0 记忆系统 | 立刻开干 | 1-2周 |
| P1 Evolver工程 | 记忆POC通过后启动 | 3-4周 |
| P2 Skills趋势 | 融入每周cron | 持续 |

## 核心原则
地基不稳不盖二楼。记忆系统不跑通则Evolver没有数据根基。
