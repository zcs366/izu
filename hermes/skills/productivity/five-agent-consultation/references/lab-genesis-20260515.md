# 五人合议案例：爱祝前沿实验室诞生记

> 2026-05-15，五人合议框架首次完整实战。

## 背景

张成市提出建"独立的大模型前沿实验室"。经过两轮讨论，最终确立了实验室的三大支柱使命：Agent自我迭代 + 多Agent协作 + AI×人文社科。

## 合议流程（实际执行）

由于本次决策涉及战略方向（非代码审计），实际执行了**韩信先行**的变体：

```
成市定方向（6点反馈） →
  军师定调（三大支柱+组织架构） →
    子贡：建实验室（写配置文档、定义6角色+工作流）
    猎手×2：论文狩猎（Agent自我迭代9篇 + 多Agent协作10篇）
    韩信：画终局（6步/24周路线图，三大"坚决做"五大"坚决不做"）
```

## 韩信终局核心输出

- **3个月**：izu有了"铸剑炉"——Agent能改进自己的技能
- **6个月**：izu有了"自愈系统"——Agent发现短板自己补
- **六步走**：地基夯实→Forge进化管道→动态路由→无人值守产线→角色自进化→闭环验证+开源

## 关键决策

1. **不做科学AI，做社科AI**（政治/军事/文学/艺术）——差异化方向
2. **学术发表为目标**——产出高质量论文，不只是内部报告
3. **Agent方向确认**——当前最热领域，研究资料充足
4. **自主研究节奏**——成市上午上班，军师凌晨+上午自主研究
5. **终极使命**：探索和实现AI自我迭代——这是AGI的"穷人路径"
6. **韩信当前**——遇到困难韩信挺身而出

- 韩信终局画像对"实验室往哪走"有极强的定锚作用——旗帜越清晰，执行越果断
