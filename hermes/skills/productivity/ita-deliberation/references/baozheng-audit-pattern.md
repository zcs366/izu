# 包拯审计执行模式

> 审计官：包拯 | 源自ITA v2.0 Day1实战审计（2026-05-19）

## 审计命令模板

### Step 1: 文件存在性

```bash
for f in <文件列表>; do
  if [ -f "$f" ]; then
    size=$(wc -c < "$f"); lines=$(wc -l < "$f")
    echo "✅ $f | ${size}B | ${lines}行"
  else
    echo "❌ $f | 文件不存在!"
  fi
done
```

### Step 2: 内容真实性抽验

```bash
# 对每个关键声称，grep检查文件中是否真实出现
echo "=== 声称X ===" && grep -c "关键词" <文件>
```

### Step 3: 20问全量验证

```bash
for i in $(seq 1 20); do
  count=$(grep -c "Q$i" <文件>)
  [ "$count" -gt 0 ] && echo "✅ Q$i" || echo "❌ Q$i 缺失!"
done
```

### Step 4: 判定输出

```
格式：
| 文件 | 存在 | 大小 | 行数 | 抽验 | 判定 |
|------|------|------|------|------|------|
```

## 包拯标记体系

| 标记 | 含义 | 处理 |
|------|------|------|
| 🟢 | 通过 | — |
| 🟡 | 证据不足 | 24h内补证据 |
| 🔴 | 虚假汇报 | 立即上报军师，关联责任团回溯问责 |
| ⚪ | 不适用 | 跳过 |

## 实战案例（2026-05-19）

7份战略文档审计：
- 存在性：7/7 🟢
- 内容真实性：10/10抽验 🟢
- 20问：20/20 🟢
- 8新问题：8/8 🟢
- 工具6维度：6/6 🟢

结论：实干，非虚报。全量通过。
