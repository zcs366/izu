# ITA止损检查点#1：张仪端到端验证桥接实验

> 张仪 | 2026-05-19 | ITA轨道最高优先级止损测试

## 核心问题

cos_sim≥0.80 能否桥接到"任务性能衰减≤5%"？如果cos_sim≈0.83但代码执行输出错误率>10%→ITA轨道核心目标破产。

## 实验设计

### 最小可行版本（当日完成，~1h）

1. 准备4个函数族（factorial/fibonacci/sorting/binary_search）
2. 每族3个语义等价变体（不同变量名/循环写法/递归vs迭代）
3. 计算变体间的n-gram cos_sim + Jaccard + 字符比
4. 执行交叉测试：变体A的代码+变体B的测试用例
5. 判定：交叉通过率<90%→任务衰减>10%→⚠️

### 完整版本（GPU就绪后）

1. HumanEval/LiveCodeBench随机采样30题
2. 生成正确解法代码 → ITA编码器编码 → FSQ量化 → 解码 → 运行测试
3. 比较 pass@1(量化后) vs pass@1(原始)

## 实战结论（2026-05-19）

```
12对语义等价变体交叉测试：✅ 100%通过
cos_sim最低仅0.39 → 执行一致性仍100%
→ 张仪警告未触发，ITA轨道继续
→ cos_sim是执行一致性的保守下界（低cos_sim≠执行失败）
```
