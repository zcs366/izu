# 活动策划与报价全面指南（原 wife-base-planner）

## 输入规范

```
【客户需求】
- 客户类型：学校研学 / 企业团建 / 亲子家庭 / 个人报名
- 人数：XX人
- 时间：X天X夜 / 半天 / 全天
- 年龄段：XX岁
- 预算范围：XX元/人
- 特别需求：……

【基地现有条件】（参考）
- 住宿：学校宿舍，可容纳200人
- 餐饮：食堂，自助/桌餐
- 场地：教学楼、操场、山林（正在建设真人CS）
- 教官：X名（待确认）
```

## 跟进方案

- 发送方案后第2天：微信跟进"收到方案了吗？有什么疑问？"
- 第5天未回复：电话或微信语音沟通
- 达成意向后：发送正式合作协议
- 活动结束后：满意度回访 + 邀请下次活动

## 定价策略

- 中端定位，性价比为卖点
- 竞品对标：周边军事体验基地
- 独特卖点：真场地+真教官+真课程体系
