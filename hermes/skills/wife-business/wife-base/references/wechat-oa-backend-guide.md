# 微信公众号后台操作指南（通过CDP连接）

> 适用于通过 Hermes CDP 连接登录后的 Windows Chrome，操作 mp.weixin.qq.com 后台。

## 前置条件

- Windows Chrome 已通过 `--remote-debugging-port=9222` 启动，Hermes `config.yaml` 已配置 `browser.cdp_url: http://xxx:9222`
- 用户已扫码登录（Chrome 中已有登录态）

## 一、数据查询

### 查看昨日阅读数据

1. **导航** → `browser_navigate(url="https://mp.weixin.qq.com/")`
2. 如未登录，页面显示登录界面（扫码或账号登录）
3. 登录后进入首页，**点左侧导航 → "数据分析" → "内容分析"**
4. 默认选中"昨日"标签，显示：
   - 数据概况：阅读 / 分享 / 留言（日和周对比）
   - 流量趋势曲线图（时间范围默认近30天）
   - 单篇文章数据明细表

### 高频查询入口

| 查询 | 导航路径 |
|------|----------|
| 昨日阅读数据 | 数据分析 → 内容分析（默认昨日） |
| 近7天/30天数据 | 内容分析 → 顶部标签切换 昨日/7天/30天 |
| 单篇数据明细 | 内容分析 → 下滑至文章明细表，有标题·阅读·占比·操作列 |
| 用户分析 | 数据分析 → 用户分析（新关注/取消关注/总用户数） |
| 消息分析 | 数据分析 → 消息分析（用户对话数据） |
| 互动分析 | 数据分析 → 菜单分析/消息分析/接口分析 |

## 二、文章发布

### 从已发表内容发布新文章

1. 首页 → **内容管理**（左侧导航）
2. 选择 新建图文 / 文章 / 选择已有内容 / 贴图 / 视频 等
3. 编辑器内写内容（支持富文本排版、插图、原创声明等）
4. 点击「发表」前**必须经用户明确授权**

### 发布前确认清单

- [ ] 内容已给用户预览并获明确反馈
- [ ] 用户已口头/文字授权"可以发了"
- [ ] 标题和摘要（如果手动设置）已确认
- [ ] 配图/封面图已确认

## 三、注意事项

### 关键限制
- **发表必须用户亲口批准**，不能自行发布
- 数据统计在凌晨更新，查询昨日数据建议在 **9:00 之后**（公众号后台提示语）
- 历史数据仅保留一定周期，2025年11月1日前的数据需单独从"查看历史数据"入口查询

### CDP会话维持
- CDP连接的Chrome标签页保持后台运行即可
- 如果关闭了公众号页面，重新 `browser_navigate` 会恢复，登录态仍在（同一Chrome进程）
- 如果Chrome进程重启，需要重新扫码登录

### 常见元素ID参考（从browser_snapshot识别）

从左侧导航栏识别：
- `数据分析` = e25（常见，但以具体snapshot为准，下同）
- `内容分析` 子项 = e31
- `内容管理` = e23
- `互动管理` = e24

首页数据卡片识别：
- `阅读` = 左侧数字
- `总用户数` = 统计卡片数字
- `近期发表` = 首页下方，最后1-5篇文章
- `数据统计中，请在9:00之后查看` = 凌晨数据未就绪

## 四、文章配图处理（关键难点）

### 4.1 核心限制

远程浏览器（Browserbase）不支持原生文件上传。以下方法已验证：

| 方法 | 结果 | 说明 |
|------|------|------|
| fetch → DataTransfer → file input | ❌ 事件不被WeChat编辑器捕获 | 上传对话框不响应JS设置的files |
| base64 data URL → contenteditable insert | ❌ 不持久化 | 插入后保存草稿即丢失 |
| Unsplash/Pexels直接下载 | ❌ 多数站点封curl | 需浏览器User-Agent绕开 |
| WeChat编辑器「免费正版图片」 | ❌ 此版本无此tab | 仅有「本地上传」 |

### 4.2 推荐策略（2026-05-19定型）

**方案A（推荐 — 对应军师三件套模式）：** 写正文 → 自己下载配图到共享目录（Pixabay/Unsplash）→ 在正文里标注图片位置 → 保存草稿 → 通知用户打开手机从相册插图+发表。
- Pixabay: https://pixabay.com/zh/（全球最大免费图库，中文搜索）
- Unsplash: https://unsplash.com/（高质量摄影风，英文搜索效果更好）
- 图片下载到 `/mnt/i/hermes/output/`（= Windows `I:\\hermes\\output\\`），用户可从Windows直接访问
- 每张图标注位置：`[图片1：插在「沙坑倒水」故事后面 — 选一张孩子玩沙的照片]`

**方案B（封面图 + 正文图 | 非远程浏览器专用）：** 用 Unsplash 直接链接通过 browser 下载到本地 → 通过「选择文件」上传。仅当 Chrome 运行在本机而非远程浏览器时可行。

**方案C（AI生图）：** 调用 `image_generate` 工具配文生图，但需要 FAL 或其他 provider 余额充足。

### 4.3 封面图 vs 正文内图

- 封面图：「拖拽或选择封面」区域，不接受remote file input注入
- 正文图：通过编辑器「图片」按钮的upload dialog上传
- **最终方案**：正文必须至少一张图才能发表。推荐策略A——正文写完存草稿，用户手动加一张图+封面。

## 五、发表流程与常见阻塞点

### 5.1 完整发表流程

```
正文写 → 声明原创（可选）→ 设置摘要 → 声明创作来源 → 确保有图 → 发表
```

### 5.0 标准协作流程（军师三件套模式，2026-05-19定型）

**这是与用户达成的固定发布协作模式，所有公众号发文走此流程：**

| 阶段 | 谁干 | 产出 |
|------|------|------|
| ① 写文章 | 军师 | 正文+标题+摘要，通过CDP填进编辑器，设好原创声明、作者、留言开关 |
| ② 找配图 | 军师 | 从Pixabay/Unsplash等免费图库下载2-3张配图到共享目录（`/mnt/i/hermes/output/`），文章正文中标注每张图插在哪个位置 |
| ③ 配图+发表 | 用户 | 打开手机公众号助手→草稿箱→从相册插入对应位置→发表 |

**关键逻辑：** AI能完成所有文字和排版工作，但「上传本地图片到微信编辑器」和「点击发表」这两步，只能由用户在手机上完成。不要尝试通过CDP/JS注入绕开——已验证不可行。

### 5.2 原创声明（原创）对话窗口陷阱

点击「原创」checkbox后弹出的dialog有三个校验条件，**任何一个不满足都卡死**：

| 条件 | 常见失败原因 | 解决办法 |
|------|-------------|----------|
| 作者不能为空且≤8字 | 输入事件没触发验证 | 用 `browser_type` 而非 JS 设置 value |
| 必须勾选协议 | 复选框校验与DOM状态不同步 | 点击包含「我已阅读并同意」的label元素 |
| 确定按钮 | 所有条件满足才能点 | 三次都失败则放弃原创，直接发表 |

**如果原创dialog卡死：** 点击「取消」关闭dialog → 取消勾选原创checkbox → 直接点「发表」。

### 5.3 创作来源声明

WeChat在发表前会弹出一个dialog：
> 「若你发表的内容涉及国内外时事、公共政策、社会事件或内容由AI生成等，需对创作来源进行声明。」

- 非时事类内容（育儿/个人随笔等）：直接点**「无需声明并发表」**
- 涉及时事/政策：点「去声明」填写来源

### 5.4 必须插入一张图片

正文中至少有一张**通过WeChat编辑器上传的图片**（本地或编辑器图库）。通过base64/dataURL注入的图不生效。最佳做法：

1. 正文写完 → 保存草稿 ✅
2. **通知用户手动加一张图** → 用户点开草稿，在正文中插入任意图片
3. 用户自己点击「发表」

## 六、会话与草稿管理

### 6.1 登录token有效期

- WeChat后台token有效期约**15-30分钟**。长时间操作（如写长文、研究配图）期间极可能过期。
- 过期后页面跳回登录页，**未保存的编辑内容全部丢失**。

### 6.2 防丢原则

1. **操作间隙就存一次草稿**——写标题存、写一半存、写完存。`browser_click(ref=e33)`（保存为草稿按钮）
2. token过期后，让用户重新扫码登录 → 导航到草稿箱找到草稿 → 继续编辑
3. 但如果草稿名为「未命名文章」，说明之前的内容**没存上**——需要重新写

### 6.3 编辑器导航

```
直接进入编辑器（新文章）：
https://mp.weixin.qq.com/cgi-bin/appmsg?t=media/appmsg_edit&action=edit&lang=zh_CN&type=10&isMul=1&token={token}

草稿箱列表：
https://mp.weixin.qq.com/cgi-bin/appmsg?begin=0&count=10&type=77&action=list_card&token={token}&lang=zh_CN

发表记录：
https://mp.weixin.qq.com/cgi-bin/appmsg?begin=0&count=10&type=9&action=list&token={token}&lang=zh_CN
```

## 七、与 wife-base 及个人账号的联动

本指南适用于**所有微信公众平台账号**的操作，包括：

| 账号 | 用途 | 归属技能 |
|------|------|----------|
| 與京美叶 | 个人创作/育儿随笔 | 无特定技能，直接操作 |
| 国防教育基地 | 商业运营 | wife-base 产出文案 → 本指南发布 |

```
wife-base 负责：写什么（内容策略、文案、品牌调性）
本指南负责：怎么发（后台操作、数据查询、发布流程、排坑）
```

使用时：产出文案 → 用户确认 → 通过CDP操作公众号后台 → 保存草稿 → 用户加图发表
