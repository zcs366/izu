## 排版格式规范（用户偏好，2026-05-09 强制实施）

所有七脉周报必须遵守以下格式规范，以保证在 Telegram/元宝等即时通讯工具上的阅读体验：

### 头部
```
# 军师祭酒 · [主题名]

**日期：2026年X月X日（周X）| 丙午年X月X日**（可选农历）
**呈：张成市**
```
- 不要用 `>` blockquote 做日期
- 用 `**粗体**` 做日期行

### 主体结构
```
## 📊 五个固定关注点

### 一、标题
正文（60-150字，精炼直接）

### 二、标题
正文

### 三、标题
正文

### 四、标题
正文

### 五、标题
正文

---

## 🔄 灵活快讯
1. **标题**: 一句话内容
2. **标题**: 一句话内容
...
（6-8条，每条带粗体标题）

---

## 💡 军师的话（可选）
> 简短有力，有温度
```

### 必须遵守的规范
1. **编号**：中文数字编号（一、二、三、四、五），不要用阿拉伯数字（1. 2. 3.）
2. **段落长度**：每项正文严格控制在60-150字内，拒绝长段落堆砌
3. **子标题**：不要用「xxx」形式的子标题，用 ### 层级即可
4. **语气**：群聊内有妻子，避免过于个人化的指责语气。用客观但有力的表达
5. **信息来源**：如果引用外部信息，末尾用 `## 📎 信息源` 列出
6. **文件存档**：生成后同时保存到 `/mnt/i/hermes/output/weekly_reports/[主题]-[日期].md`

### 反面案例（以前的周六版，已修正）
- ❌ 使用 `>` 做日期 → 应改为 `**日期：...**`
- ❌ 使用 `1. 2. 3.` 阿拉伯编号 → 应改为 `一、二、三`
- ❌ 段落超长（200-300字）→ 应控制在60-150字
- ❌ 使用 `**「xxx」**` 子标题 → 不应使用
- ❌ 过度个人化指责语气（"你沉溺、你记性不好"）→ 改为客观分析

## 修改 cron job prompt 的方法

1. 从 `/home/zcs/.hermes/cron/jobs.json` 读取当前 prompt
2. 用 `cronjob update --job_id <id> --prompt "<新文本>"` 覆盖
3. 需要提供完整的 prompt 文本（非增量修改）
4. 对 format 类修改，`cronjob update` 是首选（自动处理 json 转义）
5. cronjob 命令支持：`list | update | run | pause | resume | delete`

## 元宝 YUANBAO_HOME_CHANNEL

配置在 `~/.hermes/.env` 中：
```
YUANBAO_HOME_CHANNEL=direct:<user_id>
YUANBAO_HOME_CHANNEL_THREAD_ID=
```

`yuanbao`（不加频道参数）默认映射到 home channel（刺史私聊）。
