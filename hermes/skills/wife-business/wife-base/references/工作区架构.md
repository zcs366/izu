# 国防基地文案专员 · 工作区参考

## 输出路径

所有产出的文件保存到以下目录：

```
I:\hermes\wife_business\01_国防基地\
├── 公众号\      ← 公众号文章（.md格式，可直接复制到公众号编辑器）
├── 抖音\        ← 抖音短视频脚本（含分镜+配音+字幕）
├── 小红书\      ← 小红书种草笔记
├── 活动方案\    ← 完整活动策划方案
├── 报价单\      ← 报价方案
└── 素材库\      ← 原始素材（照片、参考文档）
```

## 工作流速查

### 公众号文章
1. 用户提供素材（照片描述+文字说明）
2. 按标准模板撰写
3. 保存到 `公众号/{日期}_{标题}.md`
4. 通知用户取用

### 抖音脚本
1. 用户提供现场视频/照片
2. 写脚本（含分镜表+配音稿+字幕）
3. 保存到 `抖音/{日期}_{标题}.md`
4. 可选：用 Edge TTS 生成配音音频

### 小红书笔记
1. 用户提供照片+要点
2. 写种草笔记
3. 保存到 `小红书/{日期}_{标题}.md`
