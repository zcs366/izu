# 认知地图（Cognitive Map）写作标准

## 定义

认知地图是长编的"导航"——7-10段手机可读的短文，引导使用者在长编资料池中找到自己的学习路径。它不是知识摘要，是路引。

## 格式规范

1. **无页码、无编号**——不要写"第1页""第2页"。段落之间用`---`分隔，像一个人在边走边聊
2. **每段结构**：一句引子（抓住人）→ 一个画面（帮助记忆）→ 三个关键事实 → 一个行动指引
3. **段落之间有节奏**——前一段末尾留下悬念（"那然后呢？"），后一段自然接上

## 写作质量要求

| 维度 | 标准 |
|------|------|
| **引子** | 开头第一句话就要抓住人。可以是反常识的、有张力的、带情绪的 |
| **画面** | 每个核心概念配一个生活化的类比或场景。让读者一秒"看见" |
| **节奏** | 长短句交错。段落不要太长（手机一屏以内）。节奏感要强 |
| **钩子** | 每段末尾留一个未回答的问题或未展开的方向——读者会产生"那然后呢"的冲动 |
| **见解** | 不止是"这里有什么"，是"我对这里的判断是什么"。普通地图只有地名，认知地图要有简介和见解 |

## 第7段：挂轴地图

最后一段（第7段）是特殊段落。它是整张地图的挂轴，展示：
- 各面之间的逻辑关系（不是散列表，是"面X和面Y的咬合点是Z"）
- 索引层级说明（长编是第几层，外面还有哪些层）
- 作者的判断——不是客观综述，是"我是这么看的"
- 最后回到"得道快乐"——明白学习本身的目标不是知道，是打开自己的门

## 语言风格

- 写给你服务的"可能不太懂或根本不懂"的人（用户原话）
- 术语第一次出现时用括号解释
- 关键概念用"一句话+一个类比"说清
- 不要贴英文原文，翻译好再写
- 不要表格（手机阅读体验差）

## 认知地图不是…

- 不是导航图（不要写"去面X看第Y节"）
- 不是知识卡片（不要干巴巴的一二三四）
- 不是广告（不要只唱赞歌，风险和争议要同时出现）
- 不是长编的替代品（它是指向长编的引子，深度在长编里）

## 认知地图的标准

一条标准就够了：读者读完，自己会想去打开长编找更多。如果他没有这个冲动，说明地图没画好。
