# 祝 v0.4 CLI Agent 使用说明

## 安装位置
- 命令：`~/.local/bin/祝`（系统PATH）
- 脚本源：`/mnt/i/hermes/scripts/祝.py`
- 底层代理：`/mnt/i/hermes/scripts/subagent.py`（直接调 DeepSeek API）

## 用法

```bash
祝 "主题"                    # 智能默认（3编，温度0.7，含交互式意图澄清）
祝 "主题" --quick            # 1编快速草稿
祝 "主题" --deep             # 5编深度精研
祝 "主题" --wild             # 发散模式（高温度0.9，5编起）
祝 "主题" --focused          # 精炼模式（低温度0.2，3编内）
祝 "主题" --t 0.8            # 自定义温度
祝 "主题" --silent           # 跳过意图询问（纯批量模式）
祝 --version                 # 版本信息
```

## 核心流程（三智能体流水线）

```
query → 意图澄清（观察反馈）→ [搜→写→劈]×N编 → 最终定稿 → 润色魔法（厚重句注入）→ 祝号 → 认知地图 → 更新画像
```

| 阶段 | 说明 | v0.4 增强 |
|------|------|-----------|
| 第0步 | 意图澄清：输出观察而非选择题 | 「你的用词告诉我你可能更关心XX方向」 |
| 搜 | 深度研究搜集，关注跨领域连接 | 加入「展望与连接」指令 |
| 写 | 风格化写作（画面、节奏、厚重句） | 加入「在人类经典文献中留下一笔」标准 |
| 劈 | 严苛审读，不留情面 | 加入对齐检查+自动校正 |
| 润色 | 最终写作后的魅力注入 | 厚重句注入、展望检查 |
| 祝号 | 输出尾巴（观察，非问句） | 新加 |
| 画像 | 会话即画像，不填表 | 新加 |

## 产出
- `output/doc/{slug}_长编_{timestamp}.md` — 研究报告（含历次批评，末尾带祝号）
- `output/doc/{slug}_认知地图_{timestamp}.md` — 手机友好地图（7段无页码，末尾带祝号）
- `output/doc/_profiles/default.json` — 画像存档（自动生成，无需配置）

## 画像层原理
- 每次使用自动记录：query、timestamp、深度、聚焦方向
- 从query中提取兴趣关键词，累计权重
- 下次使用时，画像摘要注入搜索prompt，实现「认得你」
- 不填表，不骚扰，会话即画像

## 参数哲学
- **道不变**：让人得道、快乐、触类旁通
- **术可变**：温度、种子、策略、长度——全都能调
- `--wild` = 探索模式，适合找灵感、跨领域连接
- `--focused` = 精炼模式，适合深度理解一个具体问题

## 依赖
- DeepSeek API key（已有，配置在 ~/.hermes/.env）
- Python requests 库
- 网络连接

## 文件名约定
产出文件名中的 {slug} 由研究主题自动生成：中文/标点转下划线，截取前40字符。
