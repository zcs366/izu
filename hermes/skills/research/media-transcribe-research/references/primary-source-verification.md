## 常见视频夸大模式（实战总结）

### 模式A：标题党（最危险）
- **症状**：视频标题比论文标题夸张 10 倍
- **案例**：S-Path-RAG 视频说"AI拔掉人类语言插管，矩阵级技能注入"，实际论文是"知识图谱最短路径检索+标准cross-attention"
- **应对**：直接去 arXiv 搜论文摘要，看原文措辞。如果视频标题和论文摘要的描述不是一个级别的，以论文为准。

### 模式B：场景泛化
- **症状**：视频暗示"这项技术可以通用/革命XX领域"，但论文实验只在特定场景验证
- **案例**：WeightFormer 视频没提实验限于视觉模型，论文自身标注 cs.CV
- **应对**：查看论文的 Subjects 字段（cs.CL / cs.CV / cs.AI），判断是否跨领域适用。只看实验设置(Experiment Setup)部分。

### 模式C：数据模糊化
- **症状**：视频说"大幅提升""稳定超越"，不给出具体数字
- **案例**：Ctx2Skill 知乎说"多种骨架模型稳定提升"，实际有精确数字（GPT-4.1 +5.4pp / GPT-5.1 +4.6pp）
- **应对**：论文中的数字和视频给出的数字必须逐项核对。注意"pp"（百分点）和"%"的区别。

### 模式D：作者/机构虚标
- **症状**：视频说"斯坦福开源"，实际是个人项目+194 stars
- **案例**：StatsPAI 视频说"斯坦福开源"，实际 Bryce Wang 个人项目
- **应对**：看论文/仓库的作者 affiliation 字段。如果作者单位没有官方背书（如"Stanford"仅出现在个人资料），不能自称"斯坦福官方"。

## 各信源渠道的核实优先级

| 来源 | 可信度 | 核实需求 | 代表作 |
|------|--------|---------|--------|
| arXiv 论文原文 | ✅ 高 | 直接采信 | arxiv.org |
| 官方博客 | ✅ 高 | 直接采信 | transformer-circuits.pub |
| 最佳拍档TV | 🟡 中 | **核实后可用**，通常准确但省略限制条件 | 大飞说科技系列 |
| wow频道 | 🔴 低 | **必须核实**，标题党+大幅夸大高发 | S-Path-RAG视频 |
| 知乎想法 | 🟡 中 | 部分准确，需交叉验证 | 天才研究牲/王几行XING |
| 知乎专栏软文 | 🟡 中 | 搜索验证核心数据 | 边缘AI/ELM文 |
| CSDN/51CTO | 🟡 中 | 可能转述二手信息 | 技术博客 |

## 快速论文搜索流程

```python
# 从视频描述/标题中提取论文关键词
搜索策略:
  1. arXiv 精确匹配: f'\\"{论文标题}\\" arXiv'
  2. 作者名 + 关键词: f'{作者} {关键词} arXiv 2026'
  3. 会议搜索: f'{关键词} WWW 2026 / ICML 2026 / ACL 2026'
  4. GitHub 仓库: f'{项目名} GitHub'

常见论文平台:
  - arXiv.org (首选)
  - OpenReview.net (隐式匿名评审)
  - paperswithcode.com (附带代码)
  - transformer-circuits.pub (Anthropic可解释性)
  - proceedings.mlr.press (ICML/CoLT)
  - dl.acm.org (WWW等会议)
  - huggingface.co/papers (社区精选)
```

## 置信度降级规则

如果论文原文无法获取（付费墙/会员专属/无开放版本）：

| 原始级别 | 降级后 | 标注 |
|---------|--------|------|
| 极大 | 大 | 「⚠️ 论文原文未获取，基于视频解读」 |
| 大 | 中小 | 「⚠️ 可信度待验证，视频解读未核实」 |
| 中小 | 参考 | 「⚠️ 仅作参考」 |

- 同时记录到 `wiki/queue/unverified-papers.md`
- 后续如果找到原文，补全并升级回原级别
