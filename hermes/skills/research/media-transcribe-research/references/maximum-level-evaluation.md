# 极大级评估报告结构

> 适用：用户发送"极大"级别的论文解读视频/文章，需走完整评估流程。
> 区别于标准评估（A/B/C三段式）——极大级需要更丰富的结构。

## 适用场景

- 用户说 `极大 <URL>` 或 `极大极大 <URL>`
- 论文有原始arXiv链接可核实
- 内容对标核心项目（ITA/Hermes/izu等），具备跨项目落地价值

## 工作流

```
用户发"极大"级链接
  → web_extract 获取页面元数据（视频描述/摘要）
  → 从描述中识别论文标题/arXiv ID
  → 搜索并获取原始论文（arXiv优先）
  → 核实视频解读 vs 论文原文（铁律：核实每一处数据）
  → 写极大级评估报告
  → 生成HTML双版（普通版+打印机友好版）
  → wiki概念页入库
  → log记录
```

## 报告结构（已验证模式）

### 0. YAML 头 + 批准编号

```yaml
---
title: "[论文名]——深度分析"
created: YYYY-MM-DD
type: 极大级评估报告
approval: 【批-YYYYMMDD-v1-事项简称≤8字】
tags: [相关标签]
sources:
  - arXiv:XXXX.XXXXX
  - youtube: XXXXXX
status: 待批准
---
```

> **批准编号铁律**（2026-05-20生效）：所有标"待批准"的报告必须附带【批-YYYYMMDD-v版本号-事项简称≤8字】。

### 1. 摘要 + 一句话定论

顶部的概要定论，用一句话点明"为什么这篇论文值得极大关注"。

### 2. 核心数据速览表

| 指标 | 数据 | 震撼程度 |
|------|------|---------|
| 关键指标1 | XX× | 🔥×N |
| 关键指标2 | XX% | 🔥×N |
... 

用火焰数量（🔥）直观标震撼程度，让读者秒懂论文的分量。

### 3. 实验设计（可信度评估）

表格评估四个维度，每行标注 ✅/⚠️/❌：

| 维度 | 详情 | 评价 |
|------|------|------|
| 平台/框架 | XXX | ✅/⚠️/❌ |
| 基准 | XXX | ✅/⚠️/❌ |
| 模型覆盖 | XXX | ✅/⚠️/❌ |
| 重复性 | XXX | ✅/⚠️/❌ |
| 团队 | XXX | ✅/⚠️/❌ |

结尾一句话综合判定可信度。

### 4. 核心发现详解（发现卡片）

每条发现独立成节，格式：

#### 发现N: [标题]
- 关键数据表格
- 本质解读（1-2句话）
- 实战影响（如果有）

### 5. 阶段/维度解构（表格）

如果论文涉及阶段分解或分维度分析，用简洁表格呈现占比+优化杠杆。

### 6. 核心项目落地建议（大节）

针对核心项目（ITA/izu/Hermes等）逐条输出落地建议：
- 每点用 ✅ 标记可操作项
- 给出具体推荐的模型/参数/策略

### 7. 自我反思

对 Hermes Agent / 当前工作流 的自我审视——"这篇论文揭示的问题，我们自己有没有？"

格式：列举3-5个自查点，每个带建议行动。

### 8. 评估结论（评级卡）

使用评级卡格式：

| 维度 | 评分 | 说明 |
|------|------|------|
| 学术价值 | ★★★★★ | 首次系统研究，填补空白 |
| 实用价值 | ★★★★★ | 产业界可直接应用 |
| 可信度 | ★★★★★ | 开源框架+多次重复 |
| 时效性 | ★★★★★ | 正值Agent规模化 |
| 可操作性 | ★★★★☆ | 部分建议可立即落地 |

**综合评级**: ⭐⭐⭐⭐⭐ 极大级

## 与标准评估模板的差异

| 维度 | 标准模板 (A/B/C) | 极大级模板 |
|------|-----------------|-----------|
| 目标 | 快速消化，出行动项 | 深度分析，做知识沉淀 |
| 数据量 | 每项1-2条 | 每项3-10条量化数据 |
| 实验设计 | 不要求 | 必含（评估可信度） |
| 项目落地 | 简版B栏 | 独立大节，逐条出操作 |
| 自我反思 | 无 | 有 |
| 评级卡 | 无 | 有（5维度评分） |
| HTML | 无 | 双版（普通+打印） |
| Wiki | 单条概念页 | 概念页+output三件套 |
