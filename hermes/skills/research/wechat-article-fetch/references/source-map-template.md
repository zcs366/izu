# 个人信息源地图模板

> 位置：wiki/concepts/my-info-sources.md
> 用途：记录用户信任的内容源，每个源标注风格/场景/盲区

## 源条目格式

```markdown
### {序号}. {源名称}

| 属性 | 值 |
|------|-----|
| **平台** | 微信公众号 / YouTube / 诗刊 / ... |
| **风格** | 叙事驱动/情绪驱动/资讯聚合/学者小品/文化批评... |
| **特点** | 一两句话描述这个源的独特价值 |
| **适合场景** | 什么情况下看这个源最有收获 |
| **可信度参考** | 可信/高/需交叉验证/观点大于事实 |
| **盲区** | 这个源不擅长什么、会忽略什么 |
| **最近细读** | [文章标题](URL) |
```

## 四轨分类体系（2026-05-20 验证：37源）

```
科技源 ← 资讯/叙事/硬核/工具实战
人文源 ← 学术/批评/趣味/思辨/通识
艺术源 ← 古典音乐/艺术文化/文学经典/时尚
文学源 ← 古典/现代诗/诗论/翻译/大刊
```

## 维护规则

1. 每新关注一个公众号 → 追加一条，记入对应轨
2. 账号名不确定 → 标记"待确认"，等用户纠正
3. 风格定性 → 基于该源的代表性文章判断，不是凭名称猜
4. 盲区 → 必须填。没有盲区的源说明还没吃透
5. 最近细读 → 每次读完该源的新文章，更新此字段指向最新一篇
6. 混合投喂 → 每个源独立走它的轨，分开处理

## 用户纠正模式（6种已验证）

- **"{目标}是{账号名}"** — 如"卡帕西是图灵编辑部"
- **"{内容标签}的是{账号名}"** — 如"埃尔德什的是南方Er"
- **"公众号：{账号名}"** — 显式前缀
- **"{账号名}"** — 直接给出（无前缀）
- **"源名称：{账号名}"** — 显式标注
- **"这个是{账号名}"** — 常见引导句式
