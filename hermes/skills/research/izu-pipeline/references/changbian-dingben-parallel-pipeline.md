# 长编→定本并行流水线研究法

> 已验证的快速研究→白皮书工作流。四条izu流水线并行→交叉审阅→统一厚重写作。

## 适用场景

- 一个核心命题需要多角度研究（如：学术溯源+实践框架+案例验证+扩展阶段）
- 各角度独立可研究，但最终需合为一部完整作品
- 追求速度：并行流水线将串行12+小时压缩到并行1小时内

## 流程四步

### 第一步：拆解命题为2-4个独立子命题

关键：每个子命题必须**独立可研究**——有自己的搜索范围、自己的论证链、不依赖其他子命题的输出。

示例（白皮书《从游戏中长出的学习》）：
- 子命题1：刘焱"真游戏≠好游戏"学术溯源（维果茨基→艾里康宁→刘焱→Guided Play）
- 子命题2：0-6岁Guided Play实践框架与操作指南
- 子命题3：端木个案——听觉通道堵塞学习者的游戏化方案
- 子命题4：6-12岁Guided Play自然成长历程

### 第二步：并行启动izu流水线

```bash
# 同时启动（后台进程）
cd /mnt/i/hermes/scripts && python3 izu-pipeline.py "子命题1" &
cd /mnt/i/hermes/scripts && python3 izu-pipeline.py "子命题2" &
cd /mnt/i/hermes/scripts && python3 izu-pipeline.py "子命题3" &
cd /mnt/i/hermes/scripts && python3 izu-pipeline.py "子命题4" &
```

每条流水线约15-25分钟。4条并行约25分钟完成全量研究。

### 第三步：交叉审阅定本

四条流水线产出四部定本（探→搜→织→对齐→写→劈→修→核各步骤文件）。逐一定本通读，提取：
- 统一术语（确保四部定本用词一致）
- 矛盾点（定本之间是否存在互斥论断）
- 重复内容（哪些内容在多部定本中重复出现，合一后需精简）
- 交叉引用机会（定本A的某章可以引用定本B的某结论）

### 第四步：厚重写作·合多为一

不是拼接四部定本——是焊接。需要：
1. 设计统一结构（不是"定本一+定本二+……"）
2. 写统一导言（从核心追问出发，预告全部结构）
3. 逐章写作（每章以一部定本为主，从其他定本引入交叉引用）
4. 写统一结尾（呼应导言，落在追问上）

风格：厚重、有画面、段落自然流淌。追求"在人类经典文献中留下一笔"的质感。

## 与单人串行研究对比

| 维度 | 串行（一条流水线研究全部） | 并行（多流水线+合一写作） |
|------|--------------------------|--------------------------|
| 总耗时 | 1条×60-90分钟（全命题覆盖）| 4条×25分钟并行+60分钟合一写作 |
| 深度 | 研究范围广但每角度可能偏浅 | 每角度独立深挖，深度有保障 |
| 风险 | 一条流水线失败全损 | 分布式：一条失败不影响其余 |
| 质量 | 搜索覆盖单一 | 四组搜索交叉覆盖，信息密度高 |
| 适用 | 简单命题、快速探索 | 复杂命题、需厚重产出 |
