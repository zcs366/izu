ComfyUI 概览与核心理念

1.1 什么是 ComfyUI

ComfyUI 是一个节点式（node-based）的 AI 生成界面，由开发者 comfyanonymous 于 2023 年初在 GitHub 上开源发布。它脱胎于 Stable Diffusion 社区，但如今已发展为支持图像、视频、音频、3D 等多种生成任务的统一平台。

核心设计哲学：用可视化编程（visual programming）替代传统 WebUI 的固定面板。用户通过拖拽连接「节点（nodes）」来构建生成流水线，就像搭积木一样——每个节点负责一个特定功能，节点之间的「连线（links）」决定了数据的流动方向。

2.2 安装方式概览

共 6 种安装方式（从最简单到最灵活排序）：

建议：新手用 Desktop 或秋叶整合包；开发者用 comfy-cli；没 GPU 用 Cloud。

方式一：ComfyUI Desktop（推荐新手）

  1. 访问 https://www.comfy.org/download
  2. 下载对应系统的安装包
  3. 安装后打开，内置模型管理器、节点管理器
⚠️ 目前 Beta 阶段，仅支持 Windows + macOS，Linux 暂不支持。

方式二：秋叶整合包（中文社区首选）

秋叶（秋葉aaaki）制作的整合包是中文用户最流行的 ComfyUI 分发包：

  1. 访问 B站秋葉aaaki 主页或百度网盘链接
  2. 下载整合包（含 ComfyUI + 常用节点 + 基础模型）
  3. 解压，双击 A绘师启动器.exe
  4. 在启动器中点击「一键启动」

方式三：comfy-cli（全平台推荐）

# 安装 comfy-cli
pip install comfy-cli

# 关闭数据收集
comfy --skip-prompt tracking disable

# 安装 ComfyUI（根据 GPU 选择）
comfy --skip-prompt install --nvidia    # NVIDIA CUDA
comfy --skip-prompt install --amd       # AMD ROCm
comfy --skip-prompt install --m-series  # Apple Silicon MPS

# 启动后台守护，默认端口 8188
comfy launch --background

# 验证
curl http://127.0.0.1:8188/system_stats

方式四：手动 Git 安装（高级）

git clone https://github.com/comfyanonymous/ComfyUI.git
cd ComfyUI
pip install torch torchvision torchaudio --extra-index-url https://download.pytorch.org/whl/cu124
pip install -r requirements.txt
python main.py --lowvram --preview-method auto

comfy node install comfyui-impact-pack         # 实用工具包

comfy node install comfyui-controlnet-aux      # ControlNet 预处理器

comfy node update all                          # 更新所有节点

3.3 队列与生成

  • 点击 Queue Prompt 或按 Ctrl+Enter 提交生成
  • batch count：一次生成多张图像
  • seed：固定种子可复现结果；randomize 每次不同
  • control_after_generate：fixed（固定）、increment（递增）、decrement（递减）、randomize（随机）
⚠️ 重要：ComfyUI 默认没有自动保存！请在 Settings 中设置自动保存间隔（推荐 2-5 分钟）。

工作流构建（基础）

4.1 文生图（Text-to-Image）— 最基础的工作流

这是 ComfyUI 的 "Hello World"，理解了这个就理解了核心原理。

节点结构

分步详解

  1. Load Checkpoint（加载检查点）：加载基础模型，输出 MODEL + CLIP + VAE 三路
  2. CLIP Text Encode（文本编码）：正面 prompt（positive）+ 负面 prompt（negative），分别编码为 conditioning
  3. KSampler（采样）：接收 MODEL + conditioning，输出 LATENT。核心参数：seed, steps, cfg, sampler_name, scheduler
  4. VAE Decode（解码）：将潜空间 LATENT 解码为像素 IMAGE
  5. Save Image（保存）：保存到 ComfyUI/output/

4.2 参数详解

Steps（步数）

模型推荐步数说明
SD 1.520-3020 步通常足够
SDXL20-3025 步平衡质量和速度
Flux Dev20-30对步数不敏感

⚠ Flux 特殊：Flux 使用 CFG 1.0-1.5！用 7-8 会得到完全损坏的输出！

核心节点详解

5.1 加载器（Loader）节点

CheckpointLoaderSimple（简单检查点加载器）

参数类型说明
ckpt_nameSTRING检查点文件名（从 models/checkpoints/ 中选择）

输出：MODEL（模型）→ 连接 KSampler / CLIP（文本编码器）→ 连接 CLIPTextEncode / VAE（变分自编码器）→ 连接 VAEDecode

Load LoRA（加载 LoRA）

参数说明
model (MODEL)要应用 LoRA 的基础模型
clip (CLIP)要应用 LoRA 的 CLIP
lora_nameLoRA 文件名
strength_model对模型的强度（0.0-1.0+）
strength_clip对 CLIP 的强度（0.0-1.0+）

5.2 条件（Conditioning）节点

CLIPTextEncode（CLIP 文本编码）

参数说明
text输入文本 prompt
clip (CLIP)来自 CheckpointLoader 或 LoRA 的 CLIP

输出：CONDITIONING → 连接 KSampler 的 positive/negative

💡 提示词技巧：负面 prompt 和正面同样重要。常用负面词：blurry, low quality, distorted, ugly, bad anatomy, extra limbs, mutated hands。

ControlNetApply（应用 ControlNet）

参数说明
conditioning (CONDITIONING)来自 CLIPTextEncode 的条件
control_net (CONTROL_NET)来自 Load ControlNet Model
image (IMAGE)ControlNet 的引导图像
strength控制强度 0.0-1.0
start_percent / end_percent控制作用阶段（如 0.0-0.5 只在采样前半段应用）

5.3 采样（Sampling）节点

KSampler（K 采样器）— 核心

参数类型说明
modelMODEL生成模型
seedINT随机种子（-1=随机）
stepsINT采样步数（推荐 20-30）
cfgFLOATCFG 引导尺度（推荐 7-8）
sampler_nameSTRING采样器算法
schedulerSTRING调度器策略
positiveCONDITIONING正面条件
negativeCONDITIONING负面条件
latent_imageLATENT潜空间图像（文生图=空）
denoiseFLOAT去噪强度（文生图=1.0）

避坑指南

9.1 10 大新手错误

❌ 错误 #1：不加载或加载错误的 VAE
现象：图像发灰、偏紫/绿色
解决：确保在工作流中正确连接 VAE 模型
❌ 错误 #2：忘记保存工作流
现象：辛苦搭建的工作流丢失
解决：频繁 Ctrl+S；在 Settings 中开启 Auto Save（2-5 分钟间隔）
❌ 错误 #3：Flux 使用错误的 CFG 值
现象：输出完全损坏、色彩异常
解决：Flux 用 CFG 1.0-1.5，绝对不是 7-8！
❌ 错误 #4：分辨率不匹配模型原生尺寸
解决：SD 1.5→512×512, SDXL→1024×1024, Flux→1024×1024
❌ 错误 #5：盲目复制工作流
解决：使用 Manager 的 "Install Missing Custom Nodes"；运行 comfy node install-deps --workflow=workflow.json
⚠ 错误 #6-10：自定义节点红色（缺少节点）、步数过多/过少、CFG 设置不当、种子管理混乱、忽略模型特定设置

9.2 显存问题

进阶技巧与最佳实践

10.1 工作流组织

  • 命名规范：给工作流取有意义的文件名：portrait_sdxl_photorealistic_v3.json
  • Group（群组）：选中节点 → Ctrl+G 打包，逻辑相关节点一目了然
  • Reroute（路由节点）：插入连线中间整理线路，保持画布整洁
  • Subgraph（子图）：将可复用的节点组合封装，像函数一样复用
  • Note Node（注释节点）：标记关键步骤和参数说明

10.2 5 分钟规则

在使用别人的工作流之前，花 5 分钟理解：

  1. 使用什么模型（checkpoint, LoRA, ControlNet）
  2. 使用了哪些自定义节点
  3. 数据从输入到输出的流动路径
  4. 关键参数设置（steps, CFG, sampler）
