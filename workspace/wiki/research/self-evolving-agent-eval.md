# 你缺的不是更多信息，而是一个会"自我进化"的AI Agent

**核心洞见**：收藏不是吸收。个人Agent的价值在于将外部信息从「我看过」推进到「我用上了」。

## 五步自我进化闭环

外部信息 → **Taste Filter** → **观点蒸馏** → **Memory写入** → **Skill更新** → **Eval反馈** → 系统更新

### 1. Taste Filter（品味过滤器）
5维度打分：相关性/当前价值/深度/可转化性/新鲜度（各1-5分）
- 20-25：精读蒸馏
- 15-19：快速阅读
- 10-14：暂存
- <10：丢弃

### 2. 观点蒸馏（三问法）
- 它改变了什么？
- 它能变成什么（Memory/Skill/素材）？
- 我接下来做什么？

### 3. Memory写入
写入条件（至少满足多数）：影响未来判断、与长期目标有关、反复出现、经过验证、能服务未来任务
**遗忘机制**：临时验证区→一周调用≥3次→正式写入

### 4. Skill更新
把反复有用的方法变成能力。像代码重构一样对待Skill更新。

### 5. Eval反馈
使用频率/输出提升/决策影响/复用价值/噪音程度→保留/修改/删除

## 五个失败模式
1. 过度过滤→错过跨界信息
2. Memory污染→严格执行写入规则
3. Skill僵化→像代码重构一样更新
4. 评估失真→用客观数据判断
5. 系统过复杂→宁缺毋滥

## 与我们已有的对比

| 本文 | 我们的对应 |
|-----|-----------|
| Taste Filter | 子产的需求判断 |
| 观点蒸馏 | 五人合议的产出提炼 |
| Memory写入 | 核战队技能进化（临时→正式） |
| Skill更新 | SKILL.md维护机制 |
| Eval反馈 | 萧何审计+核战队合议审计 |
| 遗忘机制 | **我们缺这个** |

**核心价值**：本文的「临时验证区→正式写入」机制是我们当前缺失的。核战队的技能进化目前是「一次写入永久生效」，应该引入「新Skill先进入试用期→被调用3次以上→正式固化」的机制。
