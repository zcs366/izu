# 多Agent vs 单Agent — 评估

## 一、核心论点

> 多Agent系统通过**系统边界划分**，将认知复杂度从 **O(C^N)降到O(N·C)**，并引入异构性打破局部最优——这是任何单Agent Prompt工程无法跨越的理论墙。

## 二、六个理论优势 × 核战队对照

| 理论 | 数学/形式化 | 核战队对应 |
|---|---|---|
| **注意力稀释** | 单Agent共享KV Cache → 角色污染 | 子产/韩信/鲁班/萧何/子贡各有独立上下文 ✅ |
| **优化景观分解** | O(C^N)→O(N·C)，局部最优密度指数下降 | 五人合议各审自己领域 ✅ |
| **认知独立性** | 同分布噪声的自举≠真正认知冲突 | 子产断需求、鲁班审工程——异构先验 ✅ |
| **角色承诺** | 架构硬编码vs提示词漂移 | 军师终裁制——物理隔离保证承诺 ✅ |
| **通信即计算** | Agent间通信等价于特征提取+信息瓶颈 | 合议流程=结构化通信协议 ✅ |
| **容错与鲁棒** | 错误率p→p^k（k个独立Agent） | 一个Agent误判不影响整体 ✅ |

## 三、边界条件——什么时候单Agent够用

| 条件 | 单Agent够 | 核战队场景 |
|---|---|---|
| 任务复杂度 | 低维、少步骤 | ❌ 高维、长程 |
| 角色异构性 | 通用助手 | ❌ 子产/韩信/鲁班/萧何/子贡互异 |
| 验证需求 | 可快速外部验证 | ⚠️ 部分可（代码运行），部分不可（战略判断） |
| 容错要求 | 低错误成本 | ❌ 高错误成本 |
| 上下文约束 | 短上下文 | ❌ 长上下文多轮 |

→ 核战队场景**全部落在多Agent必要区间**。
