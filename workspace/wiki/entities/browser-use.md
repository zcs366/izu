# browser-use

browser-use 是一个开源组织/团队，专注于AI驱动的浏览器自动化。旗下两个主要项目：

## 项目

- **browser-use/browser-use**：全功能AI浏览器Agent框架，基于Playwright + LLM + Agent三层架构。类似Django——开箱即用，功能全面。
- **[[browser-harness]]**：极简CDP直连工具，592行Python。类似裸socket——给LLM最大自由度，不走任何框架层。
- **browser-harness-js**：Browser Harness 的 JavaScript 版本。

## 核心理念

两个项目代表了两种相反的设计哲学：
- browser-use 主项目：精心设计的工具箱
- Browser Harness：给AI一根线，让它自己造工具
