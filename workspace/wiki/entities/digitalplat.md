# DigitalPlat

非营利组织，运营免费公共域名空间（`*.dpdns.org`、`*.qzz.io`、`*.us.kg`、`*.xx.kg`、`*.qd.je`）。

## 基本事实

- **创始人：** Edward Hsing（GitHub: EdwardLab），15岁开始做DNS实验
- **财政担保：** The Hack Foundation（EIN 81-2908499），501(c)(3)组织
- **赞助商：** GitHub、Twilio、1Password、Cloudflare
- **GitHub：** DigitalPlatDev/FreeDomain，162k+ Stars，AGPL-3.0
- **规模：** 已发放50万+域名
- **KYC：** GitHub OAuth 验证（授权 EdwardLab）
- **域名管理面板：** dash.domain.digitalplat.org

## 免费域名政策

- 新账号默认2个免费名额，邀请码+1，GitHub Star+1（最多4个）
- 有效期一年，到期前90天可免费续期
- Bring-your-own-DNS，可托管 Cloudflare
- US.KG 和 XX.KG 需付费，推荐 dpdns.org 和 qzz.io

## 风险评估

- ✅ 非营利背书真实（501c3 + 知名赞助商）
- ✅ 开源（AGPL-3.0），社区验证
- ⚠️ US.KG 曾全线崩溃（2025年底），虽很快恢复
- ⚠️ 本质是免费二级域名（子域名），非注册局域名
- ⚠️ 所有权不在用户手中，组织倒闭/改政策则域名失效

## 适用场景

适合学习、自用服务、临时项目。不适合对外正式网站或依赖域名稳定性的业务。
