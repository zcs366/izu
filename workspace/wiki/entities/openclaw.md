# OpenClaw

全球最火的开源 AI Agent 项目，在 GitHub 上已突破 **20 万星标**。定位是连接大模型和本地系统的"执行中枢"——给 AI 装上手和脚，能操作电脑、浏览器、文件系统。

## 核心特性

- **Skill 生态**：ClawHub 拥有 13000+ 技能（SKILL.md 格式），社区生态极为活跃
- **一键部署**：阿里云、腾讯云、字节火山引擎均提供一键部署
- **多平台消息**：支持 Telegram、Discord、微信（通过 ClawBot）、飞书等
- **浏览器自动化**：内置 Browser Automation，可控制浏览器执行爬取、填表等操作
- **自定义 Skill 开发**：每个 Skill 一个文件夹（SKILL.md），开发规范清晰

## 与 Hermes Agent 的关系

OpenClaw 与 [[Hermes Agent]] 同属开源 AI Agent 生态。Hermes Agent 在文档中提及 OpenClaw 的 ClawHub 作为技能共享平台参考。两者在 Skill 体系、多平台网关、浏览器操作等方向有相似的设计理念。

## 安全生态

ClawHub 上约 12% 的 Skill 存在安全问题。2026 年 2 月发现 341 个恶意技能。需安装 Skill Vetter 进行安全审计。
