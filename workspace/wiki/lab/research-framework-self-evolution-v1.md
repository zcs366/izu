# Agent自我迭代 · 研究框架

**日期**：2026-05-15 | **实验室**：izu前沿实验室 | **版本**：v1.0

## 框架总览

四个维度 × 八个子方向：

| 维度 | 子方向 | 核心问题 | 3月目标 | 6月目标 |
|------|--------|---------|---------|---------|
| **迭代什么** | 技能进化 | Agent的prompt能自己优化吗？ | 1个Skill跑通自优化 | 多个Skill并行进化 |
| | 记忆进化 | 学到的东西能变成行为规则吗？ | — | 1条自动编译的教训→规则 |
| | 角色进化 | Agent能发现更好的分工吗？ | — | 1个角色SKILL.md自动优化 |
| **何时迭代** | 失败驱动 | 做得不好能触发改进吗？ | 失败→诊断→进化自动链 | — |
| | 主动探索 | 没失败也能发现要改进吗？ | — | 1次Agent主动提案 |
| **怎么迭代** | 反思学习 | 能从输出中提取改进原则吗？ | 判官反馈是否改进矿工输出 | — |
| | 经验蒸馏 | 能从交互记录中提取模式吗？ | — | 100+对话→3条可复用模式 |
| **怎么验证** | 量化评估 | 怎么知道进化是进步还是退步？ | 人工评估一致率≥85% | 自动退化检测+回滚 |

## 优先级路线

```
第1-3周：反思学习 + 量化评估 → 建立评判能力
第4-8周：技能进化 + 失败驱动  → 跑通首个闭环
第9-16周：记忆进化            → 经验→规则
第17-24周：角色进化 + 主动探索 → Agent自主进化
```
