00:00 开场：搭一个 AI 工作团队

如果你能搭一个 AI 团队，帮你完成从信息筛选、内容审查，到多平台发布的全流程，你会怎么用它呢？今天我就带你从零搭建一个。

嗨，你好，欢迎回到 Axton。我们先让你来看一下这个系统搭建完成之后长什么样——这是我现在每周都在跑的一个真实的工作流。

今天的视频，我会带你从零搭建这一整套系统的起点。今天我会带你搭两样东西：

  1. Skills —— 写给 AI 的标准操作手册
  2. Agent —— 有明确职责的 AI 团队成员

如果你不懂编程，不用担心。我们全程用 Cursor 里边的 Claude Code 来操作，不需要写代码。

01:26 Claude Code 使用方式

三种使用方式：桌面端 app、终端窗口、Cursor 编辑器内。用 Cursor 可以看到项目文件结构 + Claude Code 对话界面，非常方便。

02:04 项目初始化：创建 CLAUDE.md

项目结构：context/（基础资料）、template/（模板）、article/（待处理文章）。

CLAUDE.md 是给 AI 团队的入职手册。初始化的方式是在 Claude Code 对话框输入 -init，等待自动生成。

03:07 安装官方 Skill

输入 /plugin 添加 Anthropic 官方 Skill 仓库。最需要安装的是 Skill Creator——用来创建和优化 Skills 的元技能。

04:03 搭建第一个 Skill：内容审查

双模型交叉审查——Claude 看逻辑结构，Gemini 看事实风格。覆盖更全面。

关键：把审查标准写下来（逻辑自洽、事实可验证、语气一致、AI 味等），让 AI 有章可循。

08:04 搭建第二个 Skill：微信发布

通过 MCP 协议（AI 与外部工具的桥梁）连接 Make（自动化平台），实现自动发布到微信公众号。

09:37 先搭 Skills 再搭 Agents

先定流程，再配人——顺序不能搞反。Skill 是你脑子里的流程变成了 AI 可以执行的标准操作手册。

10:54 搭建 Agent：Publisher

在终端用 /agents 命令创建。手动配置：名称 → System Prompt → 触发条件 → 工具 → 模型 → 颜色 → 记忆范围。

创建后需手工在 agent.md 的 runtime_tools 中添加引用的 Skills。

测试：一篇文章先过 content_review 审查，通过后 wechat_publish 发布，成功推送到公众号草稿箱。

15:38 搭建第二个 Agent：社交互动

不装备任何 Skill，用 Claude 基础能力把长内容转换成推文。触发词："写条推文""帮我发个推"。

17:37 两种 Agent 对比

Publisher 装备两个 Skill 走完整流水线；Social Voice 靠基础能力干活。根据任务复杂度决定配置方式。

19:13 结语

搭一个真正有效的系统需要：心智（判断工作流）、架构（灵活替换组件）、提示词（精准沟通）、系统（组装能力）。这也是《重构个体》一书的完整路径。
