# ClawHub

[[OpenClaw]] 生态的 Skill 市场和共享平台，拥有 **13000+ 个技能**。Skill 以 SKILL.md 格式定义（YAML 元数据 + Markdown 说明）。

## 安全风险

约 12% 的 Skill 存在安全问题。2026 年 2 月发现 **341 个恶意技能**。推荐使用 Skill Vetter 进行安全审计后再安装。

## 与 Hermes Agent 的关系

[[Hermes Agent]] 的技能系统也兼容 agentskills.io 标准，并通过 Skills Hub 支持社区贡献，与 ClawHub 的设计理念相似。
