# Claude永久记忆

Anthropic为Claude Cowork注入的持久化知识存储能力。Claude不再依赖混乱的通用记忆，而是让用户管理多个清晰、独立的知识库。

## 核心能力
- 持久化的知识存储库，主动检索相关背景信息
- 在交互过程中逐步学习和补充知识
- 用户可手动选择用哪个知识库作为上下文

## 行业背景
硅谷共识：2026年将是"持续学习之年"。谷歌DeepMind推出递归语言模型、Titans、Atlas架构和嵌套学习。Sam Altman称"AI真正的突破是完整的记忆能力"。
