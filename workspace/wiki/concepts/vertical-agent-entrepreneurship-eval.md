# 评估：垂直AI Agent创业趋势

## 核心主张

2025-2026 是 Agent 时代，通用 Agent 是大厂的游戏，普通人应聚焦垂直领域做 Agent。核心观点三条：①巨头垄断通用Agent → 垂直是出路；②Agent适合复杂多变的任务 → 比Workflow灵活；③基础设施成熟 → 门槛降低，行业理解 > 技术能力。

## 核实

| 文章声称 | 核实结果 | 证据 |
|---------|---------|------|
| 2025-2026是Agent时代 | ✅ 行业共识 | Forbes、Gartner（40%企业应用将集成Agent by 2026）、Salesforce CIO研究 |
| 通用Agent是巨头游戏 | ✅ 属实 | OpenAI Deep Research、Google Gemini Agent、国内大厂的投入规模 |
| 基础设施成熟、门槛降低 | ✅ 属实 | API调用即用、LangChain/CrewAI/AutoGen等框架成熟 |
| 垂直领域机会在法/医/教/金 | ⚠️ 方向对但泛 | 每个领域都有确实的Agent创业案例，但文章未给任何具体案例或数据 |
| 行业理解 > 技术能力 | ⚠️ 部分正确 | 对非技术产品型创业者成立；但对需要深度Agent工程化的场景，技术壁垒仍然高 |

## 定论

一篇及格线以上的趋势科普。框架正确，有基本判断力，没有过度鼓吹。但缺乏：
- 具体案例（只在结尾提了个"离婚财产分割文书起草Agent"的假设例子）
- 数据支撑（市场规模、增长率、竞争格局全无）
- 差异化分析（垂直Agent和传统SaaS的本质区别是什么？Agent的护城河在哪？）

**适合谁看：** 对AI Agent创业有兴趣但缺乏方向感知的人，当作入门认知地图。

**不适合谁看：** 已经在做Agent的人——这篇文章不会告诉你任何你不知道的事。

## 对张成市的价值：⚠️ 参考有限

你已经在一个垂直领域深耕了——用 Agent 做知识工作（wiki流水线、深度研究、内容生成）。这篇文章说的"垂直Agent机会"，对你来说是**已知方向**而不是新发现。

更值得你思考的不是"要不要做垂直Agent"，而是：
1. **你的护城河在哪？** 如果"行业理解"就是护城河，那你的知识工作Agent管线（wiki + 深度研究 + 自动化）的独特价值是什么？
2. **从自用到产品**——你现在是为自己做工具，但如果有一天要产品化（比如给洁琼的事业做Agent方案），需要补什么？
3. **Agent vs Workflow 的边界**——你用 Hermes 做的是高度Agent化的流程，但哪些环节其实Workflow就够了（节省token、更稳定）？

## 一句话

文章说的是对的，但对你的助益不大——你已经在做它建议的事了。比起看这类趋势文，不如多研究具体竞品（OpenHands、Devin、Claude Code 的架构选择）来得实在。
