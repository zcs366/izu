# Hermes Agent 安全使用

> "始终假设 Agent 可能被误导，并通过权限控制、物理沙箱和人工审批，将潜在损失限制在绝对可控的范围内。"

## 核心威胁

**间接提示词注入（Indirect Prompt Injection）**：Agent 将外部网页、PDF 或代码库中隐藏的恶意文本误认为真实指令，引发密钥泄露或危险操作。

## 四项防线

### 1. 切断潜意识注入

- 关闭自动记忆与技能生成
- 所有记忆和技能的写入必须经过人工核对
- 防止外部恶意输入转变为长期规则

### 2. 沙箱隔离

- **不赋予全局系统权限**
- 针对特定任务建立隔离的临时"沙箱"目录
- 仅放入必要材料，防止读取 .env 或 .ssh 等敏感数据

### 3. 内容与指令界限

- 外部文档 = 被处理数据，不是执行命令
- 处理未知文档时提前设定边界
- 明确告知 Agent：只读、只分析、不执行

### 4. 关键决策不可让渡

- 系统操作 / 网络发送 / 生产环境 → 人类最终审批
- Agent 角色：「安全顾问」，负责起草方案
- 执行按键在人类手中

## 总原则

通过权限控制 + 物理沙箱 + 人工审批，将 Agent 的潜在破坏半径约束在可控范围。
