# Agent 三阶段演进论

[[老朱]] 提出的 AI Agent 演进框架，认为 2025-2026 年的 Agent 爆发并非简单升级，而是三次方向明确的跃迁：Claude Code→OpenClaw→Hermes，分别回答"能不能做难事"、"能不能被广泛使用"、"能不能越用越懂你"三个递进问题。^[raw/articles/agent-three-evolution-stages.md]

## 三阶段总览

| 阶段 | 代表产品 | 核心贡献 | 角色类比 |
|------|---------|---------|---------|
| **第一阶段** | Claude Code | 定义 Agent 的能力天花板 | 技术专家 |
| **第二阶段** | OpenClaw | 推动 Agent 的大众普及 | 执行助理 |
| **第三阶段** | Hermes | 开启 Agent 的成长性与连续性 | 项目经理/合伙人 |

三者关系不是替代，而是递进：**能做 → 好用 → 越用越强**。^[raw/articles/agent-three-evolution-stages.md]

## 第一阶段：Claude Code — 能力天花板

**回答的问题：** Agent 能不能承担高复杂度任务？

Claude Code 证明 Agent 可以接手"完整工程"——理解复杂项目结构、持续上下文工作、修改已有代码、调试修复、沿完整开发链路推进。它让技术门槛被重新定义。

**但局限性：** 上手门槛偏高，更适合技术场景，对普通用户不够亲和，使用方式偏"专家工具"。

## 第二阶段：OpenClaw — 大众普及

**回答的问题：** Agent 能不能进入普通人的日常？

OpenClaw 降低了使用门槛，提高了可接入性，强化了"日常可用性"。让 Agent 从"技术玩具"变成"办公工具"，第一次让普通人觉得"Agent 和我有关"。

**但局限性：** 不记历史、不长记性，每次都是重新开始，没有"熟练度"概念。

## 第三阶段：Hermes — 成长与连续性

**回答的问题：** Agent 能不能形成长期能力与个性？

[[Hermes Agent]] 尝试把"执行过程"变成"可沉淀能力"。它会逐渐熟悉你的工作模式、形成自己的模板与优化方式、纠正后贴近你的表达习惯。你不再是"调用工具"，而是在"训练一个系统"。

更像一个**实习生**：一开始需要指导 → 做几次后开始熟练 → 再往后能主动优化 → 最终形成自己的工作方法。^[raw/articles/agent-three-evolution-stages.md]

## 核心启示

### 三者的终极解析

- **Claude Code = 技术上限**
- **OpenClaw = 使用下放**
- **Hermes = 自主进化**

### 未来趋势：多 Agent 协作生态

未来很可能不是某一个 Agent 一统天下，而是"多 Agent 协作生态"——不同的 Agent 各自长出边界与性格：^[raw/articles/agent-three-evolution-stages.md]

- **Claude Code 类** — 负责最复杂的技术实现
- **OpenClaw 类** — 负责最广泛的执行落地
- **Hermes 类** — 负责长期陪伴与成长

### 人的角色转变

工作方式：从手动 → 半自动 → 自动
协作方式：人+工具 → 人+Agent团队
人与工具的关系：使用 → 管理 → 共事

关键建议：不要急着判断谁会赢，先学会如何和它们一起工作——把任务拆清楚、表达目标而非步骤、学会复盘与反馈、建立长期协作关系。
