# last30days-cn 搜索聚合工具

零 API Key 的多平台搜索聚合工具，v2.0 版本支持 7 个平台白嫖搜索。

## 核心改进

v1.0 的 8 个平台中有 4 个需要 API Key（微博、小红书、抖音、微信），配置门槛高。
v2.0 通过模拟浏览器请求替代 API，实现**零 Key 搜索**。

## 当前能力

- 不写死 API Key
- 7 个主流平台搜索
- 自动解析各平台返回结果
