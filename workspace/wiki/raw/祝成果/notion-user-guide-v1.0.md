# Notion 用户操作指南 v1.0

> **一句话说清：** Notion 就像一个「万能积木盒」——你可以用它记笔记、管项目、建知识库、做团队协作，所有东西都在一个地方，不用在不同 App 之间来回切换。

---

## 第一章：Notion 是什么？（用三个类比理解）

### 类比一：乐高积木

Notion 里的每个内容——一段文字、一个标题、一张图片、一个表格——都是一块「积木」（Notion 叫它 **Block**）。你可以随意拼搭、拆开、换位置、改变形状。

普通文档软件给你的是「固定模板」，Notion 给你的是「一箱积木，你自己设计」。

### 类比二：一个可以自己装修的公寓

| 你在公寓里做的事 | 在 Notion 里对应的功能 |
|:---|:---|
| 在墙上贴便签 | 写一个 **Page（页面）** |
| 在客厅放一个书架 | 建一个 **Database（数据库）** |
| 在厨房贴菜单 | 用 **Template（模板）** |
| 跟室友一起打扫 | 用 **Team（团队协作）** |
| 把重要文件锁在抽屉里 | 设置 **Permission（权限）** |

### 类比三：瑞士军刀

别的工具是一把刀切一种东西——Word 写文档、Excel 做表格、Trello 管项目、Wiki 做知识库。Notion 是一把瑞士军刀，上面有所有这些功能，你只用一把工具就行。

## 第二章：三分钟快速上手

### ⭐ 三步走

```
第一步：注册账号 → notion.so 免费注册
第二步：建第一个页面 → 点 "New Page"
第三步：添加内容 → 打字就是文字，/todo 是待办
```

### 🖱️ 不用记命令，敲斜杠 `/`

Notion 最神奇的地方：**在空白处按一下 `/` 键**，就会弹出一个菜单，里面列出了所有你能添加的东西：

| 你打 | 出现 |
|:---|:---|
| `/text` | 普通文字段落 |
| `/h1` `/h2` `/h3` | 大/中/小标题 |
| `/todo` | 待办清单（复选框） |
| `/bullet` | 符号列表 |
| `/num` | 编号列表 |
| `/img` | 图片 |
| `/table` | 简单表格 |
| `/db` 或 `/database` | 数据库（最重要的功能！） |
| `/callout` | 高亮提示框 |
| `/code` | 代码块 |
| `/divider` | 分隔线 |

**记住一个快捷键就够了：`/` → 挑你要的。**

## 第三章：常见场景——一张卡片一个用法

### 🟢 场景一：记笔记（像用 Word 一样简单）

📝 新建页面，直接打字。就像打开一个空白 Word 文档。可以粘贴图片，可以拖拽调整段落顺序。
💡 试试 `/callout` 做重要提醒，`/toggle` 做折叠内容。

### 🟢 场景二：管任务清单

在任意位置输入 `/todo`：
```
☐ 买菜
☑ 接孩子放学
☐ 交水电费
```
点击 ☐ 变为 ☑ = 做完打勾 ✔。

### 🟢 场景三：建知识库（给家庭或团队用）

建一个页面叫「家里的事」，下面是几个子页面：
- 📄 证件资料（身份证、房产证）
- 💊 全家病历
- 🍳 菜谱收藏
- 💰 家庭账本

### 🟢 场景四：管理项目

用数据库管理「正在做的事」。视图切换：
- 📋 表格 → 像 Excel 一样看全部
- 🗂️ 看板 → 像 Trello 一样拖卡片
- 📅 日历 → 按时间看截止日
- 📍 时间线 → 看项目排期

一个数据库，四种看法，随时切换。

### 🔴 常见卡住的情况

| 卡住了 | 怎么办 |
|:---|:---|
| 想不起快捷键 | 按 `/`，菜单里全部都有 |
| 内容乱了 | 鼠标拖拽左边的 ⋮⋮ 图标调整顺序 |
| 不小心删了 | Notion 右上角 ⋯ → **Page history** 可以恢复 |
| 想搜索 | `Ctrl/Cmd + P` 全局搜索 |
| 想分享给别人看 | 右上角 **Share** → 生成链接 |

## 第四章：Notion 的「杀手锏」——数据库

数据库是 Notion 最强大的功能，也是理解它为什么「不是普通笔记软件」的关键。

### 数据库 = 有结构的笔记

普通笔记：就像一张白纸，写什么是什么。

数据库笔记：像 Excel 表格 + 白纸的结合体。每条笔记有固定的「字段」：
- 名称 / 状态（✅完成/🔄进行中/⏳未开始）/ 截止日期

每条记录点进去，又是一张完整的白纸！

### 四种视图——同一条数据，不同看法

同一个「读书数据库」：
- **📋 表格视图**：所有书一列排开（书名 | 作者 | 状态 | 评分）
- **🗂️ 看板视图**：按「状态」分组（未读 / 在读 / 读完）
- **📅 日历视图**：按「读完日期」排布
- **📍 时间线**：看什么时候读了什么

## 第四章.五（补充）：Notion AI

2023 年起，Notion 加入了 AI 功能。它像个「住在你笔记本里的助手」：
- **帮我写**：输入一个标题，AI 帮你生成内容大纲或初稿
- **改写法**：选中文字，让 AI 润色、缩短、翻译
- **自动填充**：在数据库里，AI 可以帮你自动填字段
- **问答**：问「我们上周的会议说了什么？」AI 在你自己的笔记里找答案

> ⚠️ **注意**：AI 功能需要付费（$10/月 附加到个人计划上）。不买也不影响使用核心功能。

## 第六章：FAQ（用你的口吻问）

**Q：Notion 要钱吗？**
A：免费版够个人用了——可以建无限数量的页面，支持 7 天历史记录。付费版（$10/月）加 AI 和无限历史。

**Q：跟 Obsidian 比哪个好？**
A：Obsidian 是本地 Markdown 文件，全离线，插件生态强，适合深度笔记玩家。Notion 是云端、更全能、更适合团队协作和项目管理。**如果你想要「一个工具管所有事」→ Notion。如果你想要「纯笔记工具，本地安全可控」→ Obsidian。**

**Q：中文支持好吗？**
A：Notion 有中文界面（设置里可切换）。但一些模板和社区资源还是英文为主。日常使用没问题。

**Q：能离线用吗？**
A：客户端有一定离线能力，但 Notion 本质是云端工具。没网的时候功能受限。

**Q：数据安全吗？**
A：Notion 用 AWS 云服务，有加密传输和存储。但作为云端产品，如果非常在意隐私，需要注意 Notion 员工可以访问你的数据（虽然有限制）。

**Q：我孩子/家人不会用怎么办？**
A：如果是「看」不用教——分享链接给他们就能看。如果是「编辑」，给他们一个简单的界面（比如一个看板或者一个表格），告诉他们「点这里加一行」就够了。

## 附：Notion 中英文对照表

| 中文 | English | 一句话说 |
|:---|:---|:---|
| 页面 | Page | Notion 的基本单位，像一个文件夹+文档 |
| 积木/块 | Block | 页面里的每一个元素（文字、图片、表格...） |
| 数据库 | Database | 有结构的页面集合（类似 Excel 但更强） |
| 属性 | Property | 数据库里的字段（如：日期、状态、标签） |
| 视图 | View | 同一条数据的不同展示方式 |
| 模板 | Template | 预设好的页面结构，省得每次都从头搭 |
| 工作区 | Workspace | 你的全部 Notion 内容（可以分多个） |
| 团队空间 | Teamspace | 专门给团队用的共享区域 |
| 集成 | Integration | 把 Notion 连到其他工具（如日历、Slack） |
| 关联 | Relation | 数据库之间的连线关系 |
