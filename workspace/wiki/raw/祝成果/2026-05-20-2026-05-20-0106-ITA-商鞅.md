# 商鞅 — 实验设计官

## 最小可行实验（20工时）

### 实验 1: CodeBERT Round-Trip 一致性基线测试（8工时）
- **目标**: 回答「现有 CodeBERT 模型在代码压缩-解压缩的 round-trip 中保留了多少语义？」
- **方法**:
  1. 取 CodeBERT (125M) 在 CodeSearchNet 的验证集（2000个函数）
  2. 对每个函数 C，获取隐表示 h(C) = CodeBERT.encoder(C)
  3. 用 PCA/SVD 将 h(C) 降至 d 维（d ∈ {64, 128, 256}）
  4. 从降维表示重建：C' = CodeBERT.decoder(PCA_inverse(h_pca))
  5. 对比 C 和 C' 的：(a) BLEU (b) 执行等价性 (c) CodeBLEU
- **成功/失败标准**: 
  - 通过：降维至 128 维后执行等价性 ≥ 85%
  - 失败：降维至 256 维后执行等价性 ≤ 70%
- **工具**: CodeBERT + HuggingFace transformers，已有代码无需额外训练

### 实验 2: FSQ vs VQ-VAE 代码隐空间量化对比（8工时）
- **目标**: 验证 FSQ 在代码上的码本利用率是否优于 VQ-VAE
- **方法**:
  1. 用 CodeBERT 的中间层表示作为代码隐向量（512维）
  2. 分别训练 FSQ (codebook size=512, n_channels=8) 和 VQ-VAE (codebook size=512, dim=64)
  3. 对比：(a) 码本利用率 (b) 重建困惑度 (c) 压缩率 vs 语义保留率曲线
- **成功/失败标准**:
  - 通过：FSQ 码本利用率 ≥ 95% 且 VQ-VAE ≤ 60%
  - 失败：两者差距 < 20%

### 实验 3: Activation Steering 代码补全影响测试（4工时）
- **目标**: 测试 steering vector 能否定向改变代码补全行为
- **方法**:
  1. 选取两个简单目标：生成"安全"vs"不安全"的 SQL 查询
  2. 用 50 个样本训练 activation steering vector（差向量法）
  3. 测试 100 个 prompt 的 steering 效果
- **成功/失败标准**:
  - 通过：steering 后目标属性偏移 ≥ 30%
  - 失败：偏移 < 10%
