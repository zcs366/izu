# 韩信·技术远景：Pulse Forget 协议 v1.0

## 3-6个月终局画像：izu Memory Protocol (Pulse Forget)

### 架构核心
- **遗忘决策引擎**：遗忘曲线(Ebbinghaus) + 冲突检测双信号 → 保留/压缩/遗忘三选一
- **观测压缩**：Observer+Reflector双进程（参考Mastra OM架构）
- **原子化CRUD**：Forget作为一等公民的API操作
- **RL可学习遗忘**：规则给初始值，RL调优触发策略（参考Memory-R1/AtomMem）

### 需要纳入的新技术
1. RL可学习遗忘（Memory-R1/AtomMem）
2. 观测型压缩（Mastra OM Observer+Reflector）
3. 原子化CRUD+Forget API

### 推迟纳入的技术
1. 城市数字孪生交叉（3-6月后）
2. 多Agent记忆（单Agent先站稳）

### 与竞品差异化
- Mem0做软重排（decay weights），不做硬遗忘
- Mastra做压缩不做遗忘
- Supermemory有forget API但无决策算法
- **izu唯一做：遗忘曲线+冲突检测→主动遗忘决策**
