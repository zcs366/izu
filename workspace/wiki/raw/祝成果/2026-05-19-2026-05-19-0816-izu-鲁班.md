# 鲁班 — 工程可行官

## 核心结论：能做。可做。该做。

### 关键风险矩阵

| 风险 | 等级 | 缓解方案 |
|------|------|---------|
| **时间风险**：2周FSQ + 4周原型 → 6周preprint | 🟡 中等 | FSQ核心~100行，可学习化是关键 |
| **原创性风险**：LADS (ICLR 2025) 概念相似 | 🟠 高 | 差异化：FSQ vs VQ + LLM agent vs robot RL + 持续更新 |
| **命名冲突**：H-MEM | 🔴 高 | **必须更名**（建议C-MEM / PSQ-Mem / PlanCache） |
| **APC最强竞品压制** | 🟡 中等 | 证明FSQ码本语义泛化性 > APC keyword匹配 |
| **可学习FSQ技术可行性** | 🟢 低 | 已有Soft-to-Hard方案（Gumbel-Softmax, STE） |

### 必造组件
1. **Learnable FSQ Quantizer**（D=4~8, L=5~8）
2. **Plan Trajectory Encoder**（变长序列 → 低维向量）
3. **Code-Semantic Alignment Module**
4. **四层层级码本架构（更名C-MEM）**
5. **持续学习/码本更新机制**
6. **BEAM Plan Cache评测扩展**
