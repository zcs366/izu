# Phase 0 — 三路搜索

## ITA轨道：世界模型能否实现因果推理 → FSQ代码隐空间压缩

**选题演变**: 从因果推理概念澄清 → 聚焦FSQ-VAE vs VQ-VAE在代码语义保真度上的实证对比

**核心洞察**:
- "世界模型"存在四种互竞定义（内部动力学/外部模拟器/基础世界模拟器/认知世界模型），因果推理能力高度依赖所选定义
- Pearl因果阶梯L1-L3不可互相还原，当前LLM主要停留在Level-1（因果知识检索）
- 核心争议归结为"涌现 vs 架构"：因果推理能否从预测训练中涌现，还是必须显式设计
- 最终聚焦为：FSQ均匀网格在代码隐空间上能否达到VQ-VAE学习码本的语义保真度

**研究工具**: 率失真理论 + HumanEval 164题 + ModernBERT-base + cos_sim度量

## izu轨道：AI Agent自愈基础设施 → Pulse Forget记忆遗忘引擎

**选题演变**: 从SRE自愈基础设施 → AI编程ROI预测 → 失败模式分类 → 记忆遗忘引擎

**核心洞察**:
- 70% SRE on-call倦怠，但痛点不是"太累"而是"被打扰太多"——MTTR降低30%即每年少被打扰200+次
- 失败模式分类最有长期价值（模型无关的能力边界地图），优于快照式ROI预测
- AI合成数据导致Model Collapse有Nature实证，但合成≠退化的前提武断
- 最终聚焦：Pulse Forget记忆遗忘引擎——用Ebbinghaus衰减曲线主动压缩AI Agent的工作记忆

**关键假设**: 用户痛点是"记太多"而非"记不住重要的"——张仪指出这可能是错误的问题定义

## 核战队：全局视角

**核心发现**:
- 两轨共享底层问题：AI系统的可控性与可观测性
- ITA研究"责任归谁"（法理层），izu研究"怎么提前发现出事"（工程层）
- Agent可靠性问题即劳动力替代的前提条件——60-90%可靠性不够替代人类，但已足以辅助增强
- 两轨最大共同盲区：未质疑LLM作为度量工具的有效性（"裁判即被告"问题）
