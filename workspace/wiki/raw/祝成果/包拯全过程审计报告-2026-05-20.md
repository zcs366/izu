#### 🔴 实际Round-Trip验证失败

```
python -c "ITAEncoder().encode('def add(a,b): return a+b')"
→ RuntimeError: expected scalar type Half but found Float
```

**原因**: encoder.py第114行 `torch_dtype=torch.float16`（CUDA下加载ModernBERT为半精度），但projection层（第236行forward）的Linear层默认float32，类型不匹配。

**包拯断案**: 273个测试通过说明工程基建好，但**4个失败直击核心功能**——训练管线和非mock解码。更致命的是，纯非mock编码→解码路径不通（dtype不匹配），这意味着**整个管线的端到端链路是断的**。mock模式通过不代表真实功能可用。
