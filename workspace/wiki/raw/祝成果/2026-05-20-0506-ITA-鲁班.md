# 鲁班 · 工程可行性（在理论约束内）

## 理论约束确认
墨子验证：理论下界不排除99%语义精度的可能。目标可行。

## 技术方案

### 方案A：CodeBERT + FSQ（最轻量，推荐）
```
工具链：
- 模型：CodeBERT（~125M参数，能用CPU跑）
- 量化：纯numpy实现FSQ（无依赖）
- 测试：HumanEval + MBPP公开测试用例
- 代码量：~300行Python

架构：
code → CodeBERT → 768dim vector → FSQ(4bits/dim) → 3072bits
                                                       ↓
                                           重构：0填充→反量化→768dim float
                                                       ↓
                                           KNN在原始隐空间中搜最近邻
                                                       ↓
                                           用最近邻测试用例验证

约束满足：
- 不超过墨子理论约束 ✓（4 bits/dim在理论可行范围内）
- 不依赖GPU ✓（CodeBERT推理很快，批次处理）
- 所有组件开源 ✓（HuggingFace transformers + numpy）
```

### 方案B：SAE + 语义方向提取（进阶，如需更高精度）
```
- 用SAE分解CodeBERT表示（参考arXiv:2510.02917方法）
- 识别代码正确性方向 → 只压缩"语义重要"维度
- 非语义维度丢弃（进一步压缩）
- 约束：需要训练SAE（~10小时GPU）
```

### 不满足理论约束的情况
无。本方案在墨子确认的理论约束内。

## 潜在工程问题
1. CodeBERT的输出是768维连续值 → FSQ需要知道每维的范围（用对数变换或极值统计）
2. KNN搜索O(n) → 数据集≤1000个样本时没问题，>10K需要建索引
3. 测试用例覆盖完整性 → 用HumanEval的预置测试 + 对MBPP用被测代码自身的测试

## 结论
**可行。** 方案A可在纯CPU环境、20工时内完成。无超额工程开销。
