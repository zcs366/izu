# 商鞅 · 实验设计

## 最小可行实验：CodeBERT round-trip一致性测试

### 目标
用≤20工时验证两个核心问题：
1. Transformer代码隐空间的语义维度是否远小于768？
2. FSQ量化到4 bits/dim能否保持语义保真度 ≥ 90%？

### 实验设计

**Phase A：基线测量（6工时）**
```
输入：HumanEval（164题）+ MBPP（500题）代码
模型：CodeBERT（base，12层，768维）
步骤：
1. 对每个代码，提取最后隐层表示（pooled = mean pooling）
2. 反向：用KNN在隐空间中找最近邻代码
3. 交叉测试：用最近邻代码的测试用例验证
输出：基线精度 → 隐空间语义最近邻的行为等价准确率
成功标准：≥80%表示隐空间已有语义组织
```

**Phase B：FSQ压缩（10工时）**
```
步骤：
1. 对768维隐向量，每个维度量化到{0,1,2,...,15} = 4 bits/dim
2. 总压缩率 = 4x768 / (32x768) = 12.5%（相对float32）
  或 = 4x768 / (16x768) = 25%（相对float16）
3. round-trip：量化→反量化→KNN找最近邻→交换测试用例
4. 与Phase A的基线精度对比
成功标准：精度下降 ≤ 10%
```

**Phase C：维度消融（4工时）**
```
对Phase B中精度下降 > 10%的情况：
1. 用PCA压缩隐空间到{16,32,64,128}维
2. 在每个低维空间重复Phase B的FSQ量化
3. 找到"精度不降的临界维度" → 语义流形本征维度
```

### 成功/失败判断标准
| 结果 | 含义 | 行动 |
|------|------|------|
| 精度下降 ≤ 5% | FSQ+代码语义高度兼容 | 进入工程化 |
| 精度下降 5-15% | 需要iFSQ或自适应量化 | 修改方案 |
| 精度下降 > 15% | 代码语义不能用简单量化 | 回退，重回概念定义 |
| Phase B任何结果下维度消融显示本征维度 ≤ 64 | 语义流形低维 | 支持理论假设 |

### 总工时：20工时
- Phase A: 6工时（含环境搭建2工时）
- Phase B: 10工时（含FSQ实现2工时）
- Phase C: 4工时（含PCA+消融）
