## 1. Obsidian 是什么？一句话 + 一个比喻

**一句话**：Obsidian 是一个装在你自己电脑里的知识笔记软件，用纯文本存你写的每一句话，然后用「链接」把这些话串成一张知识网。

**一个比喻**：想象你书房里有一摞空白卡片（每张卡片就是一个笔记），Obsidian 就是给你一个无限大的白板，让你把卡片贴上去、用毛线串起来、随时抽出来改写——而且这些卡片永远是你自己的，不会被任何人锁起来。

## 2. 三分钟上手：三步走

### 第一步：下载并打开

| 你的电脑 | 去哪下载 |
|---------|---------|
| Windows | [obsidian.md](https://obsidian.md) → 点大的 Download 按钮 |
| Mac | 同上，选 macOS 版本 |
| iPhone/iPad | App Store 搜「Obsidian」 |
| 安卓 | Google Play 搜「Obsidian」 |

> 💡 **不用注册账号，不用绑定手机**。下载完双击就能用。

### 第二步：创建一个「仓库」(Vault)

打开 Obsidian 后，你会看到：

```
┌─────────────────────────────────────┐
│  欢迎来到 Obsidian                  │
│                                     │
│  [打开已有仓库]    [创建新仓库]      │
│                                     │
│  仓库就是你的笔记本合集              │
└─────────────────────────────────────┘
```

点「**创建新仓库**」→ 选一个文件夹（比如 `D:\我的知识库`）→ 完成。

> 💡 **"仓库"就是你的笔记本总文件夹**。里面放的所有 `.md` 文件都是你的笔记。

### 第三步：写第一条笔记

```
┌─────────────────────────────────────┐
│  ✏️ 未命名笔记                       │
│─────────────────────────────────────│
│ # 我的第一条笔记                     │
│                                     │
│ 你好，Obsidian！                    │
│                                     │
│ 今天学到了 [[双向链接]] 这个概念。    │
│ 它有点像 [[维基百科]] 里的超链接。    │
└─────────────────────────────────────┘
```

> 💡 `[[双向链接]]` 是 Obsidian 最核心的功能——**用双括号括起来的词会自动变成可点击的链接**，点一下跳转到那篇笔记。

**写完之后**：按 `Ctrl+S` 保存。Obsidian 会自动把文件存成 `.md` 格式，存在你刚才选的文件夹里。

## 3. 常见情况卡片

### 📘 "我卡住了——怎么建链接？"

| 你想做什么 | 怎么做 |
|-----------|--------|
| 链接到另一篇笔记 | 打两个 `[[` → 开始打字 → 选已有的笔记 |
| 链接还没写的笔记 | 打 `[[还没想的想法]]` → 点一下 → 自动创建新笔记 |
| 链接到互联网网址 | 直接打 `https://...` → 自动变可点击 |

### ✅ "写完了，怎么整理？"

```
左侧边栏（文件列表） → 拖拽笔记到文件夹
左下角（标签面板） → 给笔记加 #标签
```

### ➕ "想装个新功能"

点左侧 **设置（齿轮图标⛭）** → **第三方插件** → **关闭安全模式** → **浏览社区插件市场** → 搜索 → 安装 → 启用

> 💡 **装完不会搞坏你的笔记**。插件只是增加功能，你的原始 `.md` 文件动都不会动。

### 🔴 "不小心删了笔记"

去你电脑的回收站（Windows 回收站 / Mac 废纸篓）找。因为 Obsidian 的所有笔记就是普通文件，回收站能救回来。

### 🗣️ 不想动手想用嘴说

> **"军师，帮我建一个 Obsidian 仓库，叫「我的知识库」，放在 D 盘根目录，里面先建三个文件夹：读书笔记、项目记录、随手想法。"**

## 4. 可视化：Obsidian 怎么工作的？

```
┌─────────────────────────────────────────────────────────┐
│                   你的 Obsidian 世界                      │
│                                                         │
│  ┌──────────┐    ┌──────────┐    ┌──────────────────┐  │
│  │ 你的电脑  │    │  .md文件  │    │  Obsidian 软件   │  │
│  │ (本地存储)│◄──►│(纯文本格式)│◄──►│ (阅读+编辑引擎)  │  │
│  └──────────┘    └──────────┘    └──────────────────┘  │
│       │                                  │              │
│       │ 永不锁死                         │ 加功能       │
│       ▼                                  ▼              │
│  ┌───────────────────────────────────────────────┐      │
│  │  其他任何文本编辑器（记事本、VS Code、Typora）    │      │
│  │  都能打开你的 .md 文件                           │      │
│  └───────────────────────────────────────────────┘      │
│                                                         │
│         🔑 核心：你的数据永远属于你、永远可读            │
└─────────────────────────────────────────────────────────┘
```

**关键理解**：Obsidian 只是一个"阅读器+编辑器"。你的笔记本身是纯文本文件，放在你的硬盘上。就算 Obsidian 公司明天倒闭了，你所有的笔记在任何文本编辑器里都能打开。

## 6. FAQ——用你的声音问

**Q: 我之前的笔记在 Notion 里，怎么搬过来？**

A: 有官方转换工具 Obsidian Importer，或者跟我说"帮我把 Notion 笔记搬到 Obsidian"，我来处理。

**Q: 免费版够用吗？**

A: **完全够**。Obsidian 本体永久免费。只有两个功能要花钱：Sync（多设备同步）和 Publish（发布成网站）。如果你只在电脑上用，一分钱不用花。

**Q: 存那么多笔记会不会卡？**

A: Obsidian 快的很。几千篇笔记的仓库秒开。因为它是本地软件，不依赖网速。

**Q: 能多人协作吗？**

A: 有"共享仓库"功能（需 Sync），但 Obsidian 天生是为个人知识管理设计的，团队协作不是它的强项。团队用 Notion 更好。

**Q: 手机上体验怎么样？**

A: 能用，但手机屏幕小，不适合大量写作。适合路上查看、随手记想法。配合 Obsidian Sync 或 iCloud 同步，手机和电脑无缝切换。
