# Phase 3: 一口吞摘要 + 可证伪预测

## ITA摘要:
Test-time compute scaling正在从根本上改写预训练scaling law（Chinchilla）。T2T²联合优化框架证明，当计入推理成本后，最优预训练决策大幅向overtraining偏移——训练更小的模型用更多数据，然后通过多次推理采样补偿单次能力。但pass@K的独立同分布假设、p(D,T)→Loss映射的非平凡性、以及后训练阶段的"存活"声称均存在实质性争议。RL后训练scaling law与test-time scaling之间存在尚未被建模的交叉耦合，是当前Scaling Law文献的最大空白。关键未答问题：T2T²规律能否在非推理密集型任务、MoE架构、以及multi-agent场景下保持？

## izu摘要:
AI Agent安全在2026年已从理论威胁变为现实危机——MCP协议"by design"的架构性缺陷（LLM推理与tool执行紧耦合），叠加9700万+下载的生态规模，创造了新的供应链攻击面。真实世界攻击（墨西哥政府案）和协议级RCE漏洞的披露证明这不是补丁能解决的问题。短期可行的防御路径是容器级沙箱+OAuth身份联邦+eBPF行为监控的三层架构，但面临Agent行为多样性导致的基线漂移问题。更深层的忧虑是SBOM的"合规幻觉"风险和威胁模型的根本错位——攻击者未必需要突破技术防线，他们可以是合法用户带着恶意意图。MCP 2.0、Agent Identity Federation和WASM运行时是中期方向上最有潜力的技术路径。

3. **年度战略**：跟踪MCP 2.0安全标准进度和Agent Identity Federation方案。谨慎评估WASM Agent Runtime——在技术成熟度达到生产标准前，用"容器+OAuth+eBPF"的架构作为过渡，保证架构可迁移性。
4. **战术注意**：在选择模型部署策略时，注意T2T²推荐的overtraining路径与Agent安全架构的交互——小模型+多次采样的模式会放大MCP调用频率和安全日志压力，需要预留容量。
5. **元警告**：不要因SBOM/行为监控方案而产生"安全已解决"的错觉。真正的威胁模型——合法用户恶意意图——在当前所有技术方案之外。

## 可证伪预测

**预测（12个月窗口，2026年5月→2027年5月）：**

> **至少一个主流模型提供商（OpenAI/Anthropic/Google/Meta）将在其旗舰推理模型中公开采用"过度训练+推理多次采样"策略，并引用T2T²或类似联合scaling law作为理论依据。同时，该模型在生产部署中将报告40-60%的推理计算量增长（相比前代），单次推理成本下降30%+但总推理成本（含多次采样）持平或略有上升。**

**证伪条件**（任一项成立则预测失败）：
1. 到2027年5月，没有主流模型提供商在技术报告中明确提及overtraining+多次采样策略
2. 即使有，其推理总成本增长低于20%（未被观察者视为策略性部署）
3. 三年内没有模型在Llama 4/Gemini 3/Claude 4/o5系列中展现出明确的overtraining+inference-scaling联合优化信号
4. T2T²论文在12个月内被大规模复现失败（主流实验室重复实验得出相反结论）
