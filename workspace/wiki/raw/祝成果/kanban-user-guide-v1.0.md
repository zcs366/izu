# 看板（Kanban）：让你从"忙乱"变"从容"的操作指南

> **呈：张成市** | 版本 v1.0 | 2026-05-14
>
> 这不是给项目经理看的教科书。这是给一个同时要带孩子、做家务、管运输、种菜、写代码的人看的——让你用最简单的方法，把一团乱麻的日子理清楚。

---

## 一、一个比喻：冰箱门上的便签纸

你家冰箱门上贴着几张便签纸：

- "买奶粉"——还没做
- "修水龙头（在等物业回电话）"——卡住了
- "周三家长会"——有时间要求

每天早上你扫一眼冰箱门，就知道今天该干什么。哪张贴了两周没动，你就知道这里出了事。

**看板就是这个冰箱门的升级版。** 只不过便签纸变成了卡片，冰箱门变成了一个板子。仅此而已。

看板（Kanban）是日语"看板"的音译，原意是"信号卡"。1940年代，丰田汽车工厂里挂着小卡片，流水线上缺零件了，卡片一翻，上游就补。后来这个方法被用到了软件开发、编辑部、HR、甚至个人生活中。

## 二、三步上手：比你想的还简单

### 第一步：画三条线

拿一张白纸（或用电脑上的 Notion / 飞书 / Trello），画三条竖线，分成四栏：

```
| 📥 待办     | 🔧 进行中 | ✅ 完成 |
|------------|---------|-------|
|            |         |       |
```

> **军师帮你翻译**：左边的"待办"栏是你所有要做的事。中间"进行中"是正在做的事。右边"完成"是做完了的事。就这么简单。

### 第二步：写卡片

把你能想到的所有要做的事，每件写一张小卡片，丢进左边"待办"栏。

卡片上写三样东西就够了：

| 字段 | 示例 | 说明 |
|------|------|------|
| **标题** | 给孩子买夏季校服 | 一句话说清楚 |
| **谁做** | 成市 | 如果是自己就写自己 |
| **预计几天** | 2天 | 大概就行，不用精确 |

> **别想太细。** 不用现在就分类、排序、排优先级。第一步先把脑子里的事全倒出来，给大脑腾地方。这就叫"清空大脑"。

### 第三步：设上限，开始拉

在"进行中"栏上面写一个数字，比如 **3**。

这个数字的意思是：**最多同时做3件事。** 只有做完一件、移走一件，才能从"待办"拉一件新的进来。

> 这不是限制你，是保护你。同时追三只兔子，一只也追不到。

## 三、常见的三种情况

### 情况一 🟢："我做完了！"

把那张卡片从"进行中"拖到"完成"。看一眼"待办"栏，如果"进行中"还没满3个，就拉一张新卡片进来。

如果你用的是军师，直接说：**"军师，XX做完了"**，我来帮你移卡片。

### 情况二 🟡："卡住了，做不下去"

在卡片的标题旁边画一个红色小点🔴，写上被什么卡住了：

> 例：修水龙头 🔴（等物业回电话——已等3天）

**卡住不是你的错。** 卡住是信号——告诉你这条路上有个坑，要么填坑，要么绕路。如果一张卡片卡了超过一周，就该认真看看："这事到底还做不做了？"

### 情况三 🟠："有新事情来了"

不要立刻动手。先把新事情写成一张卡片，扔进"待办"栏。

**新来不代表紧急。** 等你手头的事做完，再比较"待办"栏里所有卡片，决定下一张拉什么。

## 四、进阶玩法：常犯的错 & 怎么改

用了两三天后，你可能会碰到这几种情况：

| 你看到的 | 这说明什么 | 怎么办 |
|---------|----------|-------|
| "进行中"栏堆了七八张卡片 | WIP限制没有遵守 | 把上限调到3，做不到就先别开新的事 |
| 全是卡片，看不清了 | 分类太粗 | 加一排"泳道"：按生活/工作/家庭分成三行 |
| "待办"栏永远满的 | 承诺太多 | 设一个"本周不做"区域，把不着急的移进去 |
| 卡片一直不动 | 流程有步骤缺失 | 看看是不是少了"等待别人"这一步——单独加一栏 |
| 完成后不知道做什么 | 缺反馈 | 每周花10分钟看看"完成"栏——这周做了什么？ |

> **军师帮你**：如果你用不惯自己画板子，直接跟我说"军师，用看板帮我理一下今天的事"，我把你的待办自动排成看板格式。

## 七、常见疑问（用你自己的口气问的）

### Q：我已经忙得脚不沾地了，哪有时间搞这个看板？

先花5分钟。就5分钟。把脑子里的七八件事写成卡片。做完这一步，你就不用一直记着了——看板替你记。每天省下的"我今天该干嘛来着"的脑力，远不止5分钟。

### Q：我做事就是想起什么做什么，不喜欢被框死。

看板不是框死你。是让你看得见自己在做什么。你仍然可以随时调整——把卡片拖来拖去，比在心里默默改计划容易多了。看板上面的"待办"栏随时可以换顺序——又没人检查你的作业。

### Q：WIP上限设3个也太少了吧？我有四个孩子！

WIP限制是限制"同时进行的工作项"，不是说只能干三件事。但你一天毕竟只有24小时。设3个上限的意思是：先把手头的事做完，做完了再拉新的。不是不让你做事，是让你一件一件做完。

### Q：和Scrum有什么区别？我看别人都在搞Sprint。

Scrum像"按时发车的大巴"——两周发一趟，每趟运一批。看板像"随到随走的出租车"——来一件走一件。你不是软件团队你就别搞Sprint了，出租车更适合你。

## 八、一周实践路线

| 天 | 做什么 | 预计耗时 |
|----|-------|---------|
| 第1天 | 拿纸画三条线，把脑子里的事全写成卡片贴上去 | 10分钟 |
| 第2天 | 给"进行中"设上限，比如3。今天就严格遵守 | 0分钟（只是守规矩） |
| 第3天 | 有一张卡片卡住了？把它标红，写清楚原因 | 1分钟 |
| 第4天 | 看一眼"完成"栏——这三天做完了什么？给自己一个肯定 | 3分钟 |
| 第5天 | 把一张卡了超过3天的事拿出来，决定：做、不做、还是换个做法 | 5分钟 |
| 第6天 | 有没有"待办"里躺了很久的事？移到一个"本周不做"的区域 | 3分钟 |
| 第7天 | 回顾一周：完成了几张卡片？哪里卡了？下周怎么调？ | 10分钟 |

一周下来总共投入 **约32分钟**。换来的是一周都不用再问自己"我现在该干嘛"。

---

> **军师的话**
>
> 看板不解决"事情太多"的问题——它解决的是"看不见事情"的问题。一旦你的忙碌变得可见，你就从被事情推着走，变成了你推着事情走。这之间的区别，就是疲惫和掌控的区别。
>
> 从三条线开始。就三条线。多了你也不会坚持。明天这个时候，你有三张卡片在"待办"，一张在"进行中"。这就够了。
