# 张仪

## 最强攻击——单点失败分析

### 最可能导致失败的一个点：**FSQ的格子化破坏了代码语义的连续性结构**

**根本原因**：代码的语义在embedding空间中不是均匀分布的。关键语义边界（如"if x > 0"和"if x >= 0"之间的差异）可能刚好跨越FSQ的一个量化格子边界，导致两个语义接近的代码片段被分配到完全不同的离散码——而语义差距大的两个片段可能落在同一格子中。

**为什么是这个点？**
1. FSQ的设计初衷（图像/音频的感知压缩）中，感知失真在quantization grid上是平滑的——相邻格子产生相近感知效果
2. 代码语义在embedding空间中的拓扑结构可能是非欧几里得的——"接近"不等于"语义接近"
3. 格子边界不可学习（FSQ是固定grid）——不像VQ的codebook可以通过梯度学习调整
4. 墨子的理论约束也指向这一点：统计熵H(C) << 算法熵K(C)，意味着FSQ的格子划分基于统计分布而非语义结构

### 降级方案

**方案A：FSQ + 语义感知的格子重映射**
- 在FSQ量化后的离散码上，训练一个轻量级的语义保持映射网络（2层MLP + Gumble-Softmax）
- 使FSQ输出通过可学习的重映射层"校正"格子边界导致的语义失真
- 额外增加4工时 + ~100个可学习参数

**方案B：放弃FSQ，使用Semantic-VQ**
- 使用VQ但改变训练目标：不只是reconstruction loss，而是reconstruction + semantic contrastive loss
- 语义对比loss确保语义等价的代码获得相近的码本索引
- 代价：需要重新处理codebook collapse问题（需要ema或restart机制）
- 额外增加8工时

**方案C：混合方案——ISA（Interpretable Semantic Aggregation）**
- 先用FSQ做粗糙量化（大格子），再对粗糙码序列做SAE分解
- SAE的稀疏特征自然分离语义概念，不受FSQ格子边界的限制
- FSQ负责压缩（降低维度），SAE负责语义保真（恢复概念结构）
- 这是"双轨防御"策略：一个管效率，一个管语义
- 额外增加6工时，但容错性最好

**推荐降级路径**：Day 13-15集成FSQ时，如果发现格子边界破坏语义的问题严重（CF. 商鞅实验Step 3的early stopping），立即切换到方案C（ISA混合方案）。
