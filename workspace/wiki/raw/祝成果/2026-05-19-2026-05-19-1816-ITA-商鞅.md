# 商鞅·20工时MVE

## 工时分配

| 步骤 | 工时 | 说明 |
|------|------|------|
| S0: 环境与数据 | 3h | 安装CodeBLEU工具包；CodeSearchNet Python 500条；清洗+语法验证 |
| S1: BPE基线(CodeBERT round-trip) | 4h | CodeBERT编码→FSQ量化→解码→CodeBLEU对比 |
| S2: SemToken-like基线 | 4h | 隐向量+语义投影+FSQ |
| S3: AST-aware基线 | 4h | tree-sitter AST→子类型编码→FSQ |
| S4: 分析+决策 | 5h | R-CodeBLEU散点图+拐点检测+决策表 |

## 执行命令
```bash
python3 run_r_codebleu.py --data data/csn_python_500.jsonl --baselines bpe,semtoken,ast
```

## 成功/失败标准
- **推进**：R≥2.0 且 CodeBLEU≥95%
- **放弃**：R<1.5 或 CodeBLEU<85%
- **验证墨子**：R=2.31处CB≥99%是否成立；R=3.0是否确实不可行
