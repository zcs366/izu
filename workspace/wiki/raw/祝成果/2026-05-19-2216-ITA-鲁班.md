# 鲁班 — 工程可行官（ITA轨道）

## 在理论约束内的技术方案

### 核心问题发现
- L2归一化方差~0.007 ≪ FSQ bound范围7.5 → 97.7%范围未利用

### 修复方案：pre-scaling
```python
z = F.normalize(encoder(code), p=2, dim=-1)  # 保持L2归一化
z_subset = z[:, :codebook_dim]
scale = half_l / z_subset.std()  # half_l = (levels[0]-1)/2 * (1-eps) 
z_scaled = z_subset * scale      # scale ≈ 1071
z_q = fsq.quantize(z_scaled)     # 在scaled空间量化
cos = F.cosine_similarity(z_scaled, z_q, dim=1)
```

### 预期效果
- 配置K([16,16,16,16], dim=4, 16bits/code) 修复后 **预期cos 0.95-0.97** ⚠️（待实证）
