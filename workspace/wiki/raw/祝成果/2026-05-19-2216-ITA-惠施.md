# 惠施 — 概念辨析官

## 核心概念操作性定义

### 代码语义：层级语义一致性
- 三层次一致性得分 = 0.3×AST Edit Distance + 0.3×Control Flow Graph Isomorphism + 0.4×Behavioral Equivalence
- 可接受阈值：AST解析率≥95%，运行时通过率≥95%，I/O等价率≥95%

### 理解：对抗性功能等价理解
- Pose-F变换测试（功能保持）：接受率≥95%
- Pose-B变换测试（功能破坏）：拒绝率≥95%
- 综合理解得分 = (接受率+拒绝率)/2 × 100%，阈值≥90%

### Steering成功：离散隐编码定向Steering
- Target Property Fulfillment Rate ≥ 80%
- Side Effect Rate ≤ 10%
- 综合SRS = TFR × (1-SER) ≥ 72%

### 压缩边界
- 下界：压缩率≥4×时，Functional Distortion Rate ≤ 5%
- 上界：FDR ≤ 1%时的最高压缩率C_max
- FRD（Functional Rate-Distortion）：在FDR ≤ 1%约束下的压缩率

### 特征独立性假设
- MI矩阵平均非对角线≤0.05 nats → 独立量化假设成立
- Pure Dimension Ratio ≥ 0.75 → FSQ适用
- 绑定效应 MI > 0.2 nats的维度对需报告，簇大小≥3需联合量化
