# 张仪·izu最强攻击

## 单点失败分析

**致命点：nsjail在WSL+Ubuntu 24.04上需要从源码编译，依赖cmake/protobuf/libnl-3等大量构建依赖，初次编译至少4-6h。** 日均1h约束下，D1连编译依赖都装不完。nsjail是D4-D6 sandbox闭环的前置依赖——D1塌方则6天全白做。

## 降级方案

放弃nsjail，用Docker容器做沙箱隔离。Docker已装v29.5.0，`docker pull python`仅需2min。用`docker run --read-only --network=none`对标nsjail安全边界，evaluator.py通过volume只读挂载控制。MLflow用`pip install mlflow`直接装（5min）。D1的1h足够完成环境搭建，D2-D6可按原计划推进。
