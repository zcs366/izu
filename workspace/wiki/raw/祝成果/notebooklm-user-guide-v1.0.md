# NotebookLM 用户操作指南

> **版本**: v1.0 | **更新日期**: 2026年5月 | **适用对象**: 想用AI帮你读书、写报告、做研究的所有人
>
> **一句话**：把你收集的资料扔给NotebookLM，它会帮你读、帮你总结、帮你出主意——而且只根据你给的材料说话，不瞎编。

---

## 📦 这是什么？

想象你有一个**超级实习生**：

- 你丢给它一堆资料（PDF、网页、视频、录音），它几分钟内全部读完
- 你问它问题，它从你的资料里找答案，**每句话都告诉你来自哪一页**
- 你让它把资料变成播客、变成PPT、变成思维导图——它照做
- 你没给它的资料，它不会自己编——不会「我觉得可能是这样」

这个超级实习生就是 NotebookLM。Google 做的，有 Google 账号就能用，**免费**。

> 和 ChatGPT 的关键区别：ChatGPT 用全互联网的知识回答你，NotebookLM 只用你给它的资料回答你。后者的幻觉（胡编乱造）风险极低。

## ⚡ 三步上手

### 🟠 第一步：建一个笔记本

```
1. 打开 notebooklm.google.com
2. 登录你的 Google 账号
3. 点「新建笔记本」按钮
4. 给它起个名字，比如「2026年市场调研」
```

> **你会看到**：一个空白笔记本页面，左边是来源列表，右边是聊天区。就像打开了 Evernote 或 Notion 的新页面。

💬 **或者告诉我**：「军师，帮我建一个叫 XXX 的 NotebookLM 笔记本」

---

### 🟢 第二步：喂资料

这是最关键的一步。你可以上传：

| 资料类型 | 怎么传 | 一次最多 |
|---------|--------|---------|
| 📄 PDF / Word / TXT | 拖进页面或点「添加来源」 | 500,000词/文件，200MB |
| 🌐 网页链接 | 粘贴URL，点「添加」 | URL最长50,000字符 |
| 🎥 YouTube视频 | 粘贴视频链接 | 自动提取字幕 |
| 🎙️ 录音/音频 | 上传 .mp3/.wav 文件 | 支持多语言 |
| 📊 Google幻灯片 | 从Google Drive导入 | 建议<100页 |
| 📚 EPUB电子书 | 拖入上传 | 2026年新增支持 |

> **你会看到**：上传后，NotebookLM 会在几秒到几分钟内处理完成。来源列表里会出现文件名 + 处理状态（✅ = 已就绪）。

💬 **或者告诉我**：「军师，把这些文件加到我的 XXX 笔记本里：[列出文件路径]」

---

### 🔵 第三步：开始用

资料喂好后，你可以做这些事情：

#### 💬 聊天提问
在右侧对话框里直接用中文提问，比如：
- 「这份报告的核心结论是什么？」
- 「第三页提到的数据，有没有其他来源可以佐证？」
- 「把第二章用小学生能听懂的话解释一遍」

每个回答都会**标出来源**——点击引用编号就能跳到原文位置。

#### 🎧 生成音频概述（Audio Overview）
点击 Studio 面板里的「🎧 音频概述」，NotebookLM 会生成一段**双人播客式对话**，两个AI主持人讨论你的资料。

- 大约5-15分钟长
- 可以下载为 MP3
- **交互模式**：播放时点「加入」，你可以直接对主持人说话！

#### 🛠️ Studio 面板（一站式创作）

Studio 是 NotebookLM 2025-2026年最重要的升级。它把资料变成各种成品：

| 工具 | 做什么 | 什么时候用 |
|------|--------|-----------|
| 🎧 音频概述 | AI双人播客 | 通勤时听资料总结 |
| 🎬 视频概述 | AI生成视频摘要 | 分享给团队快速了解内容 |
| 🧠 思维导图 | 自动生成知识图谱 | 理清复杂资料的整体结构 |
| 📄 报告 | 结构化研究报告 | 需要正式文档输出 |
| 📊 PPT | 自动生成幻灯片 | 要做汇报演示 |
| 📈 信息图 | 可视化图表 | 社交媒体分享或快速传达 |
| 🃏 闪卡 | 自动生成记忆卡 | 备考、记忆关键概念 |
| ❓ 测验 | 自动出题 | 自测是否真的理解资料 |

> **关键操作**：进入笔记本后，页面顶部或侧边栏有「Studio」入口。点击任何一个工具，NotebookLM 会基于你的全部资料自动生成内容。

## 🔴 卡住了？常见状况处理

### 🟥 「上传失败，文件太大」
- **原因**：单个文件超过 500,000 词或 200MB
- **解决**：拆分文件。用 PDF 切割工具分成多个小文件，或提取关键章节单独上传

### 🟥 「NotebookLM 说找不到答案」
- **现象**：问了一个问题，AI 回答「在提供的资料中没有找到相关信息」
- **原因**：你的资料里确实没有这个信息，或者提问方式不够精准
- **解决**：换一种问法，或补充上传相关材料

### 🟥 「音频概述生成的是英文，我要中文」
- **解决**：在 Studio 面板生成音频概述时，可以自定义提示词。在「自定义」框里输入：「请用中文对话，两位主持人用标准的普通话讨论」。

### 🟥 「免费版配额用完了」
- **现象**：提示已达到每日使用上限
- **解决**：
  - 等第二天自动重置
  - 或升级到 NotebookLM Plus（Google One AI Premium，$19.99/月，学生半价）

### 🟥 「EPUB 电子书上传后格式混乱」
- **原因**：EPUB 支持是 2026 年新增功能，仍在优化中
- **解决**：先用 Calibre 等工具将 EPUB 转为 PDF 再上传

## 🎯 三套常见用法场景

### 场景一：学生备考
```
上传 → 课本PDF + 课堂笔记 + 老师讲义
问 → 「把第三章的核心概念列出来」
做 → Studio → 闪卡（自动生成记忆卡）
测 → Studio → 测验（自动出题，检验掌握程度）
听 → Studio → 音频概述（通勤路上听一遍）
```

### 场景二：职场调研
```
上传 → 行业报告×5 + 竞品网站×10 + 会议录音×3
问 → 「这些报告的共同结论是什么？」「有什么矛盾的地方？」
做 → Studio → 报告（自动生成结构化研究报告）
做 → Studio → PPT（汇报用，可下载为PPTX）
分享 → Studio → 视频概述（发给没时间读的同事）
```

### 场景三：个人学习
```
上传 → 你想读但一直没时间读的书（PDF/EPUB）
问 → 「这本书的核心观点是什么？」
深化 → 「第五章的论证有没有逻辑漏洞？」
听 → Studio → 音频概述（做家务时听）
看 → Studio → 思维导图（视觉化理解全书结构）
```

## ❓ 常见问题 FAQ

**Q：我的资料会被Google拿去训练AI吗？**
A：不会。Google 明确承诺，NotebookLM 中的用户上传内容不会被用于训练模型。这是它和其他 AI 产品的重要区别。

**Q：免费版有什么限制？**
A：每个笔记本最多50个来源，每天有音频概述生成次数限制（通常5-10次），部分 Studio 工具有使用配额。升级到 Plus（$19.99/月）可获得5倍上限 + 自定义音频概述风格。

**Q：需要科学上网吗？**
A：notebooklm.google.com 在全球200+国家和地区可直接访问（包括中国大陆），但需要 Google 账号登录。如果 Google 账号注册时需要特殊网络环境，那仅此一步。

**Q：能处理中文内容吗？**
A：能。支持中文资料上传和中文提问，音频概述也可以指定中文。但复杂的中文排版（竖排、古文）可能处理不佳。

**Q：可以团队协作吗？**
A：免费版不支持。NotebookLM Plus Enterprise 版本支持团队共享笔记本和权限管理（通过 Google Workspace 订阅）。

**Q：最多能上传多少资料？**
A：免费版每笔记本50个来源，每个来源最多500,000词或200MB。Plus版上限更高（5倍）。Chat 上下文窗口为100万token（约75万英文单词或150万中文字符）。

**Q：和 ChatGPT / Claude 比，我该用哪个？**
A：如果你需要基于自己特定资料（合同、报告、论文）的精准问答，用 NotebookLM。如果你需要通用知识、创意写作、代码编写，用 ChatGPT/Claude。两者互补，不是替代。
