# 🔀 路由与网关 · 用户操作指南 v1.0

> **你不需要成为网络工程师，也能搞定家里的网络问题。**
>
> 这本指南写给：家里有路由器、想上网顺畅、不想被满屏术语吓跑的人。

---

## 一、这是什么？—— 一个比喻就懂

把网络想象成**邮政系统**：

- 你的电脑/手机 = **你家**
- 路由器 = **小区门口的分拣站**（知道每条街在哪）
- 网关 = **城门**（你出小区必须经过的那个门）
- IP地址 = **门牌号**
- 数据包 = **一封信**

**路由**就是"这封信走哪条路到目的地"。

**网关**就是"你家所有信出去必须经过的那扇门"。

> 💡 你家路由器，既是路由器，又是网关。它帮你分拣信件，也帮你开门。

## 二、快速上手——三步搞定家里网络

### 第一步：认清你的设备 🖥️

```
你家网络大概长这样：

[光猫] ─── [路由器] ─── [你的电脑/手机/WiFi]

          这个就是你要关心的设备 ↑
```

| 你看到的东西 | 它是什么 | 在哪 |
|------------|---------|------|
| 一个方盒子，运营商给的 | 光猫（调制解调器） | 墙上/弱电箱 |
| 另一个方盒子，有天线 | 路由器 | 客厅/书房 |
| 两个合一的盒子 | 光猫路由一体机 | 弱电箱 |

### 第二步：进去看看 👀

1. 连上你家WiFi
2. 打开浏览器，在地址栏输入：`192.168.1.1` 或 `192.168.0.1`
3. 会出现登录页面，账号密码通常在路由器底部贴纸上

```
┌─────────────────────────────┐
│  路由器管理页面                │
│                              │
│  状态：✅ 已连接互联网          │
│  WAN口IP：123.45.67.89       │ ← 这是你家在互联网上的"门牌号"
│  网关：192.168.1.1            │ ← 这就是"城门"
│  内网IP范围：192.168.1.2-254  │ ← 你设备在这个范围里
└─────────────────────────────┘
```

> 💡 看到"网关"这个词了吗？`192.168.1.1` 就是你家的城门。所有设备要上网，都得从这过。

### 第三步：日常维护三件事

| 你想做什么 | 怎么做 | 或者告诉我 |
|-----------|--------|-----------|
| 网速慢了 | 重启路由器（拔电源等10秒再插） | "军师，我家网慢" |
| 某个设备连不上 | 检查是否被拉黑名单（路由器管理页面里找"设备管理"） | "军师，XX连不上WiFi" |
| 密码忘了 | 路由器背面有复位孔，用牙签按住10秒恢复出厂 | "军师，路由器密码忘了" |

## 三、常见场景速查 🎯

### 🟢 场景1：断网了，怎么办？

```
先做这个测试（1分钟定位问题）：

1. 看路由器灯 → 红灯/不亮 = 路由器或线路问题
                绿灯 = 继续下一步

2. 电脑打开命令行 → 输入 ping 192.168.1.1
   ┌──────────────────────────────┐
   │ C:\Users\你> ping 192.168.1.1│
   │ 来自 192.168.1.1 的回复...   │ ← ✅ 路由器正常
   │ 请求超时。                   │ ← ❌ 路由器或网线问题
   └──────────────────────────────┘

3. 再试 ping 114.114.114.114
   ┌──────────────────────────────┐
   │ C:\Users\你> ping 114.114.114.114    │
   │ 来自 114.114.114.114 的回复  │ ← ✅ 运营商网络正常
   │ 请求超时。                   │ ← ❌ 可能是运营商断网，打客服电话
   └──────────────────────────────┘
```

| 测试结果 | 问题在哪 | 怎么办 |
|---------|---------|--------|
| ping 网关✅ ping 外网✅ | 网络正常 | 检查电脑DNS设置 |
| ping 网关✅ ping 外网❌ | 运营商问题 | 打客服电话 |
| ping 网关❌ | 路由器或本机问题 | 重启路由器 |

### 🟡 场景2：家里有人蹭网

```
路由器管理页 → 设备管理/客户端列表
→ 看到不认识设备 → 点"禁止"或"拉黑"
→ 改WiFi密码（WPA2加密 + 复杂密码）
```

### 🔵 场景3：想要更快的游戏/视频体验

```
路由器管理页 → QoS（服务质量）设置
→ 把游戏设备或电视盒子设为"高优先级"
→ 把下载任务设为"低优先级"
```

### 🟠 场景4：家里需要两个路由器覆盖

```
方案一：有线连接（效果最好）
[主路由] ──网线── [副路由（设成AP模式）]

方案二：无线Mesh（方便但稍慢）
[主路由] ~~~无线~~~ [Mesh节点]

怎么设：买同品牌支持Mesh的路由器，
按照App引导点几下就行。
```

## 六、常见问题（用你自己的话问）

**Q：为什么我能上QQ但打不开网页？**

A：DNS问题。DNS是把"baidu.com"翻译成IP地址的服务。QQ用的是IP直连，不依赖DNS。解决方法：把DNS改成 `114.114.114.114` 或 `8.8.8.8`。

**Q：我家的IP地址会变吗？**

A：会。运营商给你的IP是动态的（每次重启光猫可能换一个）。这是"动态IP"。想要固定IP需要向运营商申请（一般要加钱）。

**Q：192.168.x.x 是什么？为什么大家都用这个？**

A：这是"私网地址"，专门给家里/公司内部用的。你在自己家用 192.168.1.5，隔壁家用 192.168.1.5——不冲突，因为中间隔了运营商的网关。就像两个小区都可以有"3栋501"，因为门牌号只在自己小区内有效。

**Q：路由器和交换机有什么区别？**

A：路由器管"不同网络之间"的通信（你家和互联网），交换机管"同一网络内部"的通信（你家电脑和打印机之间）。家用路由器里面其实内置了一个小交换机。

**Q：什么是"翻墙"？**

A：技术上，你的数据包走了一条特殊路由——先到一个境外中转服务器，再由它访问目标网站。相当于你的信不直发，先寄给香港的朋友，让他转寄。这不是本指南推荐的做法，但这是它背后的技术原理。

**Q：Mesh是什么？和普通路由器有什么区别？**

A：普通路由器：一个设备覆盖一个区域，远了信号弱。
Mesh：多个小设备组成一张网，你走到哪自动连最近的节点，像手机信号塔一样无缝切换。

**Q：我要在公司搭建网络该从哪开始？**

A：这是个大话题，建议先看本指南的姊妹篇——路由与网关技术手册。简单说：你需要一个企业级路由器（不是家用的那种）+ 交换机 + AP（无线接入点），并且需要规划IP地址段和VLAN。

## 七、安全提醒 🔒

| 做这个 | 不要做这个 |
|--------|-----------|
| ✅ WiFi用WPA2/WPA3加密 | ❌ 用WEP加密（已被破解） |
| ✅ 改掉路由器默认管理员密码 | ❌ 用 admin/admin |
| ✅ 定期更新路由器固件 | ❌ 把路由器管理页暴露到公网 |
| ✅ 关掉WPS（WiFi保护设置） | ❌ 随便让人扫你家WiFi二维码 |
| ✅ 访客网络单独开一个 | ❌ 把主WiFi密码给所有人 |

## 总结

路由与网关不是什么神秘的东西——它就是你家网络世界的**邮局和城门**。理解了这一点，你就已经超越了90%的路由器用户。

遇到问题，先 ping 一下，看问题出在哪一段。大部分家用网络问题，重启就能解决。重启不行，百度一下路由器型号 + 问题描述，一般都能找到答案。
