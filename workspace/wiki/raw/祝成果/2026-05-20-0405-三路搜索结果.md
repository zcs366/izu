# 📡 三路搜索结果

## ITA方向关键发现
1. **语义率失真理论进展**：arXiv 2602.14481 提出了RDC框架（率-失真-复杂度），给出了Gaussian和binary语义源的闭式理论下界。直接相关：代码语义压缩的理论极限计算。
2. **FSQ改进**：iFSQ（arXiv 2601.17124）用1行代码改进FSQ，用于图像生成——但尚未见到代码/软件工程领域的FSQ应用。
3. **代码嵌入的功能一致性**：Expert Systems with Applications 2025论文发现代码嵌入模型在捕获功能语义上的固有局限性，提出自演进数据训练方法。CodeBERT/CodeT5+的隐空间分离度是待测基线。
4. **语义率失真理论（CAS版）**：arXiv 2509.10061 建立条件语义概率失真约束下的率失真框架，弥合信息论与AI的差距。
5. **CSVQ**：通道共享码本向量量化，减少码本大小——方向对但尚未针对代码。

## izu方向关键发现
1. **Agent记忆2026全景**：Mem0报告显示LoCoMo/LongMemEval/BEAM三大基准。Mem0得分：LoCoMo 92.5，LongMemEval 94.4，~6900 tokens/query。
2. **记忆架构分类**：arXiv 2603.07670 提出write-manage-read循环 + 五类机制（上下文驻留压缩、检索增强存储、反思自改进、层次虚拟上下文、策略学习管理）。
3. **Hermes内存实际工作方式**：5层架构（Memory Store→Session DB→Compression→Procedural Memory/Skills→External Providers）。压缩在context window 50%时触发。
4. **跨会话身份与时间抽象**被列为最难开放问题。
5. **Context Window = RAM, not Storage**：Mem0博客指出现有Agent失败主因——把上下文窗口当存储用。

## 核战队交叉发现
1. **代码压缩↔记忆效率交叉**：Hermes的context compression机制可在50%窗口时触发，但缺乏语义级别的压缩策略。
2. **FSQ离散表征**可能直接用于知识胶囊的传输格式——尚未见到代码领域应用，是明确的空白区。
3. **记忆衰减与刷新策略**：自2025年11月已有关于decay和self-evaluation的设计教程，可用于izu记忆保鲜。
4. **Skill库与代码压缩**：Hermes的Procedural Memory (Skills) 与ITA的代码语义压缩天然对应——压缩后的代码表征可直接作为Skill的载体。
5. **时间抽象**被共同列为挑战：Agent需要从代码编辑历史中提取时间抽象模式，ITA提供压缩技术，izu提供记忆框架。
