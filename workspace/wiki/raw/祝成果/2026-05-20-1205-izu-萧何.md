# 萧何 — 执行路径官

## 资源盘点

### 总可用资源
- 人力：20 工时/月（日均 1h）
- 本轨道分配：12 工时（首月）+ 8 工时（次月连续性维护）
- 预算：$925 总额，izu 占 $100（API + 可能的向量库云费）

### 阶段拆解

#### Phase 1：基础设施搭建（Week 1-2, 6 工时, $10）
| 任务 | 工时 | 说明 |
|------|------|------|
| 部署 SimpleMem / Letta | 2h | clone + setup + 连本地 ChromaDB |
| 导入历史对话数据 | 1h | 如果有的话，造测试集 |
| 跑通 LoCoMo 子集测试 | 2h | 验证基础 recall |
| 搭建 Failure Log 采集管道 | 1h | 每个 session 结束时自动记录 recall 质量 |

#### Phase 2：进化回路（Week 3-4, 6 工时, $30）
| 任务 | 工时 | 说明 |
|------|------|------|
| 开发 Failure Pattern Classifier | 3h | DistilBERT 或 GPT-4o-mini |
| 预定义 6 种 pattern → 策略映射 | 1h | 看 EvolveMem 论文中的 diagnose 输出做参考 |
| 搭建回滚保护 | 2h | 测试集 → F1 比较 → 自动 revert |

#### Phase 3：循环迭代（Month 2+, 8 工时/月, $60）
| 任务 | 工时 | 说明 |
|------|------|------|
| 每周跑一次进化循环 | 1h/周 | 看 failure log → 手工确认 pattern → 自动提案+部署 |
| 每两周跑一次 LoCoMo 测试 | 1h/次 | 定量评估 |
| 维护+修 bug | 2h/月 | |

### 关键路径
```
Week 1: SimpleMem部署 + 基础recall测试 → 决定是否继续
   ↓
Week 2: Failure Log管道 + 分类器开发
   ↓
Week 3: 进化回路闭环（诊断→提案→Guard）
   ↓
Week 4: 第一轮手动进化 + LoCoMo对比 → 决定是否投入Month 2
```

### 风险与止损
- **最大风险**：SimpleMem 的基线和 izu 场景不匹配（izu 是陪伴，SimpleMem 设计面向 agent tool use）
  - **止损**：如果 Week 1 发现 SimpleMem 不适配，换 LangMem（LangChain 出品，更贴近对话场景）
- **成本控制**：$100 预算足够 2 个月。如果进化需要 GPT-4o → 每轮 $5，一个月 4 轮 = $20，在预算内
