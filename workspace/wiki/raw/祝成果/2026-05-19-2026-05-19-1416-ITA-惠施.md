# 惠施·概念辨析：ITA核心概念的操作性定义

## 1. 「代码语义」= 功能等价语义（L3）
操作性定义：两段代码功能等价↔对所有黑盒测试用例（覆盖率≥90%）通过。
测量方法：覆盖率引导的测试套件 + 输入输出迹记录器。

## 2. 「理解」的操作性定义
理解度 = 功能等价变体集隐向量的余弦相似度均值。
判定标准：理解度 ≥ 0.85 视为「已理解」。
测量方法：AST变换器 + LLVM opt生成变体 + 余弦相似度计算。

## 3. 「Steering成功」的操作性定义
三元条件同时成立：
- 方向正确：cos(steered, gold_target) > 0.8
- 功能保持：FPR = PASS/Total_cases = 1.0
- 属性达成：Attr_score_after > Attr_score_before × (1+δ)

## 4. 「压缩」的率失真边界
- 弱边界（最低目标）：R ≥ 16× 且 D_p ≤ 0.05
- 强边界（理想目标）：R ≥ 100× 且 D_p = 0
- D_p = 1 - 功能等价率（通过测试用例数/总测试用例数）

## 5. 「FSQ量化质量」的操作性定义
Q_FSQ = 0.6×(1-D_p) + 0.25×语义保真比 + 0.15×效率比
判定标准：Q_FSQ ≥ 0.85 为「高质量量化」

## 6. 「结构化离散化」的操作性定义
四约束同时满足：
- 层次对应：FSQ codebook对应AST粒度层
- 组合完备：K = Π L_i ≥ N_ast（训练集唯一AST结构数）
- 邻域保持：连续/离散空间的kNN排名Spearman ρ ≥ 0.7
- 感知不变：功能等价变体落入相同离散格子的概率≥70%（条件熵H ≤ 0.3×H_max）
