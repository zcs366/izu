# 萧何

## 资源盘点

### 可用资源（与 ITA 共享）
- **人力**：张成市，日均 ~1h
- **预算**：$925（ITA 实验用极少，大部分可分配给 zu）
- **基础设施**：WSL / Python / CPU 推理
- **时间窗口**：试行期 7 天

### 独占资源
- MemSkill 开源代码（GitHub, MIT License）
- Qwen2.5-7B（HuggingFace，可 CPU 推理，但慢）
- CodeBERTScore（与 ITA 共享，边际成本低）

---

## 阶段拆解 & 工时分配

### Pre-Phase：环境 + Skill Bank 初始化（4 小时，第 1 周）
| 任务 | 工时 | 说明 |
|------|------|------|
| Fork MemSkill 代码 + 环境搭建 | 1h | 基于 Python 3.10+ |
| 设计 10 个初始 skill（zu 领域） | 2h | 对话摘要、偏好提取、故事线追踪、生成长度控制等 |
| 编写 zu-MemSkill 适配接口 | 1h | 将 zu 的对话格式转成 MemSkill 的 span 格式 |

### Phase 1：核心功能验证（8 小时，第 2-3 周）
| 任务 | 工时 | 说明 |
|------|------|------|
| 复用 MemSkill controller 进行 skill 选择 | 2h | 在 10 个初始 skill 上测试 |
| 实现 Online Designer 原型 | 4h | 基于失败 case 的在线修正逻辑 |
| 端到端集成测试 | 2h | 3 条长对话场景的完整跑通 |

### Phase 2：评估 + 迭代（8 小时，第 4-6 周）
| 任务 | 工时 | 说明 |
|------|------|------|
| 在 zu 真实对话上测试召回率 | 3h | 对比 Baseline（MemoryBank） |
| Online Designer 收敛性测试 | 3h | 注入失败 case，看 skill 是否进化 |
| 报告 + 与 ITA 交叉对齐 | 2h | 共享评估指标 |

### 总工时
4 + 8 + 8 = **20 工时**

---

## 关键路径（与 ITA 的依赖关系）

```
ITA: 环境搭建 ─→ CodeBERTScore 评估
  ↓ 共享组件         ↓ 共享评估
izu: Pre-Phase ─→ Phase 1 ─→ Phase 2
     4h           8h          8h
```

**关键依赖**：izu Phase 1 的「评估」部分依赖 ITA 的 CodeBERTScore 管道（共享组件）。
- ITA 环境搭建（Phase A）必须先于 zu Phase 1 的评估
- 但 zu Pre-Phase 可以与 ITA 环境搭建并行（无依赖）

**并行策略**：
```
时间     ITA                    izu
第1周    Phase A (4h)          Pre-Phase (4h)    ← 并行
第2周    Phase B 上半 (5h)     Phase 1 上半 (4h) ← 并行
第3周    Phase B 下半 (5h)     Phase 1 下半 (4h) ← 并行
第4周    Phase C (6h)          Phase 2 (4h)       ← 并行
第5周    -                      Phase 2 下半 (4h)
```

**日历时间**：并行推进下，双轨道都在第 4-5 周完成。

## 日均 1h 排期

```
第1周:
  周一 (1h): [ITA] 环境搭建 + [izu] fork MemSkill
  周二 (1h): [ITA] 数据集准备 + [izu] 初始 skill 设计
  周三 (1h): [ITA] FSQ 实现 + [izu] 适配接口
  周四 (1h): [ITA] 实验脚本
  周五 (1h): [ITA] 实验 1/4 运行
  周六 (1h): [izu] Controller 集成
  周日 (1h): [izu] Online Designer 原型
  → ITA Phase A 完成, izu Pre-Phase 完成

第2周:
  周一至周日: 交替推进双轨道核心实验
  → ITA Phase B 完成, izu Phase 1 完成

第3周:
  分析 + 报告 + 交叉对齐
```

**结论**：双轨道并行，日均 1h，3 周可以完成核心实验和功能验证。
