# 韩信 — 技术远景官

## 对 izu 3-6 个月方向的影响

### 3个月后（2026-08）
**基线状态**：izu 拥有三层记忆架构 + 每周手动诊断的轻量自进化
- 与 Mem0 2026 的差距：LoCoMo 上预计能到 70 分（vs Mem0 92.5），但覆盖核心功能
- 关键差异优势：izu 的记忆是针对**一对一陪伴**优化的，不是通用记忆系统
- 技术阶梯：SimpleMem → Letta 社区版 → 定制化进化回路

### 6个月后（2026-11）
**进阶状态**：izu 拥有半自动自进化 + 跨 session 身份一致性
- 如果 ITA 轨道的隐空间编码方案成熟 → izu 可以直接用代码语义编码来存储/检索用户记忆
- 更现实的路线：用 Small LLM（7B 级）做 AutoResearch 的 diagnose module，完全不用 GPT-4
- 目标：LoCoMo 85+，BEAM（10M 规模）60+

## 需要纳入的新技术路线

1. **EvolveMem**：必须学它的 Evaluate–Diagnose–Propose–Guard 框架。但 runtime 用 7B 模型替代 GPT-4o
2. **Mem0 的 single-pass hierarchical extraction**：这是效率关键。izu 的日均 1h 工人无法做多轮迭代提取
3. **Natural Language Autoencoders** 的记忆应用：用户的行为模式可以用 verbalizer→text→reconstructor 的方式压缩为"行为编码"。但需要 ITA 先验证代码 NLAs 可行

## 终局画像调整

**旧画像**：一个「记得用户说过什么」的聊天机器人
**新画像**：一个「能自我修正记忆策略」的知识陪伴系统，每次对话后自动评估哪里没记好、下轮改进

## 技术阶梯
```
Month 1-2: 三层记忆 + SimpleMem → Letta → 基础 RAG
Month 3-4: 手动诊断 + 自动提案进化回路
Month 5-6: 小模型 AutoResearch（开源 7B）+ 跨 session 身份一致性
```
