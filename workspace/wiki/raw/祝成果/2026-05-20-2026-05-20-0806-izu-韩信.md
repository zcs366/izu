# 韩信（技术远景官）

## 对izu 3-6个月方向的影响

### 短期（1-2月）：采纳MemRL的「稳定推理+可塑记忆」架构
- 当前izu用静态RAG检索，可以升级为MemRL的两阶段检索
- Phase 1：语义匹配（现有方式）
- Phase 2：环境反馈验证（过滤噪声，保留高效用记忆）
- **工作量**：约1周核心逻辑修改，可并行当前的记忆胶囊开发

### 中期（3-4月）：引入EvolveMem的自进化检索
- 将izu的检索参数（top-k、重排序权重、融合策略）暴露为可调参数
- LLM诊断模块自动检测失败模式（如：用户问过类似问题但检索到了无关内容）
- **终局画像调整**：izu不是「静态记忆库」，而是「自动进化的记忆生命体」

### 长期（5-6月）：技能层+记忆层双轨进化
- 结合Agent Skills（SKILL.md/MCP）生态
- 记忆层负责"记住该怎么做"（episodic memory）
- 技能层负责"知道能做什么"（procedural knowledge）
- 两者通过统一检索接口交互

## 终局画像（调整后）
```
izu = 个性化记忆系统
    + 自进化检索机制（EvolveMem路线）
    + 非参数化技能习得（MemRL路线）
    + 技能库兼容（Agent Skills/MCP）
    = 不用微调的终身学习AI伴侣
```
