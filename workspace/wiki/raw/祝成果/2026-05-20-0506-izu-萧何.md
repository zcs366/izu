# 萧何 · 执行路径

## 资源盘点
同ITA轨道：张成市日均1h，$925预算，无GPU。

## 阶段拆解（6周/30个工作日）

### 第1-2周：最低可行技能系统（8h）

| Day | 任务 | 输出 |
|-----|------|------|
| D1 | SKILL.md格式调研 + 示例库（10个示例skill） | skills/目录 + README |
| D2 | skill_loader.py实现 | 可从目录加载skill到上下文 |
| D3 | 集成到izu主循环：system prompt注入skill | izu启动时加载skills/ |
| D4 | MCP协议调研 + mcp_bridge.py骨架 | 可调用外部MCP服务 |
| D5 | MCP集成测试（连1个外部服务） | 验证桥接 |
| D6 | trust_scorer.py实现 | 4层权限（本地/已验证/社区/未知） |
| D7 | 首个izu原生skill：代码审查skill | 带信任标签 |
| D8 | 集成测试 + bug修复 | 技能系统可运行 |

### 第3-4周：记忆系统（8h）

| Day | 任务 | 输出 |

### 关键路径
```
SKILL.md解析 → skill加载 → 集成izu主循环
     ↓
MCP桥接 → 外部服务接入
     ↓
向量记忆 → 跨session持久化
     ↓
session日志 → 模式发现 → skill自动更新
```
