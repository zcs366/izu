# 鲁班 — 工程可行官（在理论约束内）

## 技术方案

### 约束回顾（来自墨子）
1. ✅ 4x压缩+95%语义保留 → 理论可达
2. ⚠️ FSQ需要10^12+离散code → 不能直接套用，需分层
3. ❓ 隐空间Steering → 无理论保证

### 工程方案

**Phase A：隐空间分析管线（20工时，与商鞅实验合并执行）**

```
工具栈：
- CodeBERT base (transformers) → CLS embedding (768d)
- Plotly + sklearn → 可视化与聚类分析
- pytest + HumanEval → 测试函数构造

输出：
- 隐空间相似度矩阵
- 分离度统计报告
- t-SNE/PCA可视化
```

**Phase B：语义压缩原型（40工时，基于Phase A结果决定是否执行）**

```
方案1：基于现有注意力层的轻量压缩
- 对CodeBERT的中间层hidden states做均值池化
- 用PCA降维到128d/64d → 测量语义保留度
- 不训练任何新模型 → 零成本

方案2：分层FSQ（如果Phase A显示分离度良好）
- 将768d的embedding分割为8组×96d
- 每组独立做FSQ（levels=16, channels=2→256个离散值）
- 共8×256=2048个离散token → 相比原始768维 → 压缩比与维度无关（取决于token化）
- 注意：这不满足墨子计算的10^12要求，但可作为实验性验证
```

**Phase C：round-trip重建（80工时）**
```
- 用轻量MLP decoder重建CodeBERT embedding
- 测量重建embedding的语义等价保持率
- 如重建embedding在分类任务上的F1 ≥ 原始embedding的90% → 成功
```

### 工程可行性判断
| 组件 | 可行性 | 理由 |
|------|--------|------|
| Phase A（隐空间分析） | ✅ 可行 | 零训练，纯推理+分析，RTX 2080Ti足够 |
| Phase B（轻量压缩） | ✅ 可行 | PCA降维是标准操作，无需额外训练 |
| Phase B（分层FSQ） | ⚠️ 有条件 | 解决了codebook过大问题，但需验证语义保留度 |
| Phase C（round-trip重建） | ✅ 可行 | 简单MLP训练，数据量小 |

**不满足理论约束的检查**：Phase B的分层FSQ方案虽然降低了离散code总数（从10^12降到2048），但理论容量也降低了。这不是违反理论约束——这是实验性验证，明确标注trade-off即可。如果不满足理论极限预期，可以缩小目标：不做全函数压缩，只压缩特定模式（如循环体、条件块）。
