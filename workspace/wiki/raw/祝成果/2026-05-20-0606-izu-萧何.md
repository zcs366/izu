# 萧何 — 执行路径

## 资源盘点

| 资源 | 可用量 | 约束 |
|------|--------|------|
| 工时 | 日均1h（7h/周） | 不能并行做多件事 |
| 预算 | $925/月 | 主要覆盖 API 调用和云资源 |
| 现有代码 | izu agent 框架 ~20K LOC | 模块化程度中等 |
