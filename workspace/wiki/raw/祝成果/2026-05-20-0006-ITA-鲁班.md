# 鲁班 · 工程可行官

【墨子的理论约束】
- FSQ理论可行：d=4, levels=6-8（1296种编码，覆盖300+语义等价类 ✅）
- 但需要先验证"代码语义在隐空间可分"
- SAE steering可迁移但需验证sparsity

【商鞅的实验设计】
- 20工时：CodeBERT提取200个代码片段的embedding → PCA → KNN分类

## 工程可行性评估

### 商鞅的实验 → 完全可行
- CodeBERT是成熟工具（HuggingFace transformers一行调用）
- 200个样本CPU推理即可，完全不需要GPU
- 200个Python片段手工编写工作量可控
- PCA可视化使用scikit-learn，标准管道

### FSQ编码器搭建 → 条件可行
**条件** = 商鞅实验通过（d_class_gap ≥ 2.0）
- 如果通过，直接用Conv1D/Small MLP + FSQ量化器接在CodeBERT编码器后面
- 解码器用Small MLP + 线性层还原到CodeBERT隐空间维度
- 工具链：HuggingFace FSQ实现（已开源）+ PyTorch
- 估计工时：40工时（不包括训练等待）

### SAE steering迁移 → 低风险可行
- SAE训练已有成熟代码库（OpenAI/sparse_autoencoder, Google/GemmaScope）
- 关键是选择CodeBERT维度（768维）对应的SAE架构：d_model=768, d_sae≈768*8=6144, k=32（top-k）
- 训练数据：BigCode数据集/TheStack的子集（5万-10万个代码片段）
- 估计工时：30工时（数据处理+训练+评估）

## 技术方案总结

```
阶段1（当前）：CodeBERT可分性实验 → 20工时
阶段2（如果通过）：FSQ量化器搭建 + SAE训练 → 70工时
阶段3（整合）：round-trip测试 → 20工时
总计：110工时（+训练等待时间不计在内）
```

**工程不满足理论约束的风险**：如果代码语义在隐空间不可分（即商鞅实验失败），整个ITA方向需要转向——从"语义保真编码"转向"功能性编码"（不求语义逐位保真，只求功能性等价）。这需要墨子重新给出理论边界。
