# 张仪 — 最强攻击官（izu轨道）

## 唯一致命点

**Ebbinghaus衰减曲线在「无活跃用户交互」场景下完全失效——但整个轻量记忆进化方案依赖它作为底层引擎。**

### 致命假设分析

**假设①：`age_hours` 能衡量记忆价值**
当Cron定时任务每天深夜跑一次维护时，所有session的`age_hours`线性增长。用户5天不登录→所有记忆`decay_score`= `0.5^(120/24) = 0.031`→**所有记忆全被遗忘门控吞噬**。三档RL全部坍缩为"遗忘档"。

**假设②：`importance` 是静态且可准确计算**
代码中`importance = min(1.0, turns/100)`——但50轮的session可能全是废话，3轮的session可能包含核心决策。

**假设③：`accesses` 能有效对抗衰减**
访问计数器不存在自增逻辑，且Cron跑的频率不足以对抗24小时半衰期。**访问增强形同虚设。**

### 连锁崩溃路径
```
Ebbinghaus假设失效 → 重要性估算全错 → ForgetPolicy误判
→ Intake筛选器从好的session里筛出垃圾
→ RL训练数据全部污染 → Reflexion Loop强化错误结论
→ "记忆进化"退化为"记忆污染"
```

### 降级方案

**放弃Ebbinghaus曲线，改用「最后一次被实际引用的时间」作为衰减基准。**

1. **引用追踪**：每条记忆维护`last_referenced`字段
2. **交叉验证重要性**：统计`decisions + key_facts + code_blocks`总量
3. **两段式保护**：≥3条decisions或≥1条code_blocks的session标记`protected=True`
4. **立即止血**：把`FORGET_THRESHOLD = 0.15`改为`0.05`，`DECAY_HALF_LIFE = 24`改为`72`
