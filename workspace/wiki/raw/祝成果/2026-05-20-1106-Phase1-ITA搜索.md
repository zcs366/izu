# 📡 ITA方向搜索结果

## 选题: Code Round-trip Consistency + 隐空间压缩

### 发现1: RTCE基准测试
**"Can LLMs Compress (and Decompress)? Evaluating Code Understanding and Execution via Invertibility"** (arXiv 2601.13398, Jan 2026)
- RoundTripCodeEval: 4种代码执行推理任务，测试forward-backward bijection fidelity
- 零样本/SFT/self-reflection都只带来「适度改进」——**没有任何方法能闭合round-trip gap**
- 核心洞见：inversion不能靠局部模式匹配解决，需要深层语义理解；forward-only accuracy是误导性的
- 对ITA的意义：这是天然的评测基准——先测CodeBERT的round-trip一致性看基线在哪

### 发现2: 率失真下的FSQ变体
**"Robust Residual Finite Scalar Quantization (RFSQ) for Neural Compression"** (arXiv 2508.15860, Aug 2025)
- 保留FSQ的简洁性，同时用multi-stage residual量化改善重建质量
- 对code token场景，RFSQ可能比VQ-VAE更稳定（无codebook collapse问题）
- 关键问题未答：多轮auto-encoding的误差累积曲线还没人测过code域

### 发现3: EasySteer框架
**"EasySteer: A Unified Framework for High-Performance and Extensible LLM Steering"** (arXiv 2509.25175, Sep 2025)
- 基于vLLM的steering框架，5.5-11.4x加速
- 模块化架构：analysis-based + learning-based方法都支持
- 已预制8个应用域的steering vectors
- 直接相关的：code steering向量在vLLM推理中做的研究还没人系统做过
