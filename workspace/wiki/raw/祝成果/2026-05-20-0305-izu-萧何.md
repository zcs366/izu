# 萧何 — 执行路径官

## 执行路径报告

### 资源盘点
| 资源项 | 可用量 | 备注 |
|---|---|---|
| 张成市时间 | 日均 1h | 与 ITA 方向共享 |
| 代码基础 | izu v0.2 | 已有 Python 代码库 ~5000 行 |
| 外部依赖 | ITA FSQ 成果 | izu L3-L5 依赖 ITA 完成度 |
| 云资源 | 同 ITA | 共享 GPU 预算 |

### 阶段拆解

#### Sprint 1：记忆分层（2周，~10h）
| 任务 | 工时 | 交付物 |
|---|---|---|
| session 层改造（已有对话改为结构化存储） | 3h | session_store.py |
| episode 层（按主题聚类对话） | 4h | episode_summarizer.py |
| 知识层（跨session的长期知识） | 3h | knowledge_graph.py |
| **总** | **10h** | **izu v0.3** |

#### Sprint 2：技能模板化（2周，~12h）
| 任务 | 工时 | 交付物 |
|---|---|---|
| skill 注册 API 重构 | 3h | skill_registry.py |
| 从 tool call 自动生成 skill 模板 | 5h | skill_template.py |
| skill 调用优化（根据上下文自动选） | 4h | skill_selector.py |
| **总** | **12h** | **izu v0.4** |

#### Sprint 3：隐空间记忆（依赖ITA成果，4-6周，~15h）
| 任务 | 工时 | 依赖 |
|---|---|---|
| ITA 编码器接入 izu | 4h | ITA Phase B 完成 |
| 用户行为模式编码 | 4h | 编码器可用 |
| 隐空间检索 + 解码 | 5h | ITA FSQ 层 |
| Steering 试验 | 2h | ITA 操控性实验 |
| **总** | **15h** | **izu v0.5** |

### 关键路径 & 依赖关系
```
ITA 基线实验 ──→ ITA FSQ 原型 ──→ ITA 功能验证
   (Phase A)        (Phase B)        (Phase C)     ← 上游
       |                 |                 |
izu Sprint 1 ──→ izu Sprint 2 ──→ izu Sprint 3
  记忆分层           技能模板          隐空间记忆     ← 下游
```

### 风险 & 缓解
| 风险 | 概率 | 影响 | 缓解措施 |
|---|---|---|---|
| ITA 延迟 | 30% | izu L3 阻塞 | Sprint 1+2 先做，不依赖 ITA |
| ITA 技术失败 | 20% | izu L3 不可行 | 改为纯 RAG 升级路线（降级方案） |
| 张成市时间不足 | 20% | 全线推迟 | 优先保证 Sprint 1，最核心 |

### 日排班建议
和 ITA 方向共用张成市日均 1h，建议交替进行：
```
周一/三/五：ITA 方向（代码压缩）
周二/四/六：izu 方向（记忆+技能）
周日：复盘/写文档
```
每周 ITA ~3h，izu ~3h，加上周末集中时间，两线并行可推进。
