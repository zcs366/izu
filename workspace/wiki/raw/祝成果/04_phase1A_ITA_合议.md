# Phase 1A - ITA 六轮合议

**选题**：Topological Quantum Error Correction at Scale

## R0 惠施 — 概念澄清

- **拓扑量子纠错（软件编码）≠ 拓扑量子比特（硬件拓扑保护）**
- 纠错三等级：亚阈值操作 → 逻辑门保真度 → 全纠错架构（仅完成第一级）
- 表面码 ⊂ 拓扑码 ⊂ 纠错码方案；硬件拓扑保护是平行路线
- 概念混用：\"阈值跨越\"被过度推广；1000:1 vs 10:1不对等比较（已实验验证 vs 理论预测）
- \"容错\"≠\"纠错\"

## R1 墨子 — 逻辑/形式化验证

**7环节因果链拆解**：
1. 物理比特达到阈值以下（已验证）
2. 表面码有限码距展示指数抑制（部分验证，d≤7）
3. 码距可无限扩展（理论推测） ← **最关键的未验证环节**
4. 纠错周期<相干时间（部分验证，解码器瓶颈）
5. 逻辑门错误率与存储同步降低（理论推测，实验完全空白）
6. 全纠错架构工程可扩展（理论推测）
7. 可运行有意义算法（未验证）

**关键假设检验**：
- H1（阈值可无限扩展）：关联噪声可能破坏独立同分布假设
- H2（解码器延迟）：当前d=27下仍不满足1μs实时约束 ← 被低估瓶颈
- H3（逻辑门纠错）：Magic State Distillation开销巨大，实验完全空白
- H4（MS拓扑比特10:1）：高度不确定，有撤稿历史

**逻辑谬误**：滑坡谬误、合成谬误、不当类比、选择性呈现

## R2 商鞅 — 实验设计

**三大判决性实验**（按优先级）：
1. **A. 码距扩展实验** d=7→15→27（最快，~2-3年）
2. **B. 解码器延迟-精度权衡实验**（中等，~1-2年）
3. **C. 逻辑门纠错指数抑制实验**（最难，~3-5年）

**Microsoft拓扑比特独立验证协议**：
- 需看到非阿贝尔编织操作（实验实现）
- 独立第三方复现Majorana零模拓扑保护
- 超出单一实验室的可靠性数据（准粒子中毒、能隙测量）

## R3 鲁班 — 工程可行性

**解码器**：Union-Find FPGA方案最有希望，但d=27下精度-延迟权衡尚未解决。理论下界：解码延迟<0.5μs（含通信开销）。

**平台可扩展性**：
| 平台 | 木桶短板 |
|------|----------|
| 超导 | 布线/制冷差距5个数量级（1M比特1kW@20mK vs 制冷机10μW） |
| 离子阱 | 穿梭速度与加热 |
| 光子 | 确定性光子源与损耗 |
| 硅自旋 | 门保真度99% vs 超导99.9% |

**Magic State Distillation**：每个T门需~14000物理比特（d=27），工厂占70-80%物理比特。

**MS拓扑比特**：从1→10→100→10K→1M的路径每步都不透明。准粒子中毒、非阿贝尔编织操作未实现。

**时间线**：超导2030-2040+，MS拓扑2031-2045+

## R4 萧何 — 资源路径

**投资优先级**：
1. 解码器（★★★★★）— 纯软件+硬件投入，任何平台都需要
2. 纠错理论/编译器（★★★★）
3. 自动校准与控制系统（★★★★）
4. 低温制冷技术（★★★）
5. 材料科学（★★）
6. FAB/制造（★★）

**人才缺口**：解码器工程~500人（最稀缺），全球缺口3000-5000人

**机构排序**：Google > IBM > Quantinuum > Microsoft > Intel > IonQ

**地缘格局**：美国全面领先；出口管制使全球碎片化风险高（最大风险不是某方被卡，而是全球重复造轮子）

## R5 张仪 — 最强攻击

**根本性否定**：
1. 非马尔可夫噪声+关联误差可能消灭阈值定理（2024年Gottesman分析暗示阈值可能趋近于零）
2. 解码器存在不可约热力学/因果性约束（Landauer原理+实时反馈延迟下界）
3. 工程焦虑症错误：把理论问题伪装成工程问题

**致命漏洞**：
- 因果链实际上是耦合非线性系统（正反馈崩溃风险：解码器慢→门质量降→阈值失效→需更大码距→解码器更慢）
- 解码器是暂时瓶颈（商用芯片可能2027-2028突破，但新瓶颈转移未被建模）
- 表面码/拓扑比特hybrid方案被选择性忽略

**认知盲区**：
- 技术乐观主义沉默共识——无人质疑"是否可行"，仅争论"多快多贵"
- 纠错崇拜——80%资源投入纠错，NISQ路径被边缘化
- "百万比特"是政治口号而非技术需求（源于Shor算法破解RSA的特定场景，非通用需求）

**备选结论**：大规模表面码纠错可能永远无法实现。未来是NISQ+时代(2025-2035)+混合经典-量子架构+替代编码方案+硬件改进替代软件纠错。
