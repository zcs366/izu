## 一、专业技术意见

### 1.1 鲁班团队意见

**核心结论**：可行。~760行新代码，MVP 1-2周可交付。

#### 系统架构

```
Hermes Agent 主进程
┌─────────┐   ┌───────────┐   ┌──────────────┐   ┌──────────────────────┐
│ CLI/GW  │──▶│ AIAgent   │──▶│ Model Router  │──▶│ Provider Adapter     │
│ 入口    │   │ run_agent │   │ Middleware    │   │ (OpenAI SDK / Custom) │
└─────────┘   └───────────┘   └──────┬───────┘   └──────────┬───────────┘
                                      │                      │
                                      ▼                      ▼
                        ┌─────────────────────┐   ┌──────────────────┐
                        │    Task Matcher      │   │   Model Registry │
                        │    (规则引擎)         │   │   (SQLite/JSON)  │
                        └──────────┬──────────┘   └────────┬─────────┘
                                   │                       │
                        ┌──────────▼───────────────────────▼──────────┐
                        │           Capability Grading Engine           │
                        │   S(顶级) A(高) B(中) C(基础)                │
                        └──────────────────────────────────────────────┘
                                     │
                ┌────────────────────┼────────────────────┬───────────────────┐
                ▼                    ▼                    ▼                   ▼
         ┌─────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
         │ DeepSeek    │    │ OpenRouter   │    │ MiniMax CN   │    │ Local Models │
         │ (云端旗舰)   │    │ (Fallback)   │    │ (低成本)      │    │ (Ollama/     │
         │             │    │              │    │              │    │  LMStudio)   │
         └─────────────┘    └──────────────┘    └──────────────┘    └──────────────┘
```

#### 能力分级方案（四维加权）

| 等级 | 综合评分 | 标签 | 典型场景 |
|------|---------|------|----------|
| **S** | ≥8.5 | 🏆 顶级 | 复杂推理、代码生成、高质量写作、关键决策 |
| **A** | 7.0-8.4 | ⭐ 高 | 中等推理、翻译、摘要、分析 |
| **B** | 5.0-6.9 | ✅ 中 | 格式化、简单分类、信息抽取、常规对话 |
| **C** | <5.0 | 💰 基础 | 机械任务、批量处理、成本优先 |

#### 当前模型分级归属

| 模型 | Provider | 等级 | 综合分 | 理由 |
|------|----------|------|--------|------|
| **deepseek-v4-pro** | deepseek | **S** | 8.0 | 当前唯一顶级，代码/推理担当 |
| **deepseek-chat(v4-flash)** | deepseek | **A** | 8.1 | 速度快，日常主力 |
| **gemini-3-flash-preview** | gemini | **A** | 8.0 | 已配Key待启用 |
| **minimax-cn/gpt-5.4** | custom | **B** | 7.4 | 极低成本，简单任务优选 |
| **OpenRouter免费模型** | openrouter | **B/A** | 动态 | 薅羊毛主力，需再注册 |
| **LMStudio(本地)** | custom | **C** | 5.0 | 当前未响应，需修复 |
| **Ollama(本地)** | custom | **C** | 5.0 | 未安装，需部署 |

#### 路由规则引擎

6条规则树，纯代码实现（无外部规则引擎依赖）：

```
Rule 0: 显式override → 直接使用指定模型
Rule 1: 简单机械任务 → C级(B级)，强制免费或本地
Rule 2: 复杂推理/高质量 → S级
Rule 3: 速度优先 → 选最快模型
Rule 4: 成本优先 → 选最便宜模型
Rule 5: 兜底 → 均衡策略
```

#### 需要新建的装备

| 新组件 | 行数 | 功能 |
|--------|------|------|
| ModelRegistry | ~150行 | 注册表加载、查询、CRUD |
| TaskMatcher | ~200行 | 任务分类 + 规则匹配 |
| ModelRouter | ~150行 | 协调器：registry→matcher→selector |
| CapabilityGrader | ~80行 | 能力分级逻辑 + 评分计算 |
| Router CLI | ~100行 | `hermes router` 子命令 |
| 默认注册表JSON | ~80行 | 初始模型配置数据 |
| **总计** | **~760行** | |

**不需要造的新装备**：独立的规则引擎库、独立Web服务、消息队列、独立数据库、缓存层、分布式锁。

#### 与Hermes集成方式

中间件模式——在 `AIAgent._resolve_model()` 中拦截模型调用前插入路由逻辑。最小改动，不改变现有调用链。MVP阶段用中间件，稳定后可迁移到Plugin架构。

#### 技术风险评级

🟢 **低风险**。核心逻辑都是代码级规则，不依赖模型输出做判断。不改变现有调用链，只是给模型选择加了一层智能。

### 1.2 韩信意见

**终局画像（3个月后）**：

路由系统成为Hermes的智能调度中枢，用户不分心思选模型，系统自动判断：
- **日常对话/格式化/简单提取** → 不花一分钱（本地+免费模型）
- **代码/推理/长文写作** → 自动走DeepSeek V4 Pro或未来更好的模型
- **紧急/时间敏感** → 自动选最快的模型

用户唯一需要感知的是：**快且便宜的时候感觉不到路由存在，高质量的时候路由自动给了最好的模型。**

**技术阶梯**：
- **现在**（v0.1）：JSON注册表 + 规则匹配 + DeepSeek + MiniMax
- **1个月后**（v0.5）：SQLite持久化 + 自动健康检查 + OpenRouter免费模型池 + 本地Ollama
- **3个月后**（v1.0）：LLM辅助分类 + 历史学习调优 + Gemini/ChatGPT/Claude接入 + 多Key轮转

### 1.3 子贡意见

**成本模型**：

| 流量分层 | 占比 | 模型 | 成本 |
|---------|------|------|------|
| 简单任务（格式化/晴/分类） | ~70% | Ollama本地/OpenRouter免费 | **¥0** |
| 中等任务（翻译/摘要/分析） | ~25% | MiniMax GPT-5.4 / OpenRouter | ≈ ¥0.5/月 |
| 复杂任务（代码/推理/写作） | ~5% | DeepSeek V4 Pro | ≈ ¥2-5/月 |
| **合计** | 100% | — | **¥2.5-5.5/月** |

**薅羊毛策略**：Ollama本地零成本 / OpenRouter免费模型 / 阿里Qwen免费额度 / DeepSeek注册送¥10。

**关键建议**：本地模型（Ollama）投资回报率最高——一次部署，永久零成本处理~70%任务，强烈建议优先搞定。

## 二、萧何精算团跟进清单

### 2.1 改进评估

| 当前状态 | 目标状态 | 差距 | 优先级 |
|---------|---------|------|--------|
| 手动选模型 | 自动按任务匹配模型 | 需开发路由系统 | P0 |
| 只有DeepSeek+MiniMax | 多模型池（含免费/本地） | 需接入OpenRouter、Ollama | P0 |
| 成本不透明 | 每次调用自动成本估算 | 需CostEstimator | P1 |
| 模型故障人工发现 | 自动健康检查+降级 | 需监控+fallback链 | P1 |
| 单Key | 多Key轮转 | 需负载均衡 | P2 |

### 2.2 路径阶段

| 阶段 | 交付物 | 预估工时 | 关键路径标记 |

| **Phase 1**：模型注册表 | `ModelRegistry`类 + `model_registry.json` + 能力分级 | 2天 | ⭐ 关键 |
| **Phase 2**：路由引擎 | `TaskMatcher` + 规则树 + `ModelRouter` + 降级链 | 3天 | ⭐ 关键 |
| **Phase 3**：统一路由API | `route_request()`接口 + 中间件集成 + config扩展 | 2天 | ⭐ 关键 |
