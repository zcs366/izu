# 子产 — 需求判断/研究方向

## 需求判断：该不该做？

**该做。** 且比 ITA 更紧迫。

**论据**：
1. EvolveMem (May 2026) 证明了记忆架构的自我进化已是可行方向——25.7% 的提升不是 marginal gain
2. Mem0 2026 的 LoCoMo 92.5 分意味着「记忆任务已进入实用阶段」，izu 不加追就落后了
3. 用户场景：个人知识陪伴。如果有自进化记忆，izu 就能真正记得用户上次说了什么、偏好什么——这是形成依赖的关键

**不做会怎样**：
- 3个月后，同行（Mem0 / Letta / 各类 AI companion）都有了记忆自进化能力
- izu 停留在 RAG + 静态记忆，无法形成用户粘性

## 研究方向定位

**关键问题**：如何用可承受的成本（$925 预算内）实现记忆策略的自进化？

### 假设
EvolveMem 的 AutoResearch loop 可以用更轻量的方式实现——不需要每轮都用 GPT-4o 做诊断和提案，可以用小模型 + 规则 + 随机搜索的组合

### 方向判断：正确但需要裁剪
**研究方向**：轻量版自进化记忆 + 跨 session 身份保持

**裁剪要点**：
1. 不要复刻 EvolveMem 的全部 7 轮自进化——每轮需要 LLM 诊断 + 提案
2. 改为：**手动诊断 + 自动提案**——人类（张成市）每周看一次 failure log，标注问题类型；由 LLM 根据标注类型自动调整检索参数
3. 保留三层记忆（working / short-term / long-term）框架，参考 MemGPT
4. 用 Mem0 的开源替代方案（SimpleMem / Letta 社区版）作为基础，避免从头造

### 研究方向简述
「让 izu 的记忆策略每周自动进化一次。进化方式：人类提供 failure pattern → LLM 生成配置更新 → 回滚保护」
