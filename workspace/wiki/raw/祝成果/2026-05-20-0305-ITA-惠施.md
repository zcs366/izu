# 惠施 — 概念辨析官

## 核心概念操作性定义

### 1. 「代码语义」
- **非操作性定义（淘汰）**：代码的意思或意义。
- **操作性定义**：代码的语义 = 代码在给定输入上执行时产生的**行为轨迹**（状态序列 + I/O行为 + 控制流路径）。两个代码片段语义等价当且仅当对所有合法输入产生完全相同的状态转移序列。

### 2. 「理解」
- **操作性定义**：编码器E对代码段C的「理解程度」= 隐空间向量 z = E(C) 在语义等价类上的**聚类紧密度**（同类间距 variance / 异类间距 separation）。理解即隐空间对齐。

### 3. 「Steering成功」
- **操作性定义**：Steering 成功 = 在隐空间中施加干预向量 δ 后，解码器输出 D(z+δ) 的语义行为按预期方向发生了**可测量可复现的变化**。度量：干预方向与行为变化的余弦一致性 ≥ 0.8，且在不同输入上复现率 ≥ 90%。

### 4. 「压缩」
- **操作性定义**：压缩率 = 输入代码的比特数 / 经过编码器-量化器-解码器后的比特数。同时保真度由 round-trip 一致性度量——原始代码执行轨迹与重建代码执行轨迹的**状态差异**（TV距离 ≤ ε）。

### 5. 「率失真边界」
- **操作性定义**：给定代码分布 P(C)，任何编码方案 R(D) 必须满足：若要求失真 D ≤ d，则码率 R ≥ R(D)，其中 R(D) 由信息率失真函数 R(D) = min_{p(z|c): E[d(c,z)] ≤ D} I(C; Z) 定义。这是理论下界，不可突破。

### 6. 「隐空间操控性」
- **操作性定义**：隐空间的操控性 = 存在一组方向向量 {v_i}，使得沿 v_i 移动时解码器输出沿某个可定义语义轴单调变化。量化：方向-语义相关性 ≥ 0.85。

### 总结
本轮所有模糊概念已翻译为可测量、可操作的定义。下一轮墨子可以基于这些定义做形式化验证。
