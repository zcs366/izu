# 韩信 —— 技术远景官

## 3-6个月远景 (2026-05 → 2026-11)

### 核心判断

izus 3个月后应该是一个「**记得一切、越聊越聪明、但用户不需配置**」的陪伴Agent。
6个月后应该能「**从对话中提炼用户模式，主动优化回答风格和内容**」。

### 新纳入的技术路线

**必做**: Mem0集成（1天）
- 理由：92.5 LoCoMo / 94.4 LongMemEval，21框架集成，API简洁
- 这是izu的「记忆基础设施」，不做就永远停留在RAG水准

**强推荐**: 实体链接（Mem0已有entity linking支持）
- 让izu能从「你上次说喜欢村上春树」升级到「根据你读的村上春树和你上次说的'日本文学结构太松散'的评论，我推荐《挪威的森林》之前可能先看《且听风吟》」
- 实体链接是实现「跨会话推理」的最小必要组件

**中期看**: 行为模式学习（3个月后）
- 从对话中提取用户的行为模式（偏好、节奏、禁忌话题）
- 不需要强化学习——简单的pattern matching + 统计就够了
- 参考方向：ExpeL (Experiential Learning) 论文的思想但用规则实现

### 终局画像调整

**原画像**: 知识陪伴Agent，能记住用户说过的话
**新画像**: 知识陪伴Agent + 渐进式个性化学习者
- 不仅能「记住」，还能「从记忆中学习」
- 但**不承诺**「自我进化」——那是3个月后的目标
- **关键调整**: 记忆不是终点，学习才是

### 技术阶梯

```
当前 → Phase 1(Mem0集成, 1天) 
  → Phase 2(实体链接, 2-3天) 
    → Phase 3(用户模式提取, 5-7天) 
      → Phase 4(经验驱动的回答优化, 2周)
        → Phase 5(跨会话推理链, 2周)
```

每步可独立交付、独立验证。任何一步做完都可以说「izu比昨天更好了」。
