# Phase 1A — ITA 6轮合议

## Round 3: 鲁班（工程可行——在理论约束内）

### 工程约束分析

**约束1：计算开销边界**
- 实验1的3D相图绘制：每模型每配置1000次采样 → 约3×8×3×2×1000=144,000次推理
- 当前最先进LRM推理成本：~$1-2/百万token → 每个推理约$0.01-0.05
- 144,000×$0.03 ≈ $4,320/模型 → 三个模型～$13,000 → **完全在可行范围内**
- **建议**：先在小模型（Llama-3.1-70B推理版）上做grid搜索优化，再迁移到大模型

**约束2：可控谜题生成器的工程实现**
- Apple研究使用的可控谜题逻辑需要重建
- 工程路径：用Prolog（逻辑可组合性最优）或Haskell生成器→输出自然语言问题描述
- 复杂度参数化为JSON配置文件，便于批量生成
- 开发时间估计：2周（单人全职，含验证生成质量）

**约束3：激活探测的硬件需求**
- hidden state提取需要修改推理框架：vLLM或HuggingFace的`output_hidden_states=True`（但LRM可能有专有实现）
- 对闭源模型（GPT-5, Claude）：无法直接获取hidden state → 退而使用logit输出、中间层的surrogate通过API可获取的logprobs
- **可行方案**：对开源模型（Llama/Mistral系列推理版）做全探测，对闭源模型做API-level代理探测
- 开源模型算力需求：~4×A100-80GB或8×RTX4090，云服务约$50-200/实验

**约束4：实验4（验证器辅助）的系统架构**
- 推理器+验证器的并行/串行调用
- 每步调用的延迟叠加 → 对交互式场景不现实，但对离线分析可行
- 工程trade-off：验证器精度 × 延迟 → 需要做Pareto前沿分析
- 验证器缓存：对重复的子问题状态做缓存，降延迟约60%

**约束5：时间线预估**
- 实验1（相图）：3周（生成器1周 + 实验运行1周 + 分析1周）
- 实验2（激活探测）：4周（探测框架搭建2周 + 实验1周 + 分析1周）
- 实验3（体制复现）：3周（数据集标注1周 + 实验1周 + 分析1周）
- 实验4（验证器辅助）：4周（系统搭建2周 + 实验1周 + 分析1周）
- 并行度：实验1和3可并行，实验2依赖1的部分结果，实验4可独立推进
- 总工期（含并行）：约6-8周

### 理论约束内的可行路径

**路径A（保守）**：在开源LRM上完整再现Apple研究结果 + 激活探测实验 → 发表可复现性+机制分析
**路径B（激进）**：路径A + 验证器辅助实验 → 发表"局限性的克服方案"
**路径C（理论）**：仅做形式化分析（不跑实验）→ 纯理论框架论文

**建议**：路径A+B是可行的，总预算约$25,000-50,000，时间8-10周。
