# 张仪 — 最强攻击官（ITA轨道）

## 唯一致命点

**"离散码本的随机索引与代码语义属性之间存在线性可逆映射"——这个假设从始至终没有任何实证支持。**

### 四大证据

**证据一：率失真分析自己说的有条件**
> AUSteer原子单元级Steering → ⚠️ 有条件 | 理论上限AUC≈0.9，需验证每单元可分性

TACT证明的是Agent行为漂移在激活空间线性可分，和"代码语义属性在FSQ离散码本索引上线性可分"是两码事。

**证据二：量化路径每一步都在破坏原始几何结构**
```
CodeBERT(768维) → L2归一化 → 前N维降维(损失99.6%) → scale×1071 → tanh → round
```

即使cos=0.95，只说明"这段代码在量化后保持大致方向"，不代表改变码本索引能因果改变代码的语义属性。

**证据三：码本大小可能不够**
最优配置([16,16,16], dim=3)码本大小仅4096。要编码的代码语义属性（时间复杂度、输出格式、内存模式等）数量本身可能超过4096。

**证据四：整个方案没有任何实验环节验证Steering因果性**
D1-D2只验证cosine保真度，D3-D6只验证率失真，D7-D10只做理论对齐。

### 降级方案

**FSH-1 (Falsify Steering Hypothesis, 4h)**
```python
# 取HumanEval 164函数→CodeBERT编码→FSQ量化([16,16,16], dim=3)
# 对码本索引做±1步扰动，观察代码变化
# 关键测量：Kendall's τ（编辑距离 vs 扰动幅度）
# 如果τ < 0.70 → P₇证伪 → 放弃Steering主张
# 如果τ ≥ 0.70 → 继续原方案（需更大规模验证）
```

**降级接受条件：** 如果FSH-1的Kendall's τ < 0.70 → 立即放弃"离散隐编码定向Steering"主张，回退为"FSQ量化代码隐空间的率失真特性研究"。
