# 萧何 — 资源路径

## 资源盘点

| 资源项 | 可用性 | 备注 |
|--------|--------|------|
| 张成市工时 | 日均1h（约7h/周） | 极有限，必须最大化每工时的信息收益 |
| 预算 | $925/月 | 不能烧 GPU 训练成本 |
| GPU | 可选 T4 (云/Colab) ~$0.5/h | 适用于推理级实验 |
| 代码库 | izu 现有代码基 | 可复用 Agent 框架 |
| 数据集 | CodeXGLUE / HumanEval / MBPP | 免费公开 |

## 代价估算

| 阶段 | 工时 | 计算成本 | 日历时间 |
|------|------|----------|----------|
| 商鞅实验1（线性探针） | 8h | ~$10 (Colab T4) | 1周 |
| 商鞅实验2（PCA steering） | 8h | ~$20 (A10x推理) | 1周 |
| 商鞅实验3（FSQ round-trip） | 4h | ~$5 (推理) | 3天 |
| MVP 工具构建 | 16h | ~$15 | 2周 |
| **合计** | **36h** | **~$50** | **4周** |

## 关键路径

```
Week 1: 实验1（线性探针）→ Go/No-Go决策
                 ↓
Week 2: 实验2（PCA steering）+ 实验3（FSQ round-trip，并行）
                 ↓
Week 3: 分析实验结果 + MVP设计
                 ↓
Week 4: MVP 构建（代码语言 steering CLI）
```

## 阶段切割建议（张成市日均1h）

- **每日切分**：30min 编码/实验 + 20min 分析 + 10min 写 wiki
- **周一切换**：周一跑实验，周二分析，周三调整，周四验证，周五入库总结
- **Go/No-Go**：第一周实验1结果出来后必须做决策——准确率 < 60% 则此路线关门，转非线性方法研究
