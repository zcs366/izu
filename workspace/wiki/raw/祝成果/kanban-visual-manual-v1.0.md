## 📌 看板是什么？

**看板 = 一张电子白板**，上面贴着你所有要做的事。

每件事是一张"卡"：**等待做 → 正在做 → 做完了**。

你看板上有什么，挑一张，开干，做完划掉。

> **跟你的关系：** 军师诊断你「精力太散，一直在开始很少完成」——看板就是治这个的。一件事上了板，跑不掉忘不了。

---

### 🧩 打个比方

你家冰箱门上贴了3张便签纸：
- "明天交水电费" → 交完撕掉
- "周末买酱油" → 买完撕掉
- **Kanban 就是把冰箱门搬到电脑上，电子便签纸，撕不丢**

## 一、每天怎么用？三步走

### 👀 第一步：看一眼今天的任务

打开终端（黑色的那个窗口），输入：

```
hermes kanban list
```

屏幕上就会显示你的所有任务卡。每张卡前面有个编号（比如 `t_9148914b`），后面写着任务内容和状态。

重点关注 **ready** 标签——意思是"可以干了"。

---

### 🏃 第二步：开干！做完了标记完成

选一张卡，动手去做。做完了标记：

```
hermes kanban complete 任务编号
```

**或者更简单：** 直接跟我说"军师，XX 做完了"，我来帮你标记。

---

### ➕ 第三步：有新事？加上去

突然想到还有什么事要做，立刻加到板上，就不怕忘：

```
hermes kanban create "任务名称"
```

**或者跟我说：** "军师，加一张卡——明天去菜市场买菜"

---

## 二、遇到状况怎么办？

### ⛔ 卡住了：做到一半等别人回复

比如等老王确认价格，没法继续。标记一下，不耽误事：

```
hermes kanban block 任务编号 "等老王确认报价"
```

**跟我说：** "军师，XX 卡住了，等老王回话"

---

### 🔓 解除了：可以继续了

老王回复了，继续干：

```
hermes kanban unblock 任务编号
```

**跟我说：** "军师，可以继续了"

---

## 三、任务状态流转图

一张卡的"生命旅程"：

```
💡 想法 → 📝 待办 → ✅ 就绪 → 🏃 进行中 → 🎉 完成
                                          ↘  ⛔ 卡住了 → 🔓 解除了 → 回到就绪
```

**你只需要关注：** 哪些是 **ready**（可以干），哪些是 **done**（干完了）。

## 四、常用命令速查

| 你想干嘛 | 在终端输入 | 更简单的办法 |
|---|---|---|
| 👀 看看有什么要做 | `hermes kanban list` | "军师，今天有什么任务？" |
| 📋 看统计 | `hermes kanban stats` | "军师，板子什么情况？" |
| ➕ 加新任务 | `hermes kanban create "名称"` | "军师，加一张卡——XX" |
| ✅ 做完了 | `hermes kanban complete 编号` | "军师，XX 做完了" |
| ⛔ 卡住了 | `hermes kanban block 编号 "原因"` | "军师，XX 卡住了" |
| 🔓 解除卡住 | `hermes kanban unblock 编号` | "军师，可以继续了" |
| 📖 看详情 | `hermes kanban show 编号` | "军师，那张卡写了什么？" |
| 📝 写备注 | `hermes kanban comment 编号 "内容"` | "军师，帮我记一下：XX" |

## 五、经常遇到的疑问

**❓ 我看不到终端（黑窗口）怎么办？**
没关系。你就直接跟我对话说你想做什么，我来操作看板。

**❓ 任务编号（t_xxxx）太长记不住**
不用记。你跟我说"那个创建 skill 的任务做完了"，我就知道是哪张卡。

**❓ 我今天突然不想做板子上的事**
那就换。看板的目的是帮你管理任务，不是绑架你。随时加新卡、换顺序。

**❓ 做了一半被孩子打断，回不来了**
把那张卡 block 掉（卡住了），写上"被孩子打断"。回头有空了 unblock 继续。不会丢。
