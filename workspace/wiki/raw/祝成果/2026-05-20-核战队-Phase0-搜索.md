# 核战队 Phase0 搜索

## 选题1（izu方向）
**Agent 记忆系统的 skill 抽象化与代码语义编码的交叉点**

### 发现1
MemSkill 的 skill-conditioned generation 本质上是把记忆操作「代码化」——每个 skill 是一段可组合、可进化的可执行单元。这跟 zu 把 Agent 行为编译成代码的思路高度同构。问题：skill bank 的表示本身是否可以压缩？如果 skill 可以被编码到隐空间，代码压缩的成果可以直接反哺 Agent 记忆系统。

### 发现2
Memento-Skills（VentureBeat 报道）让 Agent 在不重训练的情况下重写自身 skill，使用 evolving external memory。这种「运行时 skill 进化」与 ITA 的「代码语义不变压缩」在形式上有对称性——一个是保持语义的可变执行，一个是保持语义的不可逆压缩。

## 选题2（ITA方向）
**Round-Trip Correctness 作为代码压缩保真度评估框架**

### 发现1
RTC 的核心思想：code→description→code 往返。对于代码压缩，可以直接映射为：code→compressed→decompressed→compare。RTC 的无监督特性意味着不需要人工标注压缩质量，天然适合作为 ITA 的基线评估。

### 发现2
Google DeepMind 的 RTC 代码（icml2024-roundtrip-correctness）已经开源。它包括两组实现：代码合成 RTC 和代码编辑 RTC。其中代码编辑 RTC 更接近压缩场景——给定输入代码，让模型编辑后验证语义等价性。
