# 惠施

## 概念：代码语义（Code Semantics）

**操作性定义**：代码在**给定输入下的执行行为与输出结果的等价关系**。不是词法/语法层面的相似。

**可测量指标**：
- 输入-输出对等价性：∀ input ∈ 定义域, f_original(input) = f_compressed(input)
- 若无法穷举（实际不可能），采用采样测试 + RTC往返验证

---

## 概念：代码语义不变压缩

**操作性定义**：一个变换 T: code → compressed → code'，使得对定义域内随机采样的输入，code' 的行为与 code 行为等价且可验证。

**可测量指标**：
- **Round-Trip Success Rate（RTSR）**：随机采样 N 组输入，对每组运行原始代码和压缩后代码，若输出一致计为成功。RTSR = 成功数 / N。
- **CodeBERTScore 语义距离**：压缩前后代码的 CodeBERT 嵌入余弦相似度，阈值 ≥ 0.95 视为保真。
- 注意：RTSR 是硬指标（功能等价），CodeBERTScore 是软指标（语义接近），两者需要联合使用。

---

## 概念：压缩（Compression）

**操作性定义**：将代码从原始表示（AST tokens / 字节码 / 源码）映射到更低维度的表示（隐空间向量 / 量化码本），使得存储/传输成本降低。

**可测量指标**：
- **压缩率** = 原始比特数 / 压缩后比特数
- **边界注意**：FSQ 的隐空间维度 d < 10，每维量化到 n 个值，码本大小 = n^d。如果用 float32 存每个量化值，压缩后尺寸 = d × 32 bits vs 原始代码的字节数。只有在 d 很小且量化粒度合理时才真正压缩。

---

## 概念：Steering 成功

**操作性定义**：在压缩后的隐空间中，对隐变量做定向修改（steering），解压后代码产生预期的行为变化。

**可测量指标**：
- **Steering Success Rate（SSR）**：对 N 次 steering 操作，解压后代码行为变化与预期的方向一致的比例。
- **Steering Precision**：实际行为变化与预期行为变化的语义距离（用 CodeBERTScore 或功能测试）。

---

## 概念：理解（Understanding）

**操作性定义**（ITA 语境）：压缩编码器能够在隐空间中捕捉代码的功能结构而非表面格式。

**可测量指标**：
- **语义聚类精度**：功能等价的代码（不同写法）在隐空间中是否聚集在一起，功能不同的代码是否分离。
- **线性探测准确率**：从隐空间向量能否线性分类出代码的功能类别（如排序算法 vs 搜索算法）。
