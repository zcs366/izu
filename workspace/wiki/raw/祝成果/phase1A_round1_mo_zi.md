# Phase 1A — ITA 6轮合议

## Round 1: 墨子（形式化验证）
输入：惠施的概念澄清

### 形式化框架

**命题1：LRM推理为有限状态马尔可夫过程**
令 LRM 为自动回归生成器 M: S → Δ(V)，其中 S 为状态空间（前文token序列），V为词汇表。推理过程为在S上的随机游走，终止于<eos>标记。

**定义 1（推理稳定性）**：对于一个复杂度参数 c 的问题族 P_c，M 在 P_c 上的推理稳定当且仅当：
∀ε>0, ∃N>0, 对于所有采样次数 n>N，答案准确率的方差 Var(A_n) < ε

**定理 1（复杂度阈值存在性）**：存在复杂度 C* 使得：
- 当 c < C* 时，M 在 P_c 上推理稳定
- 当 c ≥ C* 时，M 在 P_c 上推理不稳定（方差发散）
（证明思路：利用马尔可夫链的混合时间与问题组合深度的关系——当链的混合时间超过推理预算时，稳态分布不再可达）

**定义 2（推理投入函数）**：设 I_M(c) 为模型在复杂度c的问题上生成的推理token数的期望值。

**观察 1（反向内推）**：Apple实验表明 I_M(c) 在 c < C_th 时递增，在 c > C_th 时递减。即：
∂I_M/∂c > 0 for c < C_th, ∂I_M/∂c < 0 for c ≥ C_th

**猜想 1（元认知缺失假说）**：LRM不具备评估自身推理进展的元认知模块。推理投入由隐状态的表征不确定性间接驱动，当不确定性超过阈值时，模型"转换策略"——从持续推理转为直接生成（缩短输出）。形式化：存在不确定性阈值 U*，当 E[uncertainty|s_t] > U* 时，M以概率 p > 0.5 进入"快速输出模式"。

### 形式化验证的实验方案

**验证 1**：控制推理预算（max_tokens），验证在预算充裕时反向内推是否消失。
- 预期：如果不消失，则非预算约束问题，而是算法层面的问题

**验证 2**：通过激活监测（probing），在推理token序列中检测"不确定性表征"的演化。
- 预期：在c > C_th时，模型内部表征的不确定性在推理早期即达到峰值

**验证 3**：检验三个性能体制是否在token-复杂度平面上形成明确相图。
- 假设：存在(t,c)空间中的两个相边界——从体制1到2再到3的转换

### 形式化框架的局限
- 当前LLM的非马尔可夫性：注意力机制使模型拥有对所有前文token的访问，严格来说并非马尔可夫
- 但实际推理过程中，长程依赖的衰减可能使一阶近似足够
