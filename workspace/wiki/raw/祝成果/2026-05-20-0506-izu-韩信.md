# 韩信 · 技术远景

## 对izu 3-6个月方向的影响

### 当前izu画像（2026-05-20）
- 单模型部署（deepseek-v4-flash）
- 文件系统记忆（WORKING.md + 记忆文件）
- 工具调用（terminal/文件/搜索等）
- 无技能库、无自改进循环

### 3个月后画像（2026-08）
```
izu v3架构（预计）
├── 推理核心（deepseek-v4-flash 或更新）
├── 技能系统
│   ├── 本地技能库（SKILL.md格式，~50个）
│   ├── MCP工具桥接（外部服务集成）
│   └── 技能信任评分（>90分才自动加载）
├── 记忆系统
│   ├── 工作记忆（当前上下文的摘要）
│   ├── 长期记忆（跨session，decay-weighted向量检索）
│   └── 记忆基准（LoCoMo自我评测）
└── 自改进循环（每日）
    ├── session日志挖掘
    ├── 模式发现（重复失败/成功模式）
    └── skill更新（自动修正错误模板）
```

### 6个月后画像（2026-11）
```
izu v4
├── 多模型路由（不同任务用不同模型）
├── 技能生态系统
│   ├── 用户自助创建技能（自然语言→SKILL.md）
│   ├── 技能组合（compound skills）
│   └── 技能共享市场（类似Anthropic Skills目录）
├── 记忆系统
│   ├── 跨会话身份（同人不同session的身份一致性）
│   └── 时间抽象感知（"上周说过什么"）
└── 元认知（HyperAgents风格）
    ├── 自我改进策略学习
    └── 跨领域策略转移
```

## 技术阶梯

```
Step 1（2周）: SKILL.md解析器 + 基础加载
    → 最低可行技能系统
Step 2（4周）: MCP客户端 + 技能信任过滤
    → 可加载外部技能
Step 3（6周）: 向量记忆（基于Mem0架构）
    → 跨session记忆
Step 4（8周）: 每日自改进循环
    → session总结→skill更新
Step 5（12周）: 自我评测（LoCoMo基准）
    → 可量化进步
Step 6（24周）: 元认知策略学习
    → 接近HyperAgents能力
```

## 外部变化需纳入
1. **模型迭代加速**（METR时间地平线每4月翻倍）→ izu的架构需支持模型热替换
2. **技能生态的碎片化**（多厂商技能标准）→ izu应选择开放标准（SKILL.md + MCP）
3. **Agent安全成为热点**（26.1%漏洞）→ izu的安全设计是差异化优势
