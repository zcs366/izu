# 鲁班·工程可行：Pulse Forget 落地评估

## 判定：✅ 能做

### 核心组件已就位
1. `izu_session_memory.py` 已有Ebbinghaus遗忘曲线（decay_score, 半衰期24h, 阈值0.15）
2. `izu_working_memory.py` 已有工作记忆Top-K队列
3. `izu_memory_maintenance.py` 已有每6小时定时维护
4. Hermes `MemoryProvider` ABC + `MemoryManager` 提供插件接口
5. `memory_tool.py` 已有CRUD操作

### 最大Gap：压缩管线
`agent/context_compressor.py` 只做上下文窗口级压缩，不做记忆级持续压缩。这是token-30%目标的最大增量来源。

### 重复造轮子风险：低
| 竞品 | 已做 | 没做 |
|------|------|------|
| Mem0 | Memory Decay（软重排，不删除） | 遗忘决策引擎、冲突消解 |
| Mastra OM | Observer+Reflector压缩 | 遗忘曲线、主动遗忘 |
| Supermemory | forget_memory API | 遗忘决策算法 |
| A-Mem | Zettelkasten笔记构建 | 只增不删 |

**izu核心差异化：主动遗忘决策引擎——这是独一无二的，没有任何现有框架实现。**

### 新建模块
`izu_forget_engine.py`, `izu_observer.py`, `izu_reflector.py`, `izu_memory_api.py`, `izu_recycle_bin.py`
