# 韩信 — 技术远景官

## 这项研究对izu 3-6个月方向的影响

### 直接影响：记忆架构分层
**当前（v0.13）→ 3个月后 → 6个月后的技术阶梯**

```
现在（2026-05）:
  MEMORY.md (flat text)
  USER.md (flat text)
  ContextCompressor (token-level, 50%阈值触发)
  External Memory Providers (插件式)

3个月后（2026-08）:
  MEMORY.md → 分层存储（episodic + semantic + procedural）
  USER.md → 带时间戳和衰减因子的用户画像
  ContextCompressor → 语义级压缩（依赖ITA产出）
  External Memory Providers → Mem0集成（作为可选后端）

6个月后（2026-11）:
  统一记忆层：任何输入（代码、对话、反馈）自动分类 → 
    重要→存入semantic层（FSQ压缩编码）
    临时→episodic层（按时间衰减）
    可执行→procedural层（Skill库）
  检索：多信号融合（语义相似度 + 时间权重 + 重要性评分）
```

### 需要纳入的新技术路线
1. **Mem0的记忆检索API**：如果决定集成，izu需要适配其write-manage-read接口（而不是自己造轮子）
2. **FSQ离散编码**：izu的知识胶囊格式应该与ITA的代码压缩格式共用同一套离散编码方案
3. **Rate-Distortion理论**：izu的压缩层应该为每种记忆类型设置不同的率失真目标

### 终局画像调整
**原终局**："一个能记住所有对话的Agent"
**新终局**："一个知道该记住什么、该忘掉什么的Agent"

核心能力从"存储容量"变为"信息筛选+压缩"。这不只是技术优化，而是对Agent智能的根本理解——AGI不是记住一切，而是区分signal和noise。
