# 📡 izu方向搜索结果

## 选题: Agent自进化记忆架构

### 发现1: MemRL — 运行时强化学习
**"MemRL: Self-Evolving Agents via Runtime Reinforcement Learning on Episodic Memory"** (arXiv 2601.03192, Jan 2026)
- 核心创新：Two-Phase Retrieval = 语义相关候选(Phase1) → 基于Q-value的效用选择(Phase2)
- 将frozen LLM的稳定推理与plastic evolving memory显式解耦
- HLE/BigCodeBench/ALFWorld/Lifelong Agent Bench上超越SOTA
- **对izu的关键影响**: 非参数化方法 → 不需要权重更新就能持续改进；Runtime RL解决stability-plasticity困境

### 发现2: Mem0 — 2026年4月状态
**Mem0 2026年4月更新**: LoCoMo 92.5 / LongMemEval 94.4 / BEAM 1M 64.1
- 两个架构变化驱动提升: (1) 单次ADD-only提取 (2) 多信号检索（语义+关键词+实体）
- 20种向量数据库、21个框架集成
- 最难未解决问题：跨会话身份、大规模时间抽象、记忆陈旧性

### 发现3: Agent记忆调查
**"Memory in the Age of AI Agents: A Survey"** → Forms × Functions × Dynamics统一分类法
- Token-level / Parametric / Latent三种记忆形式
- Factual / Experiential / Working Memory三种功能
- Formation / Evolution / Retrieval三种动态
- 为izu提供架构设计参考：izu应采用token-level + 混合(experiential+working)记忆
