# 子产 — 需求判断/研究方向

## 双身份结论

### 身份1：需求判断官
| 问题 | 结论 |
|------|------|
| 该不该做？ | ✅ **做轻量版，不做重型版**。不做则izu在6-12个月内被通用Agent替代 |
| 为谁做？ | **仅用于张成市的izu** — 不做论文/产品/框架 |
| 不做会怎样？ | 确定性损失：izu使用体验随时间退化，被METR每4个月翻番的Agent能力边缘化 |
| 研究目的？ | **让张成市的1h/日产出≈别人的3-5h/日**，让izu「越用越聪明」 |

### 身份2：研究方向官
| 问题 | 结论 |
|------|------|
| 关键问题？ | ①最小可行进化单元=记忆级(forget/compact)+提示级(reflection loop) ②遗忘策略不靠RL训练 ③FAMA+Token效率+隐式反馈三指标评估 |
| 方向对不对？ | ✅ 方向对，但路径从「让代码进化」改为「让记忆进化」，从「追benchmark」改为「追用户效率」 |
| 最大冲突 | HyperAgents的「自指循环」才是真自进化。izu做的在学术定义下只是「记忆管理」而非「自进化」。但用户价值才是标准。 |
| 2周能做出什么？ | AST键值对记忆体MVP + Ebbinghaus独立模块 + 首份记忆健康报告（~10h，~$210） |
