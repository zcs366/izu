# 鲁班（工程可行官）— ITA Round 3

## 在理论约束内的技术实现方案

### 理论约束回顾（墨子）
- 目标代码片段 ≤ 200 tokens
- 目标语义保真度 ≥ 95%
- FSQ量化维数 ≤ 16 维
- 比特率 ≥ 每token 2 bits（对 >95%保真度）

### 技术方案

**编码器选择**:
```
首选: CodeBERTa (RoBERTa-base, 6层, ~125M参数)
  - 足够编码短代码语义
  - 隐表征维度 768 → 可降维至 64-256
  - pip install transformers, 直接可用
备选: graphcodebert (需额外图结构输入，复杂度倍增)
```

**量化器选择**:
```
FSQ实现: GitHub已有开源实现
  - pip install finite_scalar_quantization 或手写
  - 配置: levels=[8,8,8,8] (4维, 每维8级 = 12 bits总codebook)
  - 或 levels=[5,5,5,5] (4维5级 = ~9.3 bits)
```

**解码器选择**:
```
同CodeBERTa解码器头
  - 从隐表征→token序列
  - 添加线性投影层将隐表征映射回词表维度
```

**Steering组件**:
```
训练线性探针: 收集"是否包含try-except"等二值标签的隐表征
  → 计算方向向量 = avg(正例) - avg(负例)
  → 在生成时沿方向偏移隐表征
```

### 工程可行性判断

**✅ 可行**，但存在以下约束：

1. **CodeBERTa的隐空间是否对齐代码语义？** — 未知。这是实验1要回答的问题
2. **FSQ的离散化对下游任务的影响** — 需要实验2验证
3. **steering方向的语义一致性** — 线性探针可能不够，需要对比实验
4. **不满足理论约束的情况** — 如果代码长度 >200 tokens，需要CoLaR式动态压缩

### 技术路线图
```
Week 1: 环境搭建 + CodeBERTa round-trip基线 (实验1)

```
