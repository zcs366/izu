## 选题1（izu方向）
**Agent自我诊断：机械可解释性代码正确性检测在自改进Agent中的应用**

### 搜索关键词
mechanistic interpretability code correctness steering LLM agent self-improvement 2025 2026

### 发现1|发现2|发现3
1. **SAE代码正确性方向（arXiv:2510.02917）**：检测方向预测错误F1=0.821，但纠正方向引入14.66%破坏率。这意味着Agent自改进循环需要选择性干预——只在检测到错误时引导，不能持续施加。这直接影响了izu的"无感自我纠错"设计。
2. **HyperAgents的元认知转移**：改进策略可跨领域转移（机器人→数学评分），但代码正确性方向是模型内部找到的，而非手搓。启示：izu的自我改进机制应优先做"错误检测"（检测方向可靠）而非"持续纠正"（纠正方向破坏大）。
3. **MEtR时间地平线翻倍趋势**：50%可靠时间地平线50分钟，每4个月加速。意味着izu需要主动管理"何时信任Agent的自我判断"——代码正确性检测作为安全门。

## 选题2（ITA方向）
**FSQ量化在Agent记忆语义压缩中的理论边界**

### 搜索关键词
FSQ finite scalar quantization semantic compression representation agent memory 2025

### 发现1|发现2|发现3
1. **iFSQ的4 bits/dim最优平衡点**：离散与连续的最佳平衡约4 bits/dim。这对izu记忆压缩的含义是：如果Agent记忆需要压缩存储，4 bits/dim可能是理论上的最优操作点。低于此信息丢失严重，高于此边际收益递减。
2. **等间隔量化与非均匀分布的冲突**：FSQ的根本问题在于神经激活是非均匀分布的但FSQ用均匀量化。iFSQ通过分布匹配映射解决。izu的记忆系统同样面临此问题——工作记忆和长期记忆的激活分布不同，不能用同一量化策略。
3. **FSQ的双面性（离散token+连续隐变量）**：FSQ的独特价值在同时产生离散索引（对应iku的token存储）和连续值（对应语义理解）。这对izu的记忆存取策略有启示：同一表示可服务两种需求。
