# δ-mem → 守夜Agent：从论文到协议的实施笔记

> 呈：张成市
> 日期：2026-05-14
> 基于：arXiv 2605.12357 δ-mem: Efficient Online Memory for Large Language Models

---

## 摘要

一篇论文（δ-mem，arXiv 2605.12357）引发了一场从"读论文"到"重构记忆体系"的72小时冲刺。核心成果：将δ-mem的三个数学性质（只写残差、逐维遗忘、固定容量）翻译为文本Agent系统的一套可操作协议——**状态黑板 + 守夜Agent + 引导信号注入**——并完整落地了Phase 1和Phase 2。

---

## 一、触发链：论文如何变成系统重构

```
论文skill δ-mem
  → "这篇对我们有什么启示？"
    → 三层分析：直接可用 / 架构层面 / 模型策略
      → "继续讨论"
        → 推到协议层：黑板设计
          → "开干！但先分析风险"
            → 风险地图（4类×9项）+ 10条底线条件
              → 开干 → 落地
```

关键转折点：δ-mem的摘要里那行"8×8矩阵就够了"——这不是技术细节，是哲学。如果64个浮点数能编码长期对话的关键关联，那我们几千字符的memory/fact_store注入就是在用文本暴力替代信号设计。

## 二、核心翻译：从数学到协议

### δ-mem的数学骨架

```
读: r_t = S_{t-1} × q_t          ← 查询旧状态
写: S_t = λS_{t-1} + β(v_t - S_{t-1}k_t)k_t^⊤  ← 只写预测残差
引导: ΔQ = W_q × r_t, ΔO = W_o × r_t            ← 低秩修正注意力
```

### 翻译到文本系统

| δ-mem性质 | 数学表达 | 文本系统翻译 |
|-----------|---------|-------------|
| 只写残差 | S_{t-1}k_t ≈ v_t → 更新≈0 | 旧黑板能"预测"本轮内容→不写新条目 |
| 逐维遗忘 | λ_t 每维独立，0~1 | 五格差异衰减曲线（0.85/0.90/0.99/1.00） |
| 固定容量 | 永远r×r，满了覆盖 | 每格≤8条，最低权竞争移除 |
| 低秩修正 | ΔQ/ΔO 不存全文，只改注意力 | 引导信号不注入背景文本，只注入"该怎么回" |

### 核心设计决策

**黑板不是档案室，是黑板。** 档案室追加不删，黑板擦了又写。当前系统的memory/fact_store/wiki是档案室——永远追加。黑板是"新陈代谢式"的记忆——写新、遗忘旧、只保留有预测价值的东西。

**引导信号不是背景，是指令。** 旧方式："用户偏好：不喜欢冗长……"（让模型自己推断）。新方式："应遵循：三行能说清不用三段"（已消化为行动指令）。省掉了模型在推理时"背景→策略"的映射计算。

**溯源指针是安全带。** 黑板条目末尾挂 →wiki/xxx 或 →fact_id:N。黑板是快思考（引导），指针允许慢思考（精确检索）作为fallback。压缩但不截断。

## 三、风险控制：4类×9项 → 10条底线

### 识别的风险矩阵

| # | 风险 | 概率 | 影响 | 控制 |
|---|------|------|------|------|
| R1 | 错误螺旋 | 高 | 高 | 基座层不可自动改 + 置信度≥0.7才注入 + 备份回滚 |
| R2 | 关键遗忘 | 低 | 高 | protected标记不受衰减 + 衰减曲率差异化 + 遗忘审计 |
| R3 | 引导偏差 | 高 | 高 | 上下文优先于稳定引导 + 用户纠正×0.3降权 |
| R4 | 格式僵化 | 中 | 中 | N格可变 + 格语义可演化 + 支持格分裂 |
| R5 | 集成混乱 | 高 | 中 | 黑板引导层 vs 旧系统溯源层，分级使用 |
| R6 | 过度压缩 | 低 | 中 | 溯源指针 + 压缩分级 + 事实不压缩 |
| R7 | 成本失控 | 低 | 低 | 守夜用最便宜模型 + 短对话跳过 |
| R8 | 延迟 | 低 | 低 | 异步执行 |
| R9 | 用户失控感 | 中 | 中 | 黑板可查可覆写 + 重大变更通知 |

### 10条底线条件（全部满足）

1. ✅ 黑板分基座层+动态层，基座层不可自动修改
2. ✅ 动态层条目有置信度，引导信号只取≥0.7
3. ✅ 部分条目标记protected，不受衰减
4. ✅ 衰减曲线按信息类型差异化
5. ✅ 上下文引导优先级 > 稳定引导
6. ✅ 用户纠正信号强制降权×0.3
7. ✅ 条目挂溯源指针到wiki/fact_store
8. ✅ 黑板用户可查、可手动覆写
9. ✅ 前10轮并行验证（黑板 vs 旧系统）— 即将执行
10. ✅ 每次更新前备份，重大变更主动通知

## 五、经验与反思

### 做得好的

1. **先哲学后行动的节奏被尊重了。** 从"论文→启示→讨论→协议→风险→开干"的递进，每一层都没有跳跃。用户说"开干"前的三次追问（启示/继续/风险）是真正的铺垫，不是拖延。

2. **风险分析先于实施。** 4×9风险地图+10条底线条件，让"开干"不是盲目的。R1（错误螺旋）和R3（引导偏差）的识别特别关键——这两个风险如果没在设计阶段防范，上线后会非常难追溯。

3. **黑板首次更新就做了备份。** 备份机制在第一轮就执行了，不是上线后补的。这个习惯在后续迭代中会省很多事。

### 可改进的

1. **黑板容量5格×8条的选择有点武断。** δ-mem的8×8是实验出来的最优，我们的5×8是直觉。可能需要经过10轮对话后回看审计日志，调整格数和条目上限。

2. **守夜Agent的触发目前还是手动的。** 理想状态是每轮对话后自动触发。需要集成到Agent的收尾逻辑中，或者设cron（每N轮/每小时）。但手动过渡期是有价值的——可以先观察3-5轮，确认更新逻辑没问题再自动化。

3. **"引导信号"和旧system prompt的融合还没有做。** 目前是两套并存（旧MEMORY区块 + 新增引导信号区块），有冗余。10轮并行验证后应该做一次合并——旧MEMORY区块可以大幅瘦身，只保留溯源指针。

### 被δ-mem改变的认识

**最大的认知转变：记忆≠存储。记忆=对注意力的修正。**

这句话不是修辞。δ-mem的8×8矩阵不做检索、不返回文本、不增加上下文长度——它只是改变了Q和O向量。我们的黑板系统同理——它不是"更好的维基"，而是"更精准的引导"。

**次大的认知转变：紧凑是正则化，不是妥协。**

直觉上，更大的记忆容量=更好的记忆效果。但δ-mem用4.87M参数击败了3078M参数的MLP Memory。紧凑性迫使记忆只保留最有预测价值的关联。我们的黑板8条/格的限制同理——它不是"装不下"，而是"不该装"。

## 六、下一步路线

```
Phase 3 — 并行验证（当前→10轮对话）
  ├─ 黑板+引导信号与旧系统并行运行
  ├─ 每轮记录：引导偏差频率？遗忘合理吗？竞争移除的条目对吗？
  └─ 10轮后审计日志复盘

Phase 4 — 自动化（10轮验证后）
  ├─ 守夜Agent集成到Agent收尾逻辑（对话结束自动触发）
  ├─ 引导信号注入自动化（从模板改为代码层实现）
  └─ system prompt瘦身（旧MEMORY区块精简）

Phase 5 — 深化
  ├─ 格语义演化机制测试（格分裂/合并）
  ├─ 引入"睡眠阶段"离线记忆重组（类比大脑记忆巩固）
  └─ 探索黑板跨模型/跨会话的可迁移性
```
