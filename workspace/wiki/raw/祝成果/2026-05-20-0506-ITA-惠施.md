# 惠施 · 概念辨析

## 研究对象
代码语义压缩：将代码的语义信息（功能、逻辑、上下文含义）编码为紧凑表示，同时保持足够语义保真度以重构或理解。

## 核心概念的操作性定义

### 1. 「代码语义」
- **非操作性定义**：代码的意思/功能
- **操作性定义**：在给定输入-输出对上的行为等价性。两段代码语义相同 ⇔ 对所有合法输入产生相同输出（扩展等价）。**可测量**：用测试套件的通过率差异衡量语义距离。

### 2. 「理解」
- **非操作性定义**：模型知道代码在做什么
- **操作性定义**：模型在代码补全、bug检测、功能描述三个任务上的准确率。**可测量**：HumanEval通过率、bug检测F1、功能描述BLEU。

### 3. 「Steering成功」
- **非操作性定义**：成功引导模型行为
- **操作性定义**：干预后模型在目标行为上的表现变化。**可测量**：
  - 目标方向：干预后目标行为准确率 - 干预前目标行为准确率（正值表示成功）
  - 副作用：干预后非目标行为准确率 - 干预前非目标行为准确率（负值表示有害）
  - **成功标准**：目标增益 > 0 且 副作用 ≤ 5% 下降

### 4. 「压缩」
- **非操作性定义**：减少表示大小
- **操作性定义**：压缩率 = 压缩后位数/原始位数。**理论下界**由率失真函数 R(D) 给出。给定语义保真度 D（用行为等价性衡量），最小所需比特率 R(D) 不可突破。

### 5. 「语义保真度」
- **操作性定义**：压缩-解压缩后代码与原始代码的行为等价性。用交叉测试：原始代码生成测试用例 → 解压缩代码执行 → 通过率。

### 6. 「率失真边界」
- **操作性定义**：在给定语义保真度 D（行为等价准确率）下，理论最小压缩比特率 R(D)。来自率失真理论的香农下界。

### 概念间关系
```
代码 → 语义编码器 → 压缩表示 → 语义解码器 → 重构代码
   ↑                    ↑                      ↓
语义理解          率失真边界 R(D)         行为等价测试
```
