# 韩信 — 技术远景

## 3-6月后 izu 应该长什么样？

### 现状画像（2026-05-20）
izu 是一个 agent 框架：可调用 tool/skill，有有限的记忆，能完成单轮任务（研究编排、调研、文件操作）。**没有自进化能力，没有长期结构化记忆。**

### 3个月后画像（2026-08）
```
izu v2.0
├── 技能系统: Skill Library (外部) + AutoSkill (内部自提取)
│   ├── 运行时从使用中自动提取 skill 模板
│   └── Skill Retrieval Augmentation → 实时匹配最佳 skill
├── 记忆系统: Hierarchical Memory
│   ├── Working Memory (当前会话)
│   ├── Episodic Memory (历史会话摘要)  
│   └── Semantic Memory (总结的知识/规律)
└── 反馈循环: Reflection → Optimization → Validation
    ├── 每轮任务后自动反思
    └── 优化后的 skill 自动入库
```

### 6个月后画像（2026-11）
```
izu v3.0
├── 元学习层: 根据任务类型自动调整 agent 行为
├── 隐空间记忆: 经验 → 隐向量 → 高效检索
├── 跨会话迁移: 今天的经验自动迁移到明天的任务
└── 知识伙伴模式: 从「你问我答」到「主动建议」
```

## 新技术路线需要纳入

### 立即纳入
1. **Agent Skills 标准 (SKILL.md 规范)** — 2025年12月成为开放标准，62K GitHub stars。izu 应该兼容这个格式
2. **MCP 协议** — 2024年11月发布，2025年12月捐赠给 Agentic AI Foundation。izu 的 tool 接口应该兼容 MCP

### 观察纳入
3. **Skill Retrieval Augmentation** — arXiv 2604.24594 (2026年4月): 检索增强的 skill 组合提升 agent 性能。完全契合 izu 的路线
4. **Progressive Context Loading** — skill 规范的核心机制：按需加载上下文，解决 context window 限制。izu 的上下文管理需要这个

## 终局画像调整

| 方向 | 原有判断 | 调整后 |
|------|----------|--------|
| Skill 来源 | 人工定义 | 自动提取 + 外部检索 |
| 记忆层级 | 单层 | 三层（Working/Episodic/Semantic）|
| 进化速度 | 用户驱动 | 自主进化 + 反馈循环 |
| 生态兼容 | 自研 | 兼容 MCP + Skills 开放标准 |
