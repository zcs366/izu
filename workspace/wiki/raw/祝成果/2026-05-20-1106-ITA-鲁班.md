# 鲁班 —— 工程可行官

## 理论约束检查

**墨子裁定**: 目标从「完美重建」修正为「可控失真下的steering可操作性」，压缩率上限≈2x。
**约束条件**:
- 编码码率 ≥ 3.2 bits/token（10%失真容忍）
- AST等价重建不作为硬约束
- Steering向量在压缩空间的有效性需实验验证

## 技术方案

### 方案A: CodeBERT + RFSQ + 轻量Decoder（优选）
**架构**:
```
Code token → [CodeBERT encoder] → [RFSQ quantizer] → [Linear projection] → [Decoder MLP]
```
- 编码器: CodeBERT-base (110M参数) — 预训练完毕，不需训练
- 量化器: RFSQ，codebook size=64，codebook dim=32，residual stages=2
- 解码器: 2层MLP, hidden 256 → 768
- 总参数量: 解码器 < 1M参数

**理由**: RFSQ保留FSQ的简洁性且无codebook collapse问题。2个residual stages对2x压缩率足够。

### 方案B: EasySteer on DeepSeek-Coder
**架构**:
```
[DeepSeek-Coder (vLLM)] ← [EasySteer plugin] ← [steering vector pool]
```
- 不需训练或微调
- EasySteer的5.5-11.4x加速使steering开销可忽略

### 技术选型依据

| 组件 | 选型 | 理由 |
|------|------|------|
| 代码编码器 | CodeBERT (GraphCodeBERT) | 预训练，无需训练成本 |
| 量化方案 | RFSQ | 无codebook collapse，工程简单 |
| Steering框架 | EasySteer + vLLM | 现成可用，生产级性能 |
| 解码器 | Lightweight MLP | 参数少，训练快 |
| 评测 | RTCE基准 | 已公开，可复用 |

### 不满足理论约束的检查
- 如果实验显示steering在压缩后的空间中衰减 > 30% → 需在量化前/量化后各存一份steering向量 → 存储成本翻倍但不影响码率约束
- 如果EasySteer与CodeBERT的接口不兼容 → 使用repeng（更轻量）作为fallback，只有3个核心文件

### 工具清单
- Python 3.10+
- PyTorch 2.0
- vLLM + EasySteer (pip install vllm easysteer)
- CodeBERT: transformers + codebert-base
- RFSQ: from rob_res_fsq import RFSQ
- RTCE: pip install roundtrip-code-eval
