# izu Phase0 搜索

## 选题
**MemSkill 框架与 Agent 自我进化记忆系统**

### 发现1
MemSkill（Zhang et al., 2026）提出 span-level skill-conditioned memory generation，替代传统 turn-level hand-designed memory 操作。核心创新：将记忆提取从「每轮固定操作」改为「根据当前 span + 已检索记忆动态选择 skill 组合」。在三项基准（LoCoMo、LongMemEval、ALFWorld）上全面超越 MemoryBank、A-MEM、MemoryOS。

### 发现2
MemSkill 的 skill bank 是活的——designer 组件定期从 hard cases 中提炼新 skill 并优化旧 skill。且 skill bank 跨模型泛化（LLaMA 训练的 skill bank 直接迁移到 Qwen 仍有效）。这直接对应 zu 的「自进化」需求。

### 发现3
STELLA（Self-Evolving LLM Agent Architecture）提供了另一种自进化路径：通过持续反思和改进 reasoning/planning/tool-use 能力来进化，不依赖外部重训练。与 MemSkill 互补——MemSkill 管记忆层，STELLA 管推理层。
