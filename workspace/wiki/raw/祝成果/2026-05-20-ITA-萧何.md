# 萧何

## 资源盘点

### 可用资源
- **人力**：张成市，日均约 1 小时可投入
- **预算**：约 $925（Google Cloud / API 费用）
- **基础设施**：
  - WSL 环境（Ubuntu + Python）
  - 无专用 GPU（需用 Google Colab 免费版或 CPU 推理）
  - CodeBERT / CodeBERTScore 可 CPU 推理（125M 参数）
- **时间窗口**：试行期 2026-05-19 → 2026-05-26（共 7 天）

### 资源约束
- 日均 1 小时 ≈ 周总工时 7 小时
- 商鞅的实验设计 20 工时 → 需要 3 周的日均 1h
- 或者集中周末突击（建议选项）

---

## 阶段拆解 & 工时分配

### Phase A：代码环境搭建 + 数据准备（4 小时，1 周内）
| 任务 | 工时 | 依赖 |
|------|------|------|
| 安装 CodeBERT + CodeBERTScore | 1h | 无 |
| 准备 HumanEval 子集 + 等价改写 | 1.5h | 无 |
| 实现 FSQ 量化模块（numpy） | 1h | 无 |
| RTC 评估流水线集成 | 0.5h | 上述完成 |

### Phase B：核心实验（10 小时，第 2 周）
| 任务 | 工时 | 依赖 |
|------|------|------|
| PCA 降维 + FSQ 量化 9 种配置 | 2h | Phase A |
| CodeBERTScore 语义保真度计算 | 3h | Phase A |
| 等价代码分类实验（AUC） | 3h | Phase A |
| 率失真曲线绘制 | 2h | 上述数据 |

### Phase C：分析 + 决策（6 小时，第 3 周）
| 任务 | 工时 | 依赖 |
|------|------|------|
| 结果分析与可视化 | 2h | Phase B |
| 报告撰写 | 2h | 分析完成 |
| 下一步决策（P0/P1/P2） | 2h | 报告 |

### 总工时
4 + 10 + 6 = **20 工时** ✓ 满足商鞅设计

---

## 关键路径

```
Phase A ──> Phase B ──> Phase C
 4h          10h         6h
```

**关键路径总长：20 工时**
**最小日历时间**：若工作日日均 1h + 周末 5h，最快 2.5 周
**最优排期**：集中 3 个周末（周六 6h + 周日 4h），3 周完成

## 排期建议（张成市日均 1h 版本）

```
周一 (1h): 环境搭建
周二 (1h): 数据集准备 + FSQ 实现
周三 (1h): 实验脚本编写
周四 (1h): 实验 1/4 运行 + 检查
周五 (1h): 实验 2/4 运行 + 检查
周六 (3h): 剩余实验批量运行
周日 (2h): 分析 + 报告

共 10 天，实际 10 工时 → 能完成 Phase A+B 核心实验
Phase C 分析报告在次周完成
```

**结论：在日均 1h 约束下，20 工时的实验可在 10-14 个日历日内完成。**
