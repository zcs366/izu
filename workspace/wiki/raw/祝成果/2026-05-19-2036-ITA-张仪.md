# 张仪·最强攻击官

## 单点失败：PCA降维破坏ModernBERT语义保持能力

致命链式因果：
ModernBERT (768维语义) -> PCA降维(d维) -> PCA是线性投影，丢失非线性语义结构 -> FSQ量化 -> 率失真gap无法缩小 -> Steering因果性(r>=0.8)永远无法达标

无解矛盾：
- 低维(d<=8)：PCA破坏语义 -> Steering失败
- 高维(d>=64)：FSQ码本爆炸(4^64) -> 不可训练

## 降级方案

PCA -> UMAP（最轻量替换，3行代码） -> 若仍不够 -> 语义蒸馏自编码器

门控检查：第1周实验后计算PCA_retention = cos_sim(原embedding, PCA重构embedding)
- >=0.85 -> 继续原方案
- <0.85 -> 触发降级
