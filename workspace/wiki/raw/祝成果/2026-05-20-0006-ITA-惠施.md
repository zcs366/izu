## 核心概念操作性定义

### 1. "代码语义"的操作性定义
**定义**：给定两段代码片段 A 和 B，A 和 B 语义等价当且仅当：
- 对任意合法输入集合 I，A(I) 的输出等于 B(I) 的输出（函数等价），且
- A 和 B 的控制流图在抽象语法树（AST）层次的同构类中属于同一语义群组

**可测量替代**：如果无法穷举所有 I，用测试用例覆盖 ≥ 90% 分支后的行为等价作为近似。

### 2. "理解"的操作性标准
**定义**：系统"理解"一段代码，当且仅当它可以：
- (a) 准确回答该代码的功能描述（自然语言摘要与人工标注的BLEU≥0.5）
- (b) 预测给定输入的输出（≥95%正确率）
- (c) 识别该代码中违反预期的行为（bug detection F1≥0.8）

三项同时满足才判定为"理解"。单项满足只能称为"部分理解"。

### 3. "Steering成功"的测量
**定义**：Steering成功 = 在目标方向上的行为偏移量 / 激活干预强度
- 偏移量：steering前后模型在特定代码任务上的输出差异比率
- 干预强度：注入latent的activation delta的L2范数
- 成功标准：偏移量显著 > 随机扰动（p<0.01），且干预强度在合理范围（<模型激活方差的2σ）

### 4. "压缩"的率失真边界
**定义**：代码压缩的率失真下限 = 在"语义等价"失真函数下的最小比特率
- 失真函数 d(code_A, code_B) = 0 当语义等价（按定义1），否则=1（全部失真）
- 这个0-1失真函数意味着率失真边界简化为：H(S) + epsilon，其中H(S)是语义等价类的熵
- 注意：这不是比特级压缩的率失真（Claude Shannon），而是语义层面的率失真

### 5. "离散隐空间"的大小
**定义**：FSQ/VQ-VAE的codebook size K 需要覆盖代码语义等价类的数量
- 粗略估算：Python/C的常见操作符约50个 + 典型编程模式约200个 + 控制流结构约30个 = ~300个语义等价类
- 取安全上界：K=1024，远超自然语言需要的8192，但每个类的类内差异仍需测量
