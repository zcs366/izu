# 2篇SkillGraph：阿里 vs 腾讯 — 技能库从平铺列表升级为有向依赖图

**来源**: PaperToday (微信公众号)
**核心问题**: Agent技能库平铺存储，检索靠语义相似度，能找到相关技能但不知道执行顺序。

## 问题背景

> "给AI Agent派一个活儿：去厨房找到杯子，拿起来，放到微波炉里加热，最后端到餐桌上。Agent学了不少Skill技能——找东西，操作家电，移动物品——但当它真正面对这个任务时，系统检索出一堆看起来相关的Skill，却完全不知道该先做哪一步、哪一步是哪一步的前提。"

**当前通病**: 技能平铺在列表里，检索全靠语义相似度。**能找到相关技能，但不知道执行顺序。**

## 腾讯混元 — SkillSynth (Skill Graphs)

- 将AI操作终端的过程抽象成 **"场景-技能"序列**
- 每个技能从一个前置场景指向一个后置场景，形成**有向图**
- 图中的一条路径对应一个真实的多步骤工作流

## 阿里 — SkillGraph (核心内容)

### 核心改动
不再把技能平铺存储，而是组织成一张 **有向依赖图**。

### 节点间三种边类型

| 边类型 | 含义 |
|--------|------|
| **前置依赖 (prerequisite)** | 技能A必须在技能B之前执行 |
| **增强关系 (enhance)** | 通用技能A能提升特定技能B的效果 |
| **共现关系 (co-occur)** | 技能A和B经常在同一次成功轨迹中一起出现 |

### 检索方式
- 从与当前任务相关的 **"种子技能"** 出发
- 沿着图的边做**双向扩展**：回溯找前置技能，前向搜索相关后续技能
- 最后**拓扑排序**，输出依赖有序的技能链
- Agent拿到的是 **"先做A再做B再做C"** 的清晰计划

## 图动态进化机制

### 节点层面（四种自动操作）

| 操作 | 触发条件 |
|------|----------|
| **新增** | 遇到现有技能覆盖不了的失败模式，生成针对性新技能 |
| **合并** | 图邻域高度重叠的冗余技能被合成一个 |
| **拆分** | 使用率高但成功率中等的"大而全"技能分解成更精确的子技能 |
| **废弃** | 被频繁调用但持续失败的技能直接淘汰 |

### 边层面动态调整
- 成功路径上的边权重被强化
- 新发现的技能共现关系被添加为新的 `co_occur` 边
- 过时的边被衰减剪枝

### 实验数据
- 节点数从约 **20个** 自动增长到约 **140个**
- 但活跃节点数因废弃机制**提前收敛** → 系统自动控制技能库质量，而非无限膨胀
- `co_occur` 边增长最快 → 图能自动发现人类事先不知道的技能关联

### 渐进解锁设计
> "一开始只开放最基础的 level-0 技能，等这些技能的平均成功率超过阈值后，才解锁更高层级的技能。相当于给Agent设置了一个自动课程表——先学走路再学跑步。"

## 实验结果

### 模型与场景
- 使用 **Qwen2.5-7B-Instruct**（7B开源模型）
- 三个场景：ALFWorld（家庭操作）、WebShop（网购导航）、七个搜索增强问答任务

### 核心数字

| 对比项 | 结果 |
|--------|------|
| ALFWorld vs GPT-4o | **高出42.6个百分点** |
| ALFWorld vs Gemini-2.5-Pro | **高出30.3个百分点** |
| WebShop vs GPT-4o | **高出超过48分** |
| Clean/Heat子任务 | **100%成功率** |
| WebShop vs 最强对手SkillRL | **高出11.7分** |

### 消融实验关键发现
> **"去掉图感知检索，ALFWorld直接掉了31.2分。"**
> "这不是靠更多技能或更强模型换来的提升——图结构本身就是最大的贡献因素。"

### 训练效率
- SkillGraph约 **50步后** 就超过SkillRL
- **图引导检索的prompt始终比扁平检索更短** → 图遍历只保留拓扑相关的技能，不像语义检索把所有"沾边"条目都塞进去

### 零样本泛化
- 只在NQ和HotpotQA两个数据集上训练
- 零样本泛化到另外五个数据集，仍拿到最高均值 **48.9**

## 核心结论

> **"决定Agent能力的不是技能数量，而是技能之间的结构关系。"**

### 对Agent系统团队的设计优先级调整建议
- 与其花精力往技能库里塞更多条目
- **不如先把技能之间的依赖关系搞清楚**
- 消融实验已证明：图结构的收益远大于增加技能数量
