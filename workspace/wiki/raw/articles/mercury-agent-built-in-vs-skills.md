# Agent不应该什么都靠Skill

Mercury Agent设计哲学："自带电池"——基础能力开箱即用。

内置工具：文件系统、Shell命令、Git操作、网络抓取、任务调度、预算控制、子Agent委派、记忆系统。

核心论点：Skill应增强Agent，而非弥补空心内核。成熟的Agent应有记忆、工具、权限控制、进度可见、停止按钮、预算控制、开箱可用七项核心能力。
