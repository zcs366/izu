# Agent Skill 框架正在吃掉软件开发

> 作者：Jerry，2026年5月14日

## 趋势概览：GitHub Trending 上的 Skill 热潮
- mattpocock/skills：78,943 颗星，单日涨 3,392 颗
- obra/superpowers：agentic skills framework
- agentmemory：单日涨 1,978 颗星
- danielmiessler/Personal_AI_Infrastructure：14K 星
- K-Dense-AI/scientific-agent-skills：科研方向

## Agent Skills 的定义
"Agent Skills 就是给 AI Coding Agent 用的'说明书'"
核心：把常用的 skill 标准化、可复用、可共享

## 历史类比：2015 年的 npm
从"分享文本"到"分享制品"——这一步，就是生态的起点。

## 核心飞轮机制
用 Agent 写代码 → Agent 犯错 → 把经验写进 skill → Agent 犯错更少 → 写更多代码 → 更多经验变成 skill

## Skills 生态格局
- 框架层：obra/superpowers
- 库层：mattpocock/skills, K-Dense-AI/scientific-agent-skills
- 基础设施层：agentmemory, Personal_AI_Infrastructure
- 市场层：尚未出现（最大机会）

## 关键判断
"不是最好的 skills 集合赢，也不是最好的框架赢，而是最先成为开发者默认选择的那个人赢。"
