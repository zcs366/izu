# LLM路线分化与AI产品非技术壁垒

## 核心判断

### 模型分化格局
- **未来真正通用模型只有Google Gemini和OpenAI**
- **Anthropic** → Coding/Agentic（几乎放弃多模态、ToC）
- **Thinking Machines Lab**（Mira）→ 多模态/ToC/产品优先
- **xAI Grok** → 超大集群算力求突破
- **Meta SI** → 短期难进全球前三

### Anthropic的Coding赌注
- ARR：2023年底<1亿 → 2024年底9.5亿 → 2025年年化>120亿 → 2026年可达300-400亿美金
- 估值1700亿美元（被认为不高，因年化10倍+增长）
- Kimi、Qwen、DeepSeek已不再学OpenAI，而是follow Claude

### 投资配置（Q2调整）
- OpenAI 40%（非技术壁垒最强）
- 字节跳动 40%（豆包端到端体验、中国最强）
- Anthropic 10%（技术壁垒高，但产品壁垒低）
- Google 10%（规模效应追回一城）

## ChatGPT的非技术壁垒

> ChatGPT身上有很多非技术性壁垒，而Coding或模型公司只是技术壁垒。

- 品牌壁垒类比可口可乐
- 模型能力保鲜期仅3-6个月
- **最好的模型拿走最大的价值**

## AI产品"保鲜窗口"

| 产品 | 窗口时长 |
|------|----------|
| Perplexity | ~2年 |
| Cursor | ~9个月 |
| Manus | ~3个月 |

> 基础模型公司不再满足于API收费，全部要端到端做Agent。

### Claude Code vs Cursor
- Claude Code仅3-4个月ARR就反超Cursor
- 年底可能达15亿美金
- Cursor困境：token亏损率1:3甚至1:10

## 下一个L4领域：Office/Workspace

> Claude Code模式Work后可不断拓展——PPT、Excel。Office用户群从3000万扩展到5-6亿。

**核心观点**：模型正在分化（通用只有2家），ChatGPT的非技术壁垒（品牌、分发）比技术壁垒更持久，AI产品保鲜窗口在急剧缩短。

**对张成市的价值**：投资配置建议（OpenAI/字节/Anthropic/Google比例）直接可用。"保鲜窗口"概念对判断AI创业公司时间窗口极有价值——窗口从Perplexity的2年缩短到Manus的3个月。
