# AGI长编·收集计划
## 九面定义 → 收集清单 → 长编材料 → 精编定本

**启动时间**：2026-05-10  
**方法论**：先齐后精。每个面收到"齐"再进入下一个面。齐的标准：各方观点俱在、关键文献覆盖、没有明显盲区。

---

## 面1：定义面

**目标**：搞清楚AGI到底是什么，不同流派怎么定义它，AGI和现在的"窄AI"（Narrow AI/ANI）本质区别在哪。

**收集清单**：
- [ ] AGI的经典定义（哪些人下过定义？）
- [ ] 不同流派对AGI的定义分歧（符号主义 vs 连接主义 vs 行为主义）
- [ ] AGI与"强AI"、"通用智能"的关系
- [ ] 当前学界对AGI的主流看法
- [ ] AGI的衡量标准（有没有公认的测试？图灵测试够吗？）
- [ ] 中文语境下AGI的讨论和翻译

**齐的标志**：能说清"AGI至少包括这几种定义，差异在这三点"。

---

## 面2：历史面

**目标**：AGI/人工智能这条路是怎么走到今天的。关键节点、关键人物、关键转折。

**收集清单**：
- [ ] 1950年代：图灵测试、达特茅斯会议
- [ ] 三次AI寒冬的起因和经过
- [ ] 深度学习复兴（2012 AlexNet）
- [ ] Transformer的诞生（2017 "Attention Is All You Need"）
- [ ] GPT系列演进（2018 GPT-1 → 至今）
- [ ] 关键转折点时间线

**齐的标志**：能画出一条不遗漏主要事件的时间线。

---

## 面3：技术面（扩大）

**目标**：通向AGI有哪几条技术路线？各走到哪了？争议在哪？

**收集清单**：
- [ ] 大语言模型路线（Scaling Law、MoE、长上下文）
- [ ] 符号主义/经典AI路线（GOFAI、知识图谱、逻辑推理）
- [ ] 神经符号主义（Neuro-Symbolic）
- [ ] 具身智能（Embodied AI、机器人+AI）
- [ ] 世界模型（World Models、JEPA、LeCun路线）
- [ ] 多模态路线（视觉+语言+其他）
- [ ] Agent/行动路线（AI Agent、Tool Use）
- [ ] 意识/认知科学路线
- [ ] 各路线核心论文和代表人物

**齐的标志**：能说清"至少有X条路在走，每条路的核心主张和瓶颈分别是什么"。

---

## 面4：人物+机构面

**目标**：谁是主要玩家？哪些机构和人在推动AGI？

**人物清单**：
- [ ] 老一辈（Minsky、McCarthy、Hinton、LeCun、Bengio）
- [ ] 中坚代（Sutskever、Hassabis、Amodei、Altman、Musk）
- [ ] 新锐/开源贡献者
- [ ] 中国学者和从业者

**机构清单**：
- [ ] OpenAI（GPT系列、Q*、AGI路线图）
- [ ] DeepMind/Google（Alpha系列、Gemini、Gato）
- [ ] Anthropic（Claude、Constitutional AI、安全路线）
- [ ] Meta AI（LLaMA、开源路线、LeCun的立场）
- [ ] xAI（Grok、Musk的AGI观）
- [ ] 微软（投资+Infra+Copilot）
- [ ] 中国大厂（百度/阿里/腾讯/字节/小米/华为）
- [ ] 独角兽（智谱/月之暗面/零一万物/DeepSeek/Minimax等）
- [ ] 科研机构（Mila、BAIR、DeepMind Lab、各大高校）

**齐的标志**：能列出前20-30个关键人物+前15-20个关键机构，每个人/机构一句话定位。

---

## 面5：能力面

**目标**：当前AI到底有多强？在哪些方面接近人类？哪些方面差得远？

**收集清单**：
- [ ] 当前最强模型能力评测（MMLU、HumanEval、GSM8K等）
- [ ] 推理能力（Chain-of-Thought、逻辑推理）
- [ ] 规划能力（长程规划、任务分解）
- [ ] 持久记忆（Context Window限制、外挂记忆）
- [ ] 因果理解（Causal Reasoning）
- [ ] 创造力和想象力
- [ ] 常识推理（Commonsense）
- [ ] Agent自主性（自我纠正、持续学习）
- [ ] 情感/共情能力

**齐的标志**：能说清"当前AI在X方面接近人类，在Y方面还差得远"。

---

## 面6：风险面

**目标**：AGI带来的风险和挑战是什么？哪些是真实的？哪些是科幻？

**收集清单**：
- [ ] AI对齐问题（Alignment Problem）
- [ ] 控制问题（Control Problem）
- [ ] 存在风险（Existential Risk）——支持方和反对方
- [ ] 偏见和公平性
- [ ] 取代就业
- [ ] 安全和滥用（深度伪造、AI武器）
- [ ] 监管和治理（全球AI治理进展）
- [ ] 中国视角下的AI风险讨论

**齐的标志**：能列出主要风险类别，每种风险都有支持和反对两方观点。

---

## 面7：教育面（核心关注）

**目标**：AGI如何根本改变教育？这是你做这个系统的初心方向。

**收集清单**：
- [ ] AI在教育领域的当前应用
- [ ] AGI时代教育的可能范式变革
- [ ] 个性化学习的真正实现路径
- [ ] 教师角色的重新定义
- [ ] AI for education的主要项目（Khan Academy、Duolingo等）
- [ ] 中国教育+AI现状
- [ ] 特殊教育+AI（学习障碍、注意力问题等）
- [ ] 知识与能力的关系变化（记住知识还有意义吗？）
- [ ] 你的明学七则在教育中的落地设想

**齐的标志**：能说清"AGI时代教育会变成什么样，我们可以在哪个位置切入"。

---

## 面8：产业面（扩大）

**目标**：钱往哪流？谁在领跑？商业上怎么变现？

**收集清单**：
- [ ] 全球AI融资金额和趋势
- [ ] 主要公司估值和营收
- [ ] 商业模式分析（API收费、订阅、垂直行业方案）
- [ ] 算力军备竞赛（NVIDIA、AMD、云厂商）
- [ ] 开源 vs 闭源商业模式之争
- [ ] 中国AI产业格局
- [ ] AGI的变现路径猜想

**齐的标志**：能画出产业格局图——谁烧了多少钱、谁靠什么赚钱、谁在领跑。

---

## 面9：展望面

**目标**：未来怎么走？此处允许且需要幻觉。

**收集清单**：
- [ ] 主流AGI到达时间预测（各种预测与依据）
- [ ] 乐观派和悲观派的未来图景
- [ ] 5年内可能的技术突破
- [ ] 10年内可能的社会影响
- [ ] 30年的终极想象
- [ ] 你的个人展望和判断（这是最重要的，因为这是你做这个系统的原因）

**齐的标志**：能写出一篇独立的、有观点有依据的未来展望——是你自己的见解，不是摘抄。

---

## 执行顺序

拟议：**从面1开始，依序推进**。因为定义面是所有面的基础——定义没搞清，后面都站不住。每个面完成后，进入下一个面之前，先给你过目。

**但你有权在任何时候调整顺序。** 比如你想先看教育面（面7），直接说，我就跳过去。
