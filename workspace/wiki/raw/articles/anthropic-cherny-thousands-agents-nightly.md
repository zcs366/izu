5月4日红杉资本采访，Anthropic 工程师切尔尼掏出手机："每天晚上，数千个 AI 智能体在替我写代码。"

这不是吹牛。是Claude Code缔造者亲口说的、他自己的日常工作方式。
01. 5月4日，他在红杉资本说了一段"反常识"的话
5月4日，鲍里斯·切尔尼（Boris Cherny）接受红杉资本采访。这位是 Anthropic Claude Code 的核心缔造者。

他当场掏出手机，给观众演示："我装了 Claude App，左边一个代码标签页，我会同时开启大量任务会话。"

主持人问：你一般同时开多少个？他答：5 到 10 个会话，每个会话里跑多个智能体。"通常每天晚上，我都会让数千个 AI 智能体开展深度开发工作。"

注意：是 数千个。不是 5 个，不是 50 个。注意：是 在手机上管理。不是开 5 台电脑。

Claude Code 缔造者切尔尼于 5 月 4 日接受红杉资本采访时，分享了自己的 AI 工作模式，国内技术圈才开始炸。但其实切尔尼今年1月就在 X 上公开过这套配置——5个月，810万浏览、10.4万收藏。他自己却说："我没意识到这事会让别人觉得意外，对我来说就是日常。"

这就是硅谷一线工程师和我们的差距。不是他比我们聪明，是他敢把 AI 当全职员工用。
02. 真正的杠杆是两个功能：/loops 和 Routines
很多人看到"数千个智能体"就懵了，以为门槛巨高。其实切尔尼说得很清楚——他靠的是 Claude Code 的两个功能：

▸ /loops（循环指令）本地用 cron 触发，一条指令循环执行。"帮我把这个 bug 反复尝试修，直到所有测试通过。"扔进去，睡觉，早上看结果。

▸ Routines（例行任务）跑在服务器上的周期性任务。合上电脑、关掉手机，AI 照样在云端给你打工。

切尔尼原话："这简直是最酷的功能，强烈推荐体验。"

翻译成人话：你不需要盯着 AI 干活，你只需要给它派活、定节奏。然后睡觉。
03. 一个真实案例：3天交付别人1个月的小程序
上个月有个朋友接了个教育机构的报名小程序。传统报价周期：1个月。

实际交付：

第1天 上午
• 和客户开 1 小时电话，确认所有功能点• 用 Claude Code 拆出 23 个并行任务
第1天 下午到夜里
• 5 个会话同时跑：登录、报名、支付、课程列表、后台• /loops 自动跑测试，跑通了才合并
第2天
• 人工 review 代码、调 UI、对接微信支付• Routines 跑了一夜的回归测试
第3天
• 客户验收，一次过
客户不知道的是：他付的是 1 个月的工时，而朋友只用了 3 天。省下来了 27 天。
04. 给想跟进的朋友 3 条实话
▸ 第一条：别一上来就想"跑数千个智能体"切尔尼是 Anthropic 工程师，基础设施跟你我不在一个量级。个人玩家从 5 个并行会话开始，已经够用。

▸ 第二条：/loops 和 Routines 必须配合人工 reviewAI 写的代码 80% 能用，20% 是雷。夜里让它跑，白天你必须看。不看就上线 = 给客户埋炸弹。

▸ 第三条：先把"任务拆解能力"练出来能不能让 AI 替你加班，关键不在 AI，在你。你能不能把一个大需求，拆成 10 个清晰、可并行、可验证的子任务？拆不了 = AI 帮不了你。拆得了 = AI 就是你的全职员工。
05. 写在最后
切尔尼在采访结尾说了一句："我没意识到这事会让别人感到意外。"

这句话扎心。对硅谷一线工程师，这是日常。对国内大部分开发者，这是新闻。

差距不在工具——Claude Code 你也能用。差距在认知：你敢不敢把 AI 当全职员工，把自己升级成"AI 团队的项目经理"？

我用了 3 个月，从一个累死累活的独立开发者，变成一个白天谈单、晚上让 AI 加班的"一人公司"。
