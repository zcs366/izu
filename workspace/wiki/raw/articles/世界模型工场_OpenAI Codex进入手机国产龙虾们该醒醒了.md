# OpenAI Codex进入手机，国产"龙虾"们该醒醒了

> 文 | 世界模型工场 | 钛媒体

## 核心事件

OpenAI推送更新，Codex正式进入ChatGPT手机App。
- 可在手机端完成：写报告、整理数据、处理文件、自动化流程
- 每周超过400万人在用Codex

## Agent战争的三个玩家

### 1. OpenClaw（"龙虾"）—— 需求验证者
- 优势：开源、免费、持久记忆、嵌入微信/飞书/钉钉
- 致命缺陷：极客玩具，需自己部署、配API、修bug
- > "如果你不懂命令行，这个项目对你来说太危险了。" —— 核心维护者
- 真实安全事故：邮件批量删除、信用卡被盗刷、工作文件被一键清空

### 2. Claude Code —— 市场教育者
- 今年2月已装远程控制（手机扫码接管电脑会话）
- 短板：太贵；只能在终端敲命令

### 3. OpenAI Codex —— 收割者
- 更低定价、更流畅体验、手机端触手可及
- "Agent的战场，正在从开发者圈子向所有人扩张"

## 国内"龙虾"现状与问题

```
国内大厂做的"龙虾"产品 = OpenClaw开源框架套壳 + 自家大模型 + 飞书/微信/钉钉流量入口
```

- **模型能力差距**：Agent任务对推理、指令理解、容错要求极高
- **留存假象**："新鲜感过去之后，留存率才是真相"
- **商业逻辑脆弱**：Agent干不好活 → 用户不持续用 → 一切归零

## 两条出路

**路径一：继续追赶通用Agent能力**（高难度）
- 需要真正的模型投入，而非生态套壳

**路径二：放弃通用，深挖垂直场景**（务实选择）
- 医疗、法律、制造、政务
- 优势：数据安全、本地部署、行业知识

> "靠'龙虾'概念圈用户的时代，结束了。"

**窗口期正在收窄：** Agent工具的普及速度比预期快。竞争本质不是产品之争，而是模型之争。
