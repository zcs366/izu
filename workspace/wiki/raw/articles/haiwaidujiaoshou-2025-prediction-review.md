# 拾象2025 AI预测复盘（命中率80%）

## 正确预测（13项）

### 模型与云格局
- ✅ 微软投资Anthropic，模型与云解绑
- ✅ Google逆转颓势（Gemini 3重回AI王者）
- ✅ OS是最高护城河，MCP是新时代TCP/IP

### Agent落地
- ✅ Coding Agent率先落地（Claude Code ARR突破10亿美金）
- ✅ Long horizon task成功率是核心指标（每7个月翻一倍）
- ✅ Context Engineering取代RAG

### 技术范式
- ✅ RL Scaling超越Pre-training（最大范式转移）
- ✅ 推理模型商业化受限（非大众必需品）
- ✅ Chatbot竞争翻篇，新AI产品形态竞争开始

### 市场格局
- ✅ AI技术红利流入大公司，Mag 9强者恒强
- ✅ 能源紧张，核电重启潮（美股核电板块超Nasdaq100达368个百分点）

## 错误预测（2项）

- ❌ **合成数据突破**：高估了"自我造血"能力，低估了高质量人类数据不可替代性
- ❌ **Memory和Online Learning解决**：严重低估了灾难性遗忘等核心技术难度

## 关键数据

- Agent任务完成长度每7个月翻一倍
- Cursor ARR增长10倍+，Claude Code ARR突破10亿美金
- Claude Code增长速度可能比ChatGPT还快

**核心观点**：拾象2025年20个AI预测命中率80%，核心判断（模型与云解绑、Google逆袭、Agent从Coding落地）全部正确。两大错误预测（合成数据、Memory）反映了AI领域最难的技术瓶颈。

**对张成市的价值**：80%命中率的预测体系本身就是极好的投资研究方法论参考。正确和错误预测的对比分析，帮助识别哪些趋势是确定性的（Agent、Coding），哪些仍存巨大不确定性（合成数据、Memory）。
