哈喽大家好，我是灰尘。专注 AI 知识分享，希望和大家一起在 AI 的浪潮里跃迁！

前几天，卡兹克大佬免费开放了他们公司内部一直在用的 AI 热点网站——AIHOT。

其实我很早就知道这个东西了，因为之前卡兹克大佬就有在他的文章里提到过这个东西。

当时大佬也说了是他们内部用的，所以我估计应该不会开放出来，还想着看看自己能不能做一个类似的简易版。

没想到现在，大佬真的开放出来了。

模型、产品、行业等动态，这个网站一网打尽。

而且开放这个网站后没几天，大佬又开发了一个 Skill，让你的 Agent 可以直接接入 AIHOT！

真是赛博大善人🙏

在此之前，大佬还开源过几个特别好用的 Skill。

正好，昨天在 AIHOT 看到一个新闻：Anthropic 公司 Claude Code 团队的 Thariq Shihipar 主张，在向Claude 等大语言模型请求输出时，应优先选择 HTML 而非 Markdown 格式。

Thariq Shihipar 的观点一出，也是在网上引起了激烈讨论，有说 HTML 好的，也有说 Markdown 好的。

我突发奇想，能不能用卡兹克大佬开源的横纵分析法分析一下 HTML 和 Markdown，再用卡兹克写作这个 Skill 写一篇文章？

说干就干。

我找到了 Thariq Shihipar 发表在 X 上的原文，然后把它保存下来。

让 Claude Code 基于它使用横纵分析法分析，然后基于分析结果来写文章。

对了，我的 Claude Code 接入的是 Deepseek V4 模型。

然后就是等它分析，然后写文章，写完了还会自检一下。自检这个是卡兹克写作 Skill 里面的功能。

给大家看看最后生成的文章效果。

不得不说，卡兹克大佬的写作 Skill 真的很好用，写的文章质量很高，比我写得好多了。

但是我不会拿它产出的内容直接发布，因为这个东西它不是属于我的，和我本人的风格也不一样。

大佬也说了，不希望大家把这个 Skill 拿来就用，而是要结合自己的风格，一点点打磨，把它迭代成自己专属的 Skill。

到这里基本就把大佬开源的内容都用上了，还有一个 neat-freak（洁癖），这个下次再试试吧。

从找 AI 热点，到分析调研，再到产出文章，几分钟就搞定了。

这就是这套神器套装的厉害之处。

最后，再说一下我自己的观点吧。

HTML 好，还是 Markdown 好？

我觉得这个根本没必要去争，为什么呢？因为 HTML 是给人看的，Markdown 是给 AI 看的。

HTML 作为给人的视觉呈现，可以很精美，让人有很好的视觉体验。

而 Markdown 作为提供给 AI 的输入，简单易读，对 AI 友好，没有冗余无效的代码块。

现在，你明白了吗？
