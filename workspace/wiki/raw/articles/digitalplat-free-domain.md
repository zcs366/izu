大家好，这里是科技素语。

本期给大家带来一个免费域名的注册教程。提供这个域名的机构是一家名为DigitalPlat的非营利性组织，整个体验下来，我感觉还是比较靠谱的。

在开始之前，先聊聊它的几个优点：

第一，完全免费。注册后有效期一年，到期前可以免费续期，理论上可以永久免费使用。

第二，可托管到 Cloudflare。而且不需要像 ClouDNS 那样做双向解析，可以直接配合 Cloudflare 以使用各种服务。

第三，短小好记。可选的免费域名最短一共就 4 个字母——qd.je。

如果你还没下定决心买付费域名，先注册一个免费域名练手是很合适的选择。

**第一步：注册账号**

打开注册地址：这里注册地址我会放在评论区。建议大家不要直接点击进去，用电脑操作会更加方便快捷。

网站有部分英文，可以借助浏览器翻译功能，但操作时记得先关闭翻译，否则可能出问题。

接下来需要填写个人信息。只要填写一套英文的信息就可以了，但是邮箱必须填写真实邮箱地址（支持QQ邮箱），后面需要接收验证码。

填写要点：
- Username：用户名，唯一性要求，建议复杂一点
- Legal Full Name：填写英文姓名，名字中间必须包含一个空格
- Email：必须是真实邮箱，且只支持以下几种：Gmail、Zoho、Outlook、Yahoo、Yandex、Hotmail、iCloud、163、QQ。其他后缀的邮箱无法收到验证邮件
- Phone：按官方格式填写，如 +1-XXXXXXXXXX（不要求真实）
- Password：至少 8 位，包含字母和数字，显示绿色即合格
- 推荐码：从链接进去会自动填写，注册成功之后会送一个免费域名额度

然后填写地址：
- WHOIS / 域名联系地址：英文地址习惯，从小到大，格式为：街道，城市，省，邮编，国家

重要提醒：提交前一定要把用户名、姓名、邮箱、电话、地址这几项信息复制到记事本保存，防止忘记。

确认信息无误后，点击蓝色的注册按钮，看到 Successful 提示就说明注册成功，邮件已发出。

**第二步：验证邮箱**

这一步可能会遇到意外——即使用了官方要求的邮箱后缀，也有一定概率收不到验证邮件。

如果遇到这种情况，建议改天再试。一般不是邮箱的问题，而是对方服务器的问题。过几天再试就可以了。

注意：验证邮件通常会被丢进垃圾邮件里，记得去那里翻一下。

**第三步：KYC 身份验证**

登录后会跳转到另一个页面，提示选择 KYC 验证方式。之前还有 Upload KYC Document 这种方式，现在只有 GitHub 账号验证这一个选项。有账号的直接登录，没有的注册一个也很简单，GitHub 同样可以QQ邮箱注册。

点击 使用GitHub登录 进入下一步。

登录之后就来到了上面的页面，继续点击 Authorize EdwardLab。

稍等页面跳转。看到页面提示 GitHub verification completed and your account is now KYC verified，KYC 验证就完成了。

**第四步：注册域名**

新注册的账号一开始最多有 3 个免费域名注册额度。填写邀请码可以多一个名额；然后官方还有一个在他们的 GitHub 点 star 的活动，也可以再获得一个名额。

来到上面这个页面，点击注册，就可以看到自己有两个 Free slots 名额。右上角可选语言，选择简体中文。

页面往下滑你会看到这里，可以选择想要的域名后缀，前面输入想要的域名前缀，勾选下方的同意条款，点击检查可用性。可以注册会自动跳转。（注意：US.KG 和 XX.KG 需要付费，选择另外三个之一就行，推荐 dpdns.org 和 qzz.io，因为 qd.je 暂时不能托管到 Cloudflare，可能和它是新推出的域名有关。）

接下来需要填写至少两个 Name Server（名称服务器）。这个网站只负责发放域名，不负责解析，需要我们自己托管到别处——首选当然是 Cloudflare。

**第五步：托管到 Cloudflare**

打开 Cloudflare 官网登录（没有账号就免费注册一个）。操作流程：
1. 点击"添加域"，然后点击"链接域名"，输入刚才注册的域名，继续
2. 选择计划，Free 免费版就够用
3. 一路点击继续，直到提示"没有 DNS 记录"，确认即可
4. Cloudflare 会分配两个名称服务器给你

把这两个 Name Server 复制回到域名的注册页面，分别填入两个 Name Server 输入框，点击注册完成域名注册。

回到 Cloudflare 继续点击"继续"。它会提示最多需要 24 小时处理，但实际上通常几分钟就好了。

最后再确认一项：边缘证书是否生效。在左侧 SSL/TLS → 边缘证书，初始是"待验证"状态，几分钟后刷新会变成"有效"，证书 3 个月有效期，会自动续订，不用管。

**如何免费续订**

域名有效期一年，可以在到期前 90 天内免费续订。进入域名列表 → 点击你的域名 → 点击续费按钮 → 再点蓝色的申请免费续费。如果还没到 90 天窗口期，按钮是不可点击的。官方不一定会发邮件提醒到期，建议大家自己设个提醒。

**免费域名的局限性**

第一，稳定性较差。US.KG 在去年年底曾经全线崩溃，所有域名都无法解析。

第二，所有权不在你手里。万一这家机构倒闭或改变政策，你可能就失去使用权。

所以如果是用来搭建对外发布的个人网站，还是建议申请一个正式的付费域名。免费的二级域名比较适合用来学习和搭建自用服务。
