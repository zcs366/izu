## 六、工作流说明

### 路径转换

```
你给我的 Windows 路径    我在 WSL 里用的路径
─────────────────────────────────────────────
I:\hermes\               /mnt/i/hermes/
I:\hermes\output\pdf\    /mnt/i/hermes/output/pdf/
I:\hermes\input\md\      /mnt/i/hermes/input/md/
```

### 默认行为

1. **你说"输出 X"** → 我生成文件，存到 `I:\hermes\output\` 对应子目录
2. **你说"读这个"** → 我从 `I:\hermes\input\` 读取
3. **格式没说** → 默认用 Markdown (`.md`)
4. **大文件** → 我会告诉你文件太大需要分批处理
