# Karpathy 推文：用 HTML 呈现 LLM 回答

## 输出形态演进

纯文本 → Markdown → HTML（新默认值） → ... → 交互式神经视频/模拟

## 核心论点

人类约三分之一大脑是视觉皮层。文字是小路，视觉是主干道。信息密度决定效率。

## Karpathy 原文关键引用

> "Many open questions as to how exact/procedural Software 1.0 artifacts may be woven together with neural artifacts..."

承认传统代码与神经网络如何协同仍是开放问题。

## 实操建议

每次问 LLM 时加一句："用 HTML 呈现你的回答"

## 注意事项

1. 场景适配：简单查询不需要HTML
2. 容易炫技过度：需约束"简洁，信息优先"
3. 无后端逻辑：HTML仅包装前端模拟
4. 额外步骤：需打开浏览器
5. Token成本：比Markdown多1.5~2倍

## 更大思考

输出端仍是文字流——水管进口加粗十倍，出水口还是吸管。每一次输出形态改变都催生新平台。
