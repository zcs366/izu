# Scientific Agent Skills

**GitHub**: https://github.com/K-Dense-AI/scientific-agent-skills (23k Stars | MIT)
**官网**: https://agentskills.io/

## 核心理念
AI不应该只会写通用代码，更应该懂科研。
135个科研技能包，AI助手能理解并执行复杂科研流程。

## 135个技能覆盖领域
| 领域 | 技能数 |
|------|--------|
| 生物信息学与基因组学 | 序列分析、单细胞RNA-seq、基因调控网络 |
| 化学信息与药物发现 | 分子性质预测、虚拟筛选、ADMET分析 |
| 蛋白质组学与质谱 | LC-MS/MS数据处理、肽段鉴定 |
| 临床研究 | 临床试验、药物基因组学 |
| ML/AI | 深度学习、强化学习、贝叶斯方法 |
| 材料科学与化学 | 晶体结构分析、相图 |
| 物理与天文 | 天文数据分析、宇宙学 |
| 工程与模拟 | 离散事件模拟、多目标优化 |
| 数据分析和可视化 | 统计分析、出版级图表 |
| 地理空间科学 | 卫星影像处理、GIS |
| 实验室自动化 | 液体处理协议、LIMS集成 |
| 科学交流 | 文献综述、同行评审、科技写作 |

## 100+可调用数据库
PubChem、ChEMBL、UniProt、COSMIC、ClinicalTrials.gov、BioServices（~40个）、BioPython Entrez（38个NCBI）、gget（20+基因组）
