awesome 是 GitHub 上最知名的资源索引项目，由 Node.js 之父 Sindre Sorhus 创建。收录 GitHub 上最优质的资源列表，覆盖前端、后端、AI、区块链等所有技术领域，4000+ 子列表。

466k Stars，常年霸榜 GitHub 全站前十。

三大价值：节约时间（筛选好的链接）、质量保证（社区审核）、永不落伍（动态更新，任何人都可以提 PR）。
