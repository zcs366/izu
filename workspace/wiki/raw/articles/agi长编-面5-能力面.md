# AGI长编 · 面5：能力面（初编）
## 当前AI有多强？还差多少？

**版本**：v1.0 · 2026-05-10

---

## 前言

"AGI"不是"有或没有"的开关。更准确的说法是：**当前AI在某些维度上已经很接近人类，在另一些维度上还差得很远。** 这一面就是把每个维度拆开来看。

---

## 一、当前最强模型的能力概览（2026年）

在不讨论"这算不算真智能"的前提下，当前最强的模型（GPT-4o、Claude Opus 4、Gemini Ultra 2、DeepSeek V4）能做到：

**✅ 能做的事：**

| 能力 | 表现 | 接近人类吗？ |
|------|------|------------|
| 语言理解与生成 | 写文章、翻译、总结、改写 | ✅ 已经超过大多数人 |
| 编程 | 写代码、调试、解释 | ✅ 接近中级工程师水平 |
| 知识问答 | 回答各种学科问题 | ✅ 超过大多数人类（但会出错） |
| 逻辑推理（简单） | 三段论、简单推理 | ✅ 不错 |
| 图像理解 | 看懂图片内容和图表 | ✅ 接近人类水平 |
| 考试 | 律师考试、医学执照考试 | ✅ 超过大部分考生 |
| 数学竞赛题 | 能解决高难度数理化题 | ✅ o3接近国际奥赛水平 |

**❌ 还做不好的事：**

| 能力 | 为什么不行 |
|------|-----------|
| 真正的推理 | 会做模式匹配式的"看起来像推理"，但改两个数字就不会了。苹果2025年研究：大模型在简单逻辑变化题上惨败 |
| 因果理解 | 知道"A之后是B"不代表理解"因为A所以B" |
| 长程规划 | 能写计划，但超过10步的任务容易中途出错或跑偏 |
| 持久记忆 | 训练完就固定了，不会自动更新。上下文窗口再大也是暂时的 |
| 自我意识 | 没有任何证据表明有意识或自我感知 |
| 情感理解 | 能模仿但缺乏真实共情 |
| 自主学习 | 需要人类设计训练流程，不会自己设定学习目标 |
| 常识 | 经常犯"人都不会犯"的错，比如以为"人用鳃呼吸" |

## 二、核心能力维度拆解

### 1. 推理能力（Reasoning）

**当前水平**：
- 简单逻辑推理：✅ 强
- 复杂多步推理：⚠️ 中等（o3等"推理模型"有进步，但仍不稳定）
- 类比推理：⚠️ 能模仿但本质是模式匹配
- 反事实推理（"如果当初没发生X会怎样"）：❌ 弱

**关键争议**：
- 苹果2025年研究让大模型做数学题，**只改题目中的名字和数字（逻辑完全一样），准确率从97%暴跌到30%以下**。这说明它的"推理"更像记忆匹配，不是真理解。
- 反对者说：人类也会被这种"换汤不换药"的题骗到，所以这不证明大模型没推理。

### 2. 规划能力（Planning）

**当前水平**：
- 可以写出看起来很合理的计划
- 但执行中遇到意外情况难以调整
- 多步骤任务（10步以上）容易出错

**为什么重要**：没有规划能力，AI就不能独立完成复杂任务——这是AGI的关键能力。

### 3. 记忆能力（Memory）

**当前水平**：
- 短期记忆（上下文窗口）：
  - GPT-4 Turbo：128K tokens（约一本300页的书）
  - Gemini 1.5 Pro：1M tokens（约三本）
  - Kimi：200万字（约六本）
  - DeepSeek V4：1M tokens
- **长期记忆**：❌ 几乎所有模型都没有。训练完知识就固定了。有人用外挂数据库模拟，但这不是真正的"记住"。

**为什么重要**：没有长期记忆的"智能"就像金鱼——每次对话都像第一次见面。

### 4. 创造力（Creativity）

**争议最大**：
- **支持派**：GPT-4能写诗、编故事、设计产品，这是创造
- **反对派**：它是把见过的内容重组，不是真正的"无中生有"；创造力需要情感和个人经历

### 5. 自主学习（Self-directed Learning）

**当前水平**：❌ 目前的AI不能自己决定"我要学什么"。训练流程是人设计的，数据是人选的。真正的AGI应该能像人类一样自己设定学习目标。

### 6. Agent能力（自主行动）

**当前水平**：⚠️ 2025-2026年进展很快，出现了能调用工具、执行任务的Agent。但：
- 中途出错无法自动恢复
- 需要人类频繁干预
- 安全风险大（让AI自主操作计算机、访问网站、执行命令）

## 三、基准测试数据速览

这些是用来"给AI打分"的常见考试：

| 测试名称 | 考什么 | GPT-4o/claude水平 | 人类基准 |
|---------|-------|-----------------|---------|
| **MMLU** | 57个学科的知识（高中到大学水平） | 88-90% | 约75-80%（专家级约90%） |
| **HumanEval** | 编程能力（写函数） | 85-92% | 100% |
| **GSM8K** | 小学数学应用题 | 95%+ | 100% |
| **GPQA** | 博士级推理 | 60-70% | 约65-75%（专家水平） |
| **SWE-bench** | 真实软件工程任务 | 40-50% | 100% |

**注意**：基准测试有"污染"问题——很多题目可能已经在训练数据中出现过，所以分数高不一定代表真能力。

## 四、"能力全景图"：一图看懂还差什么

```
                 近距离   ║   中距离      ║   远距离
                 (已接近)  ║  (正在进步)    ║  (还差得远)
                 ═════════╬══════════════╬═══════════════
语言理解与生成    ●■■■■■■■║              ║
编程能力         ●■■■■■■ ║              ║
知识问答         ●■■■■■  ║              ║
图像理解         ●■■■■■  ║              ║
简单推理         ●■■■■   ║              ║
─────────────────┼────────╫──────────────╫───────────────
复杂推理         │        ║ ●■■■        ║
Agent能力        │        ║ ●■■■        ║
创造力           │        ║ ●■■          ║
─────────────────┼────────╫──────────────╫───────────────
长期记忆         │        ║              ║ ●■
```

**关键发现**：当前AI在"和人对话"这个场景下已经很惊艳，但一涉及到**独立生存、自主学习、深层理解**，差距立刻拉大。这正好解释了为什么现在的AI需要人类喂养和引导——它还没有"站起来自己走"的能力。

## 五、与你相关的特别关注

你打算做**教育系统**，有几个能力短板特别重要：

1. **推理不可靠** → 当它给学生讲题时，它自己可能都是错的（特别是复杂的数理化）
2. **没有长期记忆** → 不能真正"了解"一个学生并持续跟踪他的进步
3. **缺乏自我修正** → 不能意识到自己在犯错并主动纠正

这些都是做教育系统时**必须解决的问题**，也是你的系统需要弥补的缺口。
