# MMSkills: Towards Multimodal Skills for General Visual Agents

## 一句话总结
为视觉Agent设计了一种**多模态技能包**——将文本流程、运行时状态卡和多视图关键帧绑定为可复用的紧凑包，通过分支加载架构在推理时提供视觉证据而不污染主对话历史。

## 核心贡献
1. **正式化"多模态程序性知识"**：视觉Agent的技能不仅需要"做什么操作"，还需要"如何识别视觉状态、解读进度信号、决定下一步"
2. **MMSkill Package 三元组**：`(文本流程, 运行时状态卡, 多视图关键帧)` — 515个跨域技能覆盖Ubuntu/macOS桌面/Minecraft/Super Mario
3. **Trajectory-to-Skill Generator**：agentic流水线从公开非评估轨迹自动提取可复用多模态技能（workflow grouping → procedure induction → visual grounding → meta-skill auditing）
4. **Branch-Loaded Agent**：推理时分三阶段——(0)技能选择/(1)临时分支加载视觉证据/(2)蒸馏为结构化文本指导返回主agent，图片从不进入主对话历史
5. **开源**：GitHub + HuggingFace数据集（515 skill packages）

## 实验结果
| 模型 | No Skill | MMSkills | 增益 |
|------|----------|----------|------|
| Gemini 3.1 Pro | 44.08 | **50.11** | +6.03 |
| Gemini 3 Flash | 36.65 | **47.97** | +11.32 |
| Qwen3-VL-235B | 21.34 | **39.17** | +17.83 |
| Qwen3-VL-8B | 10.78 | **25.40** | +14.62 |

**消融结论**：文本/状态卡/图片各自独立贡献增益；分支加载本身（即使纯文本）优于直接注入主prompt

## 对Hermes Agent的实施方略

### P0（立即）
- 扩展SKILL.md格式，增加state元数据（when_to_use/when_not_to_use/verification_cue）
- 允许skill引用Images/目录截图

### P1（1-2周）
- Branch-Loaded Skill适配器：临时上下文分支+结构化指导蒸馏
- State Card解析器：从runtime_state_cards.json生成紧凑文本摘要

### P2（月级）
- Task-Skill映射系统
- Trajectory-to-Skill Generator原型

### P3（远期）
- 社区贡献门户
- 动态Runtime Skill学习
